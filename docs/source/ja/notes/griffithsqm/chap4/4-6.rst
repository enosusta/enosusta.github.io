Problem 4.6
==================

球面調和関数の定義より，

.. math::
    Y_l^{-m}(\theta,\phi)
    =
    \sqrt{
        \frac{2l+1}{4\pi}
        \frac{(l+m)!}{(l-m)!}
    }
    e^{-im\phi}P_l^{-m}(\cos\theta)

である。一方，負の `m` に対する Legendre 陪関数は，

.. math::
    P_l^{-m}(x)
    =(-1)^m\frac{(l-m)!}{(l+m)!}P_l^m(x)

と定義される。これを代入すると，

.. math::
    \begin{aligned}
        Y_l^{-m}(\theta,\phi)
        &=
        (-1)^m
        \sqrt{
            \frac{2l+1}{4\pi}
            \frac{(l+m)!}{(l-m)!}
        }
        \frac{(l-m)!}{(l+m)!}
        e^{-im\phi}P_l^m(\cos\theta)
        \\
        &=
        (-1)^m
        \sqrt{
            \frac{2l+1}{4\pi}
            \frac{(l-m)!}{(l+m)!}
        }
        e^{-im\phi}P_l^m(\cos\theta)
    \end{aligned}

となる。 `P_l^m(\cos\theta)` は実関数なので，

.. math::
    Y_l^{-m}(\theta,\phi)
    =(-1)^m\left[Y_l^m(\theta,\phi)\right]^*

となる。
