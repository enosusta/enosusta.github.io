Problem 4.16
==================

基底状態では，

.. math::
    |\psi_{100}(r,\theta,\phi)|^2
    =\frac{1}{\pi a^3}e^{-2r/a}

である。電子が `r` と `r+\dd r` の間の球殻内に見いだされる確率は，

.. math::
    P(r)\,\dd r
    =4\pi r^2|\psi_{100}|^2\,\dd r
    =\frac{4r^2}{a^3}e^{-2r/a}\,\dd r

となる。動径確率密度を微分すると，

.. math::
    \dv{P}{r}
    =\frac{8r}{a^3}e^{-2r/a}
    \left(1-\frac{r}{a}\right)

となる。停留点は `r=0` と `r=a` であり， `P(0)=0` かつ `P(a)>0` なので，最大値を与えるのは，

.. math::
    r=a

である。したがって，最も確からしい半径は Bohr 半径である。
