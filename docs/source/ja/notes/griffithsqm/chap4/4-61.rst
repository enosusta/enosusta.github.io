Problem 4.61
==================

`S_z` の固有状態を，`m=3/2,1/2,-1/2,-3/2` の順に基底として選ぶ。昇降演算子の作用は，

.. math::
    S_\pm\ket{s\,m}
    =
    \hbar\sqrt{s\left(s+1\right)-m\left(m\pm1\right)}
    \ket{s\,m\pm1}

である。`S_x=\left(S_++S_-\right)/2` と `s=3/2` を用いると，

.. math::
    S_x
    =
    \frac{\hbar}{2}
    \begin{pmatrix}
        0&\sqrt{3}&0&0\\
        \sqrt{3}&0&2&0\\
        0&2&0&\sqrt{3}\\
        0&0&\sqrt{3}&0
    \end{pmatrix}

となる。`\mu\coloneqq2\lambda/\hbar` と置けば，特性方程式は，

.. math::
    \begin{aligned}
        0
        &=
        \det
        \begin{pmatrix}
            -\mu&\sqrt{3}&0&0\\
            \sqrt{3}&-\mu&2&0\\
            0&2&-\mu&\sqrt{3}\\
            0&0&\sqrt{3}&-\mu
        \end{pmatrix}
        \\
        &=\mu^4-10\mu^2+9
        =\left(\mu^2-1\right)\left(\mu^2-9\right)
    \end{aligned}

となる。したがって，`S_x` の固有値は，

.. math::
    \lambda
    =
    \frac{3\hbar}{2},\quad
    \frac{\hbar}{2},\quad
    -\frac{\hbar}{2},\quad
    -\frac{3\hbar}{2}

となる。
