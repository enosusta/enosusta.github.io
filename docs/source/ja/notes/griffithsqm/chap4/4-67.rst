Problem 4.67
==================

a.  全スピン `\bm{S}=\bm{S}_1+\bm{S}_2+\bm{S}_3` の2乗を展開すると，

    .. math::
        S^2
        =
        \sum_{i=1}^3S_i^2
        +2\left(
        \bm{S}_1\cdot\bm{S}_2
        +\bm{S}_2\cdot\bm{S}_3
        +\bm{S}_3\cdot\bm{S}_1
        \right)

    となる。各粒子について `S_i^2=3\hbar^2/4` なので，ハミルトニアンは，

    .. math::
        H
        =
        \frac{J}{2}
        \left(S^2-\frac{9}{4}\hbar^2\right)

    と書ける。

b.  三つのスピン `1/2` から，全スピン `s=3/2` の四重項と，`s=1/2` の二つの二重項が得られる。エネルギーは，

    .. math::
        E_s
        =
        \frac{J\hbar^2}{2}
        \left[
        s\left(s+1\right)-\frac{9}{4}
        \right]

    なので，

    .. math::
        E_{3/2}=\frac{3}{4}J\hbar^2,
        \quad
        E_{1/2}=-\frac{3}{4}J\hbar^2

    となる。`J>0` だから，基底状態のエネルギーは `-3J\hbar^2/4` である。`s=1/2` の二重項が二組あるため，縮退度は4である。

c.  `\bm{A}\coloneqq\bm{S}_1+\bm{S}_3`，`\bm{B}\coloneqq\bm{S}_2+\bm{S}_4` と置けば，`\bm{S}=\bm{A}+\bm{B}` であり，

    .. math::
        \begin{aligned}
            S^2-A^2-B^2
            &=2\bm{A}\cdot\bm{B}\\
            &=2\left(
            \bm{S}_1\cdot\bm{S}_2
            +\bm{S}_2\cdot\bm{S}_3
            +\bm{S}_3\cdot\bm{S}_4
            +\bm{S}_4\cdot\bm{S}_1
            \right)
        \end{aligned}

    となる。したがって，

    .. math::
        H
        =
        \frac{J}{2}
        \left[
        S^2-\left(\bm{S}_1+\bm{S}_3\right)^2
        -\left(\bm{S}_2+\bm{S}_4\right)^2
        \right]

    となる。対角線上の各組のスピン量子数を `s_{13}`，`s_{24}` とすると，

    .. math::
        E
        =
        \frac{J\hbar^2}{2}
        \left[
        s\left(s+1\right)
        -s_{13}\left(s_{13}+1\right)
        -s_{24}\left(s_{24}+1\right)
        \right]

    となる。最小値は `s_{13}=s_{24}=1` を全スピン `s=0` に結合したときに得られ，

    .. math::
        E_0=-2J\hbar^2

    となる。この `1\otimes1` に含まれる一重項は一つだけなので，基底状態は一意である。
