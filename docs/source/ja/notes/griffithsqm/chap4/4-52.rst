Problem 4.52
==================

a.  `n=3`，`l=2` の動径関数と `m=1` の球面調和関数は，

    .. math::
        R_{32}(r)
        =
        \frac{4}{81\sqrt{30}a^{3/2}}
        \left(\frac{r}{a}\right)^2
        e^{-r/(3a)},

    .. math::
        Y_2^1(\theta,\phi)
        =
        -\sqrt{\frac{15}{8\pi}}
        \sin\theta\cos\theta\,e^{i\phi}

    である。したがって，

    .. math::
        \psi_{321}(r,\theta,\phi)
        =
        -\frac{1}{81\sqrt{\pi}a^{3/2}}
        \left(\frac{r}{a}\right)^2
        e^{-r/(3a)}
        \sin\theta\cos\theta\,e^{i\phi}

    を得る。

b.  規格化積分は，

    .. math::
        \begin{aligned}
            \int|\psi_{321}|^2\,\dd^3\bm{r}
            ={}&
            \frac{1}{81^2\pi a^7}
            \int_0^\infty
            r^6e^{-2r/(3a)}\,\dd r
            \\
            &\times
            \int_0^\pi
            \sin^3\theta\cos^2\theta\,\dd\theta
            \int_0^{2\pi}\dd\phi
        \end{aligned}

    である。各積分は，

    .. math::
        \int_0^\infty
        r^6e^{-2r/(3a)}\,\dd r
        =
        6!\left(\frac{3a}{2}\right)^7,
        \quad
        \int_0^\pi
        \sin^3\theta\cos^2\theta\,\dd\theta
        =
        \frac{4}{15},
        \quad
        \int_0^{2\pi}\dd\phi=2\pi

    なので，

    .. math::
        \int|\psi_{321}|^2\,\dd^3\bm{r}
        =
        \frac{
        6!\left(3a/2\right)^7
        }{
        81^2\pi a^7
        }
        \frac{4}{15}\left(2\pi\right)
        =1

    となる。

c.  角度積分は規格化によって消去できるため，

    .. math::
        \begin{aligned}
            \braket{r^s}
            &=
            \frac{
            \displaystyle
            \int_0^\infty
            r^{s+6}e^{-2r/(3a)}\,\dd r
            }{
            \displaystyle
            \int_0^\infty
            r^6e^{-2r/(3a)}\,\dd r
            }
            \\
            &=
            \frac{\Gamma\left(s+7\right)}{\Gamma(7)}
            \left(\frac{3a}{2}\right)^s
        \end{aligned}

    を得る。原点で積分可能であるための条件は `s+6>-1` なので，

    .. math::
        s>-7

    のとき，かつそのときに限り有限である。
