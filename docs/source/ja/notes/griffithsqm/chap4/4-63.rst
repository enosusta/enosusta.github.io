Problem 4.63
==================

球面調和関数を，

.. math::
    Y_l^m
    =
    K_l^m e^{im\phi}P_l^m\left(\cos\theta\right)

と書く。上昇演算子を作用させると，

.. math::
    \begin{aligned}
        L_+Y_l^m
        &=
        \hbar K_l^m e^{i\left(m+1\right)\phi}
        \left[
        \pdv{}{\theta}
        -m\cot\theta
        \right]
        P_l^m\left(\cos\theta\right)\\
        &=
        \hbar K_l^m e^{i\left(m+1\right)\phi}
        P_l^{m+1}\left(\cos\theta\right)
    \end{aligned}

となる。第2式では，`x=\cos\theta` と問題文の微分公式を用いた。一方，規格化された角運動量固有状態に対する昇降演算子の作用は，

.. math::
    L_+Y_l^m
    =
    \hbar\sqrt{\left(l-m\right)\left(l+m+1\right)}
    Y_l^{m+1}

である。両者を比較すると，

.. math::
    K_l^{m+1}
    =
    \frac{K_l^m}
    {\sqrt{\left(l-m\right)\left(l+m+1\right)}}

となる。`C(l)\coloneqq K_l^0` としてこの漸化式を反復すれば，

.. math::
    K_l^m
    =
    C(l)
    \sqrt{\frac{\left(l-m\right)!}{\left(l+m\right)!}}

となる。この式は下降演算子を用いることで，負の `m` にも拡張される。

:ref:`notes/griffithsqm/chap4/4-25:Problem 4.25` の結果と，

.. math::
    P_l^l\left(\cos\theta\right)
    =
    \frac{\left(-1\right)^l\left(2l\right)!}
    {2^l l!}
    \sin^l\theta

を比較する。上の一般式では，

.. math::
    \begin{aligned}
        Y_l^l
        &=
        \frac{C(l)}{\sqrt{\left(2l\right)!}}
        e^{il\phi}P_l^l\left(\cos\theta\right)\\
        &=
        \frac{\left(-1\right)^l C(l)\sqrt{\left(2l\right)!}}
        {2^l l!}
        \sin^l\theta e^{il\phi}
    \end{aligned}

となる。:ref:`notes/griffithsqm/chap4/4-25:Problem 4.25` の規格化係数と等置すると，

.. math::
    C(l)=\sqrt{\frac{2l+1}{4\pi}}

となる。したがって，求める規格化因子は，

.. math::
    K_l^m
    =
    \sqrt{
    \frac{2l+1}{4\pi}
    \frac{\left(l-m\right)!}{\left(l+m\right)!}
    }

となる。
