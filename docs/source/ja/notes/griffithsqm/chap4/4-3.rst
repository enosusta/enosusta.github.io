Problem 4.3
==================

a.  波動関数は角度に依存しないので，球座標の Laplacian は，

    .. math::
        \nabla^2\psi
        =\frac{1}{r^2}\dv{}{r}
        \left(r^2\dv{\psi}{r}\right)

    となる。 `\psi=Ae^{-r/a}` に対して，

    .. math::
        \begin{aligned}
            \dv{\psi}{r}&=-\frac{1}{a}\psi,
            \\
            \nabla^2\psi
            &=\left(\frac{1}{a^2}-\frac{2}{ar}\right)\psi
        \end{aligned}

    である。時間に依存しない Schrödinger 方程式から，

    .. math::
        V(r)
        =E+\frac{\hbar^2}{2m}\frac{\nabla^2\psi}{\psi}
        =E+\frac{\hbar^2}{2ma^2}
        -\frac{\hbar^2}{mar}

    を得る。 `r\to\infty` で `V(r)\to0` となるためには，

    .. math::
        E=-\frac{\hbar^2}{2ma^2}

    でなければならない。したがって，

    .. math::
        V(r)=-\frac{\hbar^2}{mar}

    となる。

b.  今度は `\psi=Ae^{-r^2/a^2}` なので，

    .. math::
        \begin{aligned}
            \dv{\psi}{r}&=-\frac{2r}{a^2}\psi,
            \\
            \nabla^2\psi
            &=\left(-\frac{6}{a^2}+\frac{4r^2}{a^4}\right)\psi
        \end{aligned}

    となる。したがって，

    .. math::
        V(r)
        =E-\frac{3\hbar^2}{ma^2}
        +\frac{2\hbar^2}{ma^4}r^2

    である。条件 `V(0)=0` より，

    .. math::
        E=\frac{3\hbar^2}{ma^2}

    となるので，求めるポテンシャルは，

    .. math::
        V(r)=\frac{2\hbar^2}{ma^4}r^2

    である。これは角振動数 `\omega=2\hbar/(ma^2)` の3次元等方的調和振動子ポテンシャルであり，得られたエネルギーは `E=3\hbar\omega/2` と一致する。
