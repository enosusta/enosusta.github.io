Problem 4.25
==================

a.  `Y_l^l` は固定した `l` に対する梯子の最上段にある。これより大きい `m` の状態は存在しないので，

    .. math::
        L_+Y_l^l=0

    である。

b.  `L_zY_l^l=\hbarl Y_l^l` と `L_z=-i\hbar\partial/\partial\phi` から，

    .. math::
        Y_l^l(\theta,\phi)
        =\Theta(\theta)e^{il\phi}

    と書ける。これに，

    .. math::
        L_+
        =
        \hbar e^{i\phi}
        \left(
        \pdv{}{\theta}
        +i\cot\theta\pdv{}{\phi}
        \right)

    を作用させ，\(a) を用いると，

    .. math::
        \dv{\Theta}{\theta}
        -l\cot\theta\,\Theta=0

    を得る。したがって，

    .. math::
        \frac{1}{\Theta}\dv{\Theta}{\theta}
        =l\cot\theta
        \quad\Longrightarrow\quad
        \Theta(\theta)=C_l\sin^l\theta

    であり，

    .. math::
        Y_l^l(\theta,\phi)
        =
        C_l\sin^l\theta\,e^{il\phi}

    となる。

c.  規格化条件は，

    .. math::
        \begin{aligned}
            1
            &=
            \int_0^{2\pi}\int_0^\pi
            \left|Y_l^l\right|^2
            \sin\theta\,\dd\theta\,\dd\phi
            \\
            &=
            2\pi\left|C_l\right|^2
            \int_0^\pi\sin^{2l+1}\theta\,\dd\theta
        \end{aligned}

    である。積分値，

    .. math::
        \int_0^\pi\sin^{2l+1}\theta\,\dd\theta
        =
        \frac{2^{2l+1}\left(l!\right)^2}
        {\left(2l+1\right)!}

    を用いると，

    .. math::
        \left|C_l\right|
        =
        \frac{1}{2^ll!}
        \sqrt{\frac{\left(2l+1\right)!}{4\pi}}

    を得る。規格化だけでは全体の位相は決まらない。通常の Condon--Shortley の位相規約 `C_l=(-1)^l|C_l|` を選べば，

    .. math::
        Y_l^l(\theta,\phi)
        =
        \frac{(-1)^l}{2^ll!}
        \sqrt{\frac{\left(2l+1\right)!}{4\pi}}
        \sin^l\theta\,e^{il\phi}

    となり，問題 4.7 の結果と一致する。
