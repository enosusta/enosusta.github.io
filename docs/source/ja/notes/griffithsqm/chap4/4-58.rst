Problem 4.58
==================

a.  規格化条件は，

    .. math::
        1
        =
        |A|^2
        \left(
        |1-2i|^2+|2|^2
        \right)
        =
        9|A|^2

    となる。全体の位相を0に選べば，

    .. math::
        A=\frac{1}{3},
        \quad
        \chi=
        \frac{1}{3}
        \begin{pmatrix}
            1-2i\\
            2
        \end{pmatrix}

    となる。

b.  `S_z` の固有値は `\pm\hbar/2` である。各確率はスピノールの成分の絶対値の2乗なので，

    .. math::
        P_z^+
        =
        \frac{5}{9},
        \quad
        P_z^-
        =
        \frac{4}{9}

    となる。したがって，

    .. math::
        \braket{S_z}
        =
        \frac{\hbar}{2}
        \left(
        P_z^+-P_z^-
        \right)
        =
        \frac{\hbar}{18}

    となる。

c.  `S_x` の規格化された固有スピノールは，

    .. math::
        \chi_\pm^{(x)}
        =
        \frac{1}{\sqrt{2}}
        \begin{pmatrix}
            1\\
            \pm1
        \end{pmatrix}

    となる。したがって，

    .. math::
        \begin{aligned}
            P_x^+
            &=
            \frac{1}{2}
            \left|
            \frac{1-2i}{3}+\frac{2}{3}
            \right|^2
            =
            \frac{13}{18},
            \\
            P_x^-
            &=
            \frac{1}{2}
            \left|
            \frac{1-2i}{3}-\frac{2}{3}
            \right|^2
            =
            \frac{5}{18}
        \end{aligned}

    となる。測定値は `\pm\hbar/2` であり，

    .. math::
        \braket{S_x}
        =
        \frac{\hbar}{2}
        \left(
        P_x^+-P_x^-
        \right)
        =
        \frac{2\hbar}{9}

    となる。

d.  `S_y` の規格化された固有スピノールは，

    .. math::
        \chi_+^{(y)}
        =
        \frac{1}{\sqrt{2}}
        \begin{pmatrix}
            1\\
            i
        \end{pmatrix},
        \quad
        \chi_-^{(y)}
        =
        \frac{1}{\sqrt{2}}
        \begin{pmatrix}
            1\\
            -i
        \end{pmatrix}

    となる。よって，

    .. math::
        \begin{aligned}
            P_y^+
            &=
            \frac{1}{2}
            \left|
            \frac{1-2i}{3}
            -i\frac{2}{3}
            \right|^2
            =
            \frac{17}{18},
            \\
            P_y^-
            &=
            \frac{1}{2}
            \left|
            \frac{1-2i}{3}
            +i\frac{2}{3}
            \right|^2
            =
            \frac{1}{18}
        \end{aligned}

    となる。測定値は `\pm\hbar/2` であり，

    .. math::
        \braket{S_y}
        =
        \frac{\hbar}{2}
        \left(
        P_y^+-P_y^-
        \right)
        =
        \frac{4\hbar}{9}

    となる。
