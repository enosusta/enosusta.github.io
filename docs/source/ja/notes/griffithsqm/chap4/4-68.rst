Problem 4.68
==================

a.  格子間隔を `\Delta r=b/(N+1)`，内部格子点を `r_j=j\Delta r` とする。有限差分法で用いるエネルギー尺度は，

    .. math::
        \lambda
        \coloneqq
        \frac{\hbar^2}{2m_e\left(\Delta r\right)^2}

    である。有効ポテンシャルをこの尺度で割ると，

    .. math::
        \begin{aligned}
            v_j
            &=
            \frac{1}{\lambda}
            \left[
            -\frac{e^2}{4\pi\epsilon_0r_j}
            +\frac{\hbar^2l\left(l+1\right)}{2m_er_j^2}
            \right]\\
            &=
            -\frac{2\Delta r}{aj}
            +\frac{l\left(l+1\right)}{j^2}\\
            &=
            -\frac{2\beta}{j}
            +\frac{l\left(l+1\right)}{j^2},
            \quad
            \beta\coloneqq\frac{b}{\left(N+1\right)a}
        \end{aligned}

    を得る。ここでは `a=4\pi\epsilon_0\hbar^2/(m_ee^2)` を用いた。したがって，無次元ハミルトニアン `\bm{H}/\lambda` は，対角要素が `2+v_j`，隣接する非対角要素が `-1` の三重対角行列である。

b.  `\beta=1/50`，`N=1000` として，三重対角行列の最低三つの固有値を計算する。`|E_1|=\hbar^2/(2m_ea^2)` とすると `\lambda=|E_1|/\beta^2` なので，数値固有値 `\varepsilon` は `E/|E_1|=\varepsilon/\beta^2` に変換できる。

    .. exec_code::

        import numpy as np
        from scipy.linalg import eigh_tridiagonal

        N = 1000
        beta = 1.0 / 50.0
        j = np.arange(1, N + 1, dtype=float)
        off_diagonal = -np.ones(N - 1)

        print(
            f"{'l':>2} {'state':>5} {'E/|E_1|':>12} "
            f"{'free H E/|E_1|':>20}"
        )
        for l in range(3):
            diagonal = (
                2.0 - 2.0 * beta / j
                + l * (l + 1.0) / j**2
            )
            energies = eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, 2),
                eigvals_only=True,
            ) / beta**2

            for index, energy in enumerate(energies):
                n = l + index + 1
                exact = -1.0 / n**2
                print(
                    f"{l:2d} {index + 1:5d} {energy:12.8f} "
                    f"{exact:20.8f}"
                )

    `l=0` の最低二状態と `l=1` の最低状態は，自由な水素の値とよく一致する。より広がった高励起状態では，`b/a=(N+1)\beta=20.02` の壁による圧縮の影響が大きくなる。

    対応する規格化固有関数 `u(r)` を描く。見やすくするため，各曲線の最大絶対値を1に揃える。

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt
        from scipy.linalg import eigh_tridiagonal

        N = 1000
        beta = 1.0 / 50.0
        j = np.arange(1, N + 1, dtype=float)
        off_diagonal = -np.ones(N - 1)
        radius = np.arange(N + 2) * beta

        fig, axes = plt.subplots(
            1, 3, figsize=(12, 3.8), sharex=True,
            constrained_layout=True,
        )

        for l, ax in enumerate(axes):
            diagonal = (
                2.0 - 2.0 * beta / j
                + l * (l + 1.0) / j**2
            )
            values, vectors = eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, 2),
            )
            energies = values / beta**2

            for index in range(3):
                vector = vectors[:, index]
                if vector[np.argmax(np.abs(vector))] < 0.0:
                    vector *= -1.0
                vector /= np.max(np.abs(vector))
                vector = np.pad(vector, (1, 1))
                ax.plot(
                    radius,
                    vector,
                    label=rf"$E/|E_1|={energies[index]:.4f}$",
                )

            ax.axhline(0.0, color="black", linewidth=0.7)
            ax.set_title(rf"$l={l}$")
            ax.set_xlabel(r"$r/a$")
            ax.set_xlim(0.0, radius[-1])
            ax.grid(alpha=0.25)
            ax.legend(fontsize="small")

        axes[0].set_ylabel(r"$u(r)$ (scaled)")
        plt.show()
