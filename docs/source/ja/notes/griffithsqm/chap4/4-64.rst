Problem 4.64
==================

a.  二つの項はとも `l=1` の状態なので，得られる値は，

    .. math::
        L^2=2\hbar^2

    だけであり，その確率は1である。

b.  第1項では `m_l=0`，第2項では `m_l=1` である。したがって，

    .. math::
        \begin{array}{c|cc}
            L_z&0&\hbar\\ \hline
            P&1/3&2/3
        \end{array}

    となる。

c.  電子のスピンは `s=1/2` に固定されている。したがって，

    .. math::
        S^2=\frac{3}{4}\hbar^2

    が確率1で得られる。

d.  第1項はスピン上向き，第2項はスピン下向きなので，

    .. math::
        \begin{array}{c|cc}
            S_z&\hbar/2&-\hbar/2\\ \hline
            P&1/3&2/3
        \end{array}

    となる。

e.  `m_j=1/2` の部分空間における結合基底は，

    .. math::
        \begin{aligned}
            \ket{\frac{3}{2}\,\frac{1}{2}}
            &=
            \sqrt{\frac{2}{3}}
            \ket{1\,0}\ket{\frac{1}{2}\,\frac{1}{2}}
            +
            \sqrt{\frac{1}{3}}
            \ket{1\,1}\ket{\frac{1}{2}\,{-\frac{1}{2}}},\\
            \ket{\frac{1}{2}\,\frac{1}{2}}
            &=
            \sqrt{\frac{1}{3}}
            \ket{1\,0}\ket{\frac{1}{2}\,\frac{1}{2}}
            -
            \sqrt{\frac{2}{3}}
            \ket{1\,1}\ket{\frac{1}{2}\,{-\frac{1}{2}}}
        \end{aligned}

    である。したがって，与えられた角度・スピン状態は，

    .. math::
        \frac{2\sqrt{2}}{3}
        \ket{\frac{3}{2}\,\frac{1}{2}}
        -
        \frac{1}{3}
        \ket{\frac{1}{2}\,\frac{1}{2}}

    と書ける。よって，

    .. math::
        \begin{array}{c|cc}
            J^2&15\hbar^2/4&3\hbar^2/4\\ \hline
            P&8/9&1/9
        \end{array}

    となる。

f.  どちらの項でも `m_j=m_l+m_s=1/2` なので，

    .. math::
        J_z=\frac{\hbar}{2}

    が確率1で得られる。

g.  スピン状態は互いに直交するので，位置の確率密度は，

    .. math::
        \begin{aligned}
            \rho\left(r,\theta,\phi\right)
            &=
            \left|R_{21}(r)\right|^2
            \left[
            \frac{1}{3}\left|Y_1^0\right|^2
            +
            \frac{2}{3}\left|Y_1^1\right|^2
            \right]\\
            &=
            \frac{1}{96\pi a^3}
            \left(\frac{r}{a}\right)^2e^{-r/a}
        \end{aligned}

    となる。角度依存性が相殺されるため，この密度は等方的である。微小体積 `\dd^3\bm{r}` に粒子を見いだす確率は `\rho\,\dd^3\bm{r}` である。

h.  スピン上向き成分だけを残し，角度について積分する。単位 `r` 当たりの同時確率は，

    .. math::
        \begin{aligned}
            \dv{P_+}{r}
            &=
            \frac{1}{3}r^2\left|R_{21}(r)\right|^2
            \int\left|Y_1^0\right|^2\dd\Omega\\
            &=
            \frac{r^4}{72a^5}e^{-r/a}
        \end{aligned}

    である。
