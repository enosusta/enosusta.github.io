Problem 4.38
==================

a.  まず二つのクォークのスピンを合成すると，

    .. math::
        \frac{1}{2}\otimes\frac{1}{2}
        =
        1\oplus0

    となる。ここへ第3のクォークのスピン `1/2` を加えると，

    .. math::
        \begin{aligned}
            1\otimes\frac{1}{2}
            &=
            \frac{3}{2}\oplus\frac{1}{2},
            \\
            0\otimes\frac{1}{2}
            &=
            \frac{1}{2}
        \end{aligned}

    となる。したがって，バリオンに可能な全スピンは，

    .. math::
        s=\frac{3}{2},
        \quad
        \frac{1}{2}

    となる。`s=1/2` の組合せは二つの独立な仕方で現れる。

b.  クォークと反クォークはともにスピン `1/2` をもつので，

    .. math::
        \frac{1}{2}\otimes\frac{1}{2}
        =
        1\oplus0

    となる。したがって，中間子に可能な全スピンは，

    .. math::
        s=1,
        \quad
        0

    となる。
