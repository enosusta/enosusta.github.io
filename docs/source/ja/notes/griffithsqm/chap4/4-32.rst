Problem 4.32
==================

a.  `S_y` の固有値を `\lambda` とすると，

    .. math::
        \det\left(
        \frac{\hbar}{2}
        \begin{pmatrix}
            0&-i\\
            i&0
        \end{pmatrix}
        -\lambda\mathsf{I}
        \right)
        =
        \lambda^2-\frac{\hbar^2}{4}
        =0

    となるので，固有値は `\lambda_\pm=\pm\hbar/2` である。対応する規格化された固有スピノールは，

    .. math::
        \chi_+^{(y)}
        =
        \frac{1}{\sqrt{2}}
        \begin{pmatrix}
            1\\
            i
        \end{pmatrix},
        \quad
        \chi_-^{(y)}
        =
        \frac{1}{\sqrt{2}}
        \begin{pmatrix}
            1\\
            -i
        \end{pmatrix}

    と選べる。

b.  一般的な状態 `\chi=(a,b)^{\mathsf T}` と各固有スピノールとの内積は，

    .. math::
        \begin{aligned}
            \left(\chi_+^{(y)}\right)^\dagger\chi
            &=
            \frac{a-ib}{\sqrt{2}},
            \\
            \left(\chi_-^{(y)}\right)^\dagger\chi
            &=
            \frac{a+ib}{\sqrt{2}}
        \end{aligned}

    となるので，測定結果とその確率は，

    .. math::
        \begin{array}{c|c}
            S_y & P\\ \hline
            +\hbar/2 & \dfrac{1}{2}|a-ib|^2\\[2mm]
            -\hbar/2 & \dfrac{1}{2}|a+ib|^2
        \end{array}

    となる。 `a` と `b` が複素数であっても，

    .. math::
        \frac{1}{2}|a-ib|^2
        +\frac{1}{2}|a+ib|^2
        =
        |a|^2+|b|^2
        =1

    であり，確率の和は1である。

c.  `S_y^2=(\hbar^2/4)` なので，どの規格化された状態に対しても，

    .. math::
        S_y^2\chi=\frac{\hbar^2}{4}\chi

    となる。したがって，測定値は `\hbar^2/4` だけであり，その確率は1である。
