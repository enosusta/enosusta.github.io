Problem 4.54
==================

a.  基底状態の確率密度は，

    .. math::
        |\psi_{100}|^2
        =
        \frac{1}{\pi a^3}e^{-2r/a}

    である。したがって，半径 `b` の原子核内に電子を見いだす確率は，

    .. math::
        P
        =
        \frac{4}{a^3}
        \int_0^b r^2e^{-2r/a}\,\dd r

    となる。`x=2r/a`，`\epsilon=2b/a` と置けば，

    .. math::
        \begin{aligned}
            P
            &=
            \frac{1}{2}
            \int_0^\epsilon x^2e^{-x}\,\dd x
            \\
            &=
            1-e^{-\epsilon}
            \left(
            1+\epsilon+\frac{\epsilon^2}{2}
            \right)
        \end{aligned}

    となる。

b.  `e^{-x}` を展開して積分すれば，

    .. math::
        P
        =
        \frac{\epsilon^3}{6}
        -\frac{\epsilon^4}{8}
        +\frac{\epsilon^5}{20}
        +O\left(\epsilon^6\right)

    となる。`\epsilon=2b/a` なので，最低次では，

    .. math::
        P
        \approx
        \frac{1}{6}
        \left(\frac{2b}{a}\right)^3
        =
        \frac{4}{3}
        \left(\frac{b}{a}\right)^3

    となる。

c.  原子核内で波動関数を一定とみなせば，

    .. math::
        P
        \approx
        \frac{4}{3}\pi b^3|\psi_{100}(0)|^2
        =
        \frac{4}{3}\pi b^3
        \frac{1}{\pi a^3}
        =
        \frac{4}{3}
        \left(\frac{b}{a}\right)^3

    となり，\(b) の最低次の結果と一致する。

d.  与えられた値を用いた数値計算は次のとおりである。

    .. exec_code::

        b = 1.0e-15
        a = 0.5e-10
        probability = (4.0 / 3.0) * (b / a)**3

        print(f"P = {probability:.3e}")

    したがって，

    .. math::
        P\approx1.07\times10^{-14}

    となる。
