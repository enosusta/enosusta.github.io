Problem 3.18
==================

a.  `Q=1` の場合，

    .. math::
        \dv{\braket{1}}{t}
        =\frac{i}{\hbar}\braket{[\hat{H},1]}
        =0

    となる。ここで，

    .. math::
        \braket{1}
        =\braket{\Psi|\Psi}
        =\int|\Psi(x,t)|^2\,\dd x

    なので，これは波動関数の規格化が時間とともに保存されることを表す。

b.  `Q=H` の場合，

    .. math::
        \dv{\braket{H}}{t}
        =\left\langle\pdv{\hat{H}}{t}\right\rangle

    となる。時間に陽に依存しないハミルトニアンでは `\partial\hat{H}/\partial t=0` なので，

    .. math::
        \dv{\braket{H}}{t}=0

    となり，エネルギーの期待値が保存される。

c.  `Q=x` の場合，ハミルトニアンを，

    .. math::
        \hat{H}=\frac{\hat{p}^{\,2}}{2m}+V(x)

    と書くと， `[V(x),x]=0` であり，

    .. math::
        \begin{aligned}
            [\hat{p}^{\,2},x]
            &=\hat{p}[\hat{p},x]+[\hat{p},x]\hat{p}
            \\
            &=\hat{p}(-i\hbar)+(-i\hbar)\hat{p}
            \\
            &=-2i\hbar\hat{p}
        \end{aligned}

    であるから，

    .. math::
        [\hat{H},x]=-\frac{i\hbar}{m}\hat{p}

    となり，

    .. math::
        \dv{\braket{x}}{t}
        =\frac{\braket{p}}{m}

    となる。これは式 (1.33) である。

d.  `Q=p` の場合， `[\hat{p}^{\,2},\hat{p}]=0` であり，:ref:`notes/griffithsqm/chap3/3-14:Problem 3.14` の \(c) より，

    .. math::
        [V(x),\hat{p}]
        =i\hbar\dv{V}{x}

    であるから，

    .. math::
        [\hat{H},\hat{p}]
        =i\hbar\dv{V}{x}

    となり，

    .. math::
        \dv{\braket{p}}{t}
        =-\left\langle\dv{V}{x}\right\rangle
        =\braket{F}

    となる。これは式 (1.38) である。
