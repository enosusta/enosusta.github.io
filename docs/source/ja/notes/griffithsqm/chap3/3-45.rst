Problem 3.45
==================

状態をエネルギー固有基底で，

.. math::
    |S(t)\rangle
    =\sum_{n'=0}^{\infty}c_{n'}(t)|n'\rangle

と展開する。:ref:`notes/griffithsqm/chap3/3-39:Problem 3.39` で得た位置演算子の行列要素を用いると，

.. math::
    \begin{aligned}
        \braket{n|\hat{x}|S(t)}
        &=\sum_{n'=0}^{\infty}
        c_{n'}(t)\braket{n|\hat{x}|n'}
        \\
        &=\sqrt{\frac{\hbar}{2m\omega}}
        \sum_{n'=0}^{\infty}c_{n'}(t)
        \left(
            \sqrt{n'}\,\delta_{n,n'-1}
            +\sqrt{n}\,\delta_{n',n-1}
        \right)
        \\
        &=\sqrt{\frac{\hbar}{2m\omega}}
        \left[
            \sqrt{n+1}\,c_{n+1}(t)
            +\sqrt{n}\,c_{n-1}(t)
        \right]
    \end{aligned}

となる。
