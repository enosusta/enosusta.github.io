Problem 3.12
==================

自由粒子の一般解は，式 (2.101) より，

.. math::
    \Psi(x,t)
    =\frac{1}{\sqrt{2\pi}}
    \int_{-\infty}^{\infty}
    \phi(k)e^{ikx}e^{-i\hbar k^2t/(2m)}\,\dd k

である。ここで， `p'=\hbar k` と変数変換すると，

.. math::
    \begin{aligned}
        \Psi(x,t)
        &=\frac{1}{\sqrt{2\pi}\hbar}
        \int_{-\infty}^{\infty}
        \phi\left(\frac{p'}{\hbar}\right)
        e^{ip'x/\hbar}e^{-ip'^2t/(2m\hbar)}\,\dd p'
        \\
        &=\frac{1}{\sqrt{2\pi\hbar}}
        \int_{-\infty}^{\infty}e^{ip'x/\hbar}
        \left[
            \frac{1}{\sqrt{\hbar}}
            \phi\left(\frac{p'}{\hbar}\right)
            e^{-ip'^2t/(2m\hbar)}
        \right]\,\dd p'
    \end{aligned}

となる。これを式 (3.55) と比較すると，

.. math::
    \Phi(p,t)
    =\frac{1}{\sqrt{\hbar}}
    \phi\left(\frac{p}{\hbar}\right)
    \exp\left(-\frac{ip^2t}{2m\hbar}\right)

となる。時間依存性は絶対値が `1` の位相因子だけなので，確率密度は時間に依存しない。
