Problem 3.20
==================

:ref:`notes/griffithsqm/chap2/2-5:Problem 2.5` の波動関数は，

.. math::
    \Psi(x,t)
    =\frac{1}{\sqrt{2}}
    \left[
        \psi_1(x)e^{-i\omega t}
        +\psi_2(x)e^{-i4\omega t}
    \right],
    \quad
    \omega=\frac{\pi^2\hbar}{2ma^2}

である。ここで，

.. math::
    \psi_n(x)
    =\sqrt{\frac{2}{a}}
    \sin\left(\frac{n\pi x}{a}\right),
    \quad
    E_n=n^2\hbar\omega

である。エネルギー `E_1=\hbar\omega` と `E_2=4\hbar\omega` は，それぞれ確率 `1/2` で得られるので，

.. math::
    \begin{aligned}
        \braket{H}
        &=\frac{1}{2}(E_1+E_2)
        =\frac{5}{2}\hbar\omega
        \\
        \braket{H^2}
        &=\frac{1}{2}(E_1^2+E_2^2)
        =\frac{17}{2}(\hbar\omega)^2
    \end{aligned}

となる。したがって，

.. math::
    \begin{aligned}
        \sigma_H^2
        &=\braket{H^2}-\braket{H}^2
        \\
        &=\left(\frac{17}{2}-\frac{25}{4}\right)
        (\hbar\omega)^2
        \\
        &=\frac{9}{4}(\hbar\omega)^2
    \end{aligned}

となり，

.. math::
    \sigma_H=\frac{3}{2}\hbar\omega

となる。

次に位置の分散を求める。:ref:`notes/griffithsqm/chap2/2-5:Problem 2.5` より，

.. math::
    \braket{x}
    =\frac{a}{2}
    -\frac{16a}{9\pi^2}\cos(3\omega t)

である。 `x^2` の対角行列要素は，

.. math::
    \braket{n|x^2|n}
    =a^2\left(
        \frac{1}{3}-\frac{1}{2n^2\pi^2}
    \right)

なので，

.. math::
    \braket{1|x^2|1}
    =a^2\left(
        \frac{1}{3}-\frac{1}{2\pi^2}
    \right),
    \quad
    \braket{2|x^2|2}
    =a^2\left(
        \frac{1}{3}-\frac{1}{8\pi^2}
    \right)

となる。非対角要素は，

.. math::
    \begin{aligned}
        \braket{1|x^2|2}
        &=\frac{2}{a}\int_0^a x^2
        \sin\left(\frac{\pi x}{a}\right)
        \sin\left(\frac{2\pi x}{a}\right)\,\dd x
        \\
        &=\frac{1}{a}\int_0^a x^2
        \left[
            \cos\left(\frac{\pi x}{a}\right)
            -\cos\left(\frac{3\pi x}{a}\right)
        \right]\,\dd x
    \end{aligned}

となる。ここで，正の整数 `r` に対して，

.. math::
    \int_0^a x^2
    \cos\left(\frac{r\pi x}{a}\right)\,\dd x
    =\frac{2a^3(-1)^r}{r^2\pi^2}

であるから，

.. math::
    \braket{1|x^2|2}
    =-\frac{16a^2}{9\pi^2}

となる。行列要素は実数なので `\braket{2|x^2|1}` も同じ値であり，

.. math::
    \begin{aligned}
        \braket{x^2}
        &=\frac{1}{2}\left(
            \braket{1|x^2|1}
            +\braket{2|x^2|2}
        \right)
        +\braket{1|x^2|2}\cos(3\omega t)
        \\
        &=a^2\left(
            \frac{1}{3}
            -\frac{5}{16\pi^2}
            -\frac{16}{9\pi^2}\cos(3\omega t)
        \right)
    \end{aligned}

となる。したがって，

.. math::
    \sigma_x^2
    =a^2\left[
        \frac{1}{12}
        -\frac{5}{16\pi^2}
        -\frac{256}{81\pi^4}\cos^2(3\omega t)
    \right]

となり，

.. math::
    \sigma_x
    =a\sqrt{
        \frac{1}{12}
        -\frac{5}{16\pi^2}
        -\frac{256}{81\pi^4}\cos^2(3\omega t)
    }

となる。また， `\braket{x}` を微分すると，

.. math::
    \dv{\braket{x}}{t}
    =\frac{16a\omega}{3\pi^2}\sin(3\omega t)

となる。

エネルギー・時間不確定性原理の両辺を自乗して差を取ると，

.. math::
    \sigma_H^2\sigma_x^2
    -\frac{\hbar^2}{4}
    \left(\dv{\braket{x}}{t}\right)^2
    =\hbar^2a^2\omega^2
    \left(
        \frac{3}{16}
        -\frac{45}{64\pi^2}
        -\frac{64}{9\pi^4}
    \right)

となる。

.. exec_code::

    import numpy as np

    coefficient = (
        3.0 / 16.0
        - 45.0 / (64.0 * np.pi**2)
        - 64.0 / (9.0 * np.pi**4)
    )

    print(f"Difference = {coefficient:.10f} hbar^2 a^2 omega^2")
