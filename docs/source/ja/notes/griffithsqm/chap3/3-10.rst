Problem 3.10
==================

幅 `a` の無限深井戸を `0<x<a` に取ると，規格化された基底状態は，

.. math::
    \psi_1(x)=\sqrt{\frac{2}{a}}
    \sin\left(\frac{\pi x}{a}\right)
    \quad (0<x<a)

であり，井戸の外ではゼロである。井戸の内部で運動量演算子を作用させると，

.. math::
    \begin{aligned}
        \hat{p}\psi_1
        &=-i\hbar\dv{\psi_1}{x}
        \\
        &=-i\hbar\sqrt{\frac{2}{a}}\frac{\pi}{a}
        \cos\left(\frac{\pi x}{a}\right)
    \end{aligned}

となる。これは `\psi_1` に定数を掛けた形ではない。したがって，

.. math::
    \hat{p}\psi_1\not\propto\psi_1

ので，この状態に確定した運動量は存在しない。

別の見方をすると，運動量の固有値方程式，

.. math::
    -i\hbar\dv{\psi}{x}=p\psi

の非零解は `\psi(x)=Ce^{ipx/\hbar}` である。この関数は `\psi(0)=\psi(a)=0` という無限深井戸の両境界条件を満たせない。また，基底状態では対称性から `\braket{p}=0` となるが，平均値がゼロであることは運動量が確定してゼロであることを意味しない。実際， `\hat{p}\psi_1\neq0` であり，運動量には有限の分散がある。
