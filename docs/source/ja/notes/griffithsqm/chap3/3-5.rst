Problem 3.5
==================

a.  `x` は実数なので，

    .. math::
        \braket{f|xg}
        =\int f^*xg\,\dd x
        =\int(xf)^*g\,\dd x
        =\braket{xf|g}

    となる。したがって，

    .. math::
        x^\dagger=x

    である。定数 `i` については，

    .. math::
        \braket{f|ig}
        =i\braket{f|g}
        =\braket{-if|g}

    となるので，

    .. math::
        i^\dagger=-i

    である。最後に，部分積分により，

    .. math::
        \begin{aligned}
            \braket{f|\dv{}{x}g}
            &=\int f^*g'\,\dd x
            \\
            &=\left[f^*g\right]_{\text{boundary}}
            -\int f'^*g\,\dd x
            \\
            &=\braket{-\dv{}{x}f|g}
        \end{aligned}

    となるので，

    .. math::
        \left(\dv{}{x}\right)^\dagger=-\dv{}{x}

    となる。

b.  定義より，

    .. math::
        \begin{aligned}
            \braket{f|\hat{Q}\hat{R}g}
            &=\braket{\hat{Q}^\dagger f|\hat{R}g}
            \\
            &=\braket{\hat{R}^\dagger\hat{Q}^\dagger f|g}
        \end{aligned}

    となるので，

    .. math::
        (\hat{Q}\hat{R})^\dagger
        =\hat{R}^\dagger\hat{Q}^\dagger

    となる。同様に，

    .. math::
        \begin{aligned}
            \braket{f|(\hat{Q}+\hat{R})g}
            &=\braket{\hat{Q}^\dagger f|g}
            +\braket{\hat{R}^\dagger f|g}
            \\
            &=\braket{(\hat{Q}^\dagger+\hat{R}^\dagger)f|g}
        \end{aligned}

    となるので，

    .. math::
        (\hat{Q}+\hat{R})^\dagger
        =\hat{Q}^\dagger+\hat{R}^\dagger

    となる。また，

    .. math::
        \braket{f|c\hat{Q}g}
        =c\braket{\hat{Q}^\dagger f|g}
        =\braket{c^*\hat{Q}^\dagger f|g}

    となるので，

    .. math::
        (c\hat{Q})^\dagger
        =c^*\hat{Q}^\dagger

    となる。

c.  式 (2.48) は

    .. math::
        \hat{a}_+
        =\frac{1}{\sqrt{2\hbar m\omega}}
        \left(-i\hat{p}+m\omega x\right)

    であるから，

    .. math::
        \begin{aligned}
            \hat{a}_+^\dagger
            &=\frac{1}{\sqrt{2\hbar m\omega}}
            \left[(-i\hat{p})^\dagger+(m\omega x)^\dagger\right]
            \\
            &=\frac{1}{\sqrt{2\hbar m\omega}}
            \left(i\hat{p}+m\omega x\right)
            \\
            &=\hat{a}_-
        \end{aligned}

    となる。
