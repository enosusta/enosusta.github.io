Problem 3.19
==================

a.  :ref:`notes/griffithsqm/chap3/3-18:Problem 3.18` より，

    .. math::
        \dv{\braket{x}}{t}
        =\frac{\braket{p}}{m},
        \quad
        \dv{\braket{p}}{t}
        =-\left\langle\dv{V}{x}\right\rangle

    である。自由粒子では `V(x)=0` なので，

    .. math::
        \dv{\braket{p}}{t}=0

    となる。したがって， `\braket{p}` は時間に依存しない。これを第1式に代入して積分すると，

    .. math::
        \braket{x}(t)
        =\braket{x}(0)
        +\frac{\braket{p}}{m}t

    となる。

b.  調和振動子では，

    .. math::
        V(x)=\frac{1}{2}m\omega^2x^2,
        \quad
        \dv{V}{x}=m\omega^2x

    なので，

    .. math::
        \dv{\braket{p}}{t}
        =-m\omega^2\braket{x}

    となる。一方， `\dd\braket{x}/\dd t=\braket{p}/m` をもう一度微分すると，

    .. math::
        \dv{^2\braket{x}}{t^2}
        =\frac{1}{m}\dv{\braket{p}}{t}
        =-\omega^2\braket{x}

    となる。したがって， `\braket{x}` は古典的な単振動方程式を満たす。
