Problem 3.9
==================

a.  無限深井戸が該当する。幅 `a` の井戸における許容エネルギーは，

    .. math::
        E_n=\frac{n^2\pi^2\hbar^2}{2ma^2},
        \quad n=1,2,3,\ldots

    であり，互いに孤立した値だけからなる。井戸の外へ粒子が出る散乱状態は存在しないので，スペクトルは離散部分だけをもつ。

b.  反発的デルタ関数障壁，

    .. math::
        V(x)=+\alpha\delta(x),\quad
        \alpha>0

    が該当する。負のエネルギー `E=-\hbar^2\kappa^2/(2m)` の束縛状態があると仮定すると，無限遠で減衰する解は，

    .. math::
        \psi(x)=Ae^{-\kappa|x|}

    の形でなければならない。この関数の微分の跳びは，

    .. math::
        \psi'(0^+)-\psi'(0^-)=-2\kappa A

    となる。一方，Schrödinger 方程式を原点のまわりで積分すると，反発的デルタ関数障壁に対して，

    .. math::
        \psi'(0^+)-\psi'(0^-)
        =\frac{2m\alpha}{\hbar^2}\psi(0)
        =\frac{2m\alpha}{\hbar^2}A

    となる。左辺は `A` と反対符号，右辺は同符号なので， `\kappa>0` を満たす非自明解は存在しない。したがって束縛状態はなく， `E=\hbar^2k^2/(2m)\geq0` の散乱状態からなる連続スペクトルだけが残る。

c.  引力的デルタ関数井戸，

    .. math::
        V(x)=-\alpha\delta(x),\quad
        \alpha>0

    が該当する。\(b) と同じ束縛状態の候補 `\psi(x)=Ae^{-\kappa|x|}` に対し，今度の跳びの条件は，

    .. math::
        -2\kappa A
        =-\frac{2m\alpha}{\hbar^2}A

    となるので，

    .. math::
        \kappa=\frac{m\alpha}{\hbar^2},\quad
        E_0=-\frac{\hbar^2\kappa^2}{2m}
        =-\frac{m\alpha^2}{2\hbar^2}

    という1つの離散的な束縛状態が存在する。同時に， `E>0` には散乱状態が存在し，連続スペクトルを構成する。したがって，この Hamiltonian は離散部分と連続部分の両方をもつ。
