Problem 3.24
==================

正規直交基底 `\{|e_n\rangle\}` における行列要素を，

.. math::
    Q_{mn}=\braket{e_m|\hat{Q}e_n}

と書く。 `\hat{Q}` のエルミート性より，

.. math::
    \braket{e_m|\hat{Q}e_n}
    =\braket{\hat{Q}e_m|e_n}

である。一方，

.. math::
    \begin{aligned}
        Q_{nm}^*
        &=\braket{e_n|\hat{Q}e_m}^*
        \\
        &=\braket{\hat{Q}e_m|e_n}
    \end{aligned}

となるので，

.. math::
    Q_{mn}=Q_{nm}^*

となる。行列の随伴の成分は，

.. math::
    \left(Q^\dagger\right)_{mn}=Q_{nm}^*

であるから，

.. math::
    Q_{mn}=Q_{nm}^*
    \iff
    Q^\dagger=Q

となる。
