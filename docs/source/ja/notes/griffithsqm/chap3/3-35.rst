Problem 3.35
==================

中心運動量を，

.. math::
    p_0=\frac{2\pi\hbar}{\lambda}

と置いて，Fourier 変換すると，

.. math::
    \begin{aligned}
        \Phi(p,0)
        &=\frac{1}{\sqrt{2\pi\hbar}}
        \frac{1}{\sqrt{2n\lambda}}
        \int_{-n\lambda}^{n\lambda}
        e^{-i\left(p-p_0\right)x/\hbar}\,\dd x
        \\
        &=\frac{1}{2\sqrt{\pi\hbar n\lambda}}
        \frac{2\hbar
        \sin\left[
            \left(p-p_0\right)n\lambda/\hbar
        \right]}
        {p-p_0}
        \\
        &=\sqrt{\frac{\hbar}{\pi n\lambda}}
        \frac{
            \sin\left[
                \left(p-p_0\right)n\lambda/\hbar
            \right]
        }
        {p-p_0}
    \end{aligned}

となる。ここで，無次元変数，

.. math::
    X=\frac{x}{n\lambda},
    \quad
    Q=\frac{\left(p-p_0\right)n\lambda}{\hbar}

を導入する。

.. plot::
    :include-source: True
    :context: reset

    import matplotlib.pyplot as plt
    import numpy as np

    fig, axes = plt.subplots(1, 2, figsize=(9, 3.4))

    x = np.linspace(-1.5, 1.5, 1201)
    position_density = np.where(np.abs(x) < 1, 1.0, 0.0)
    axes[0].plot(x, position_density)
    axes[0].set_xlabel(r"$X=x/(n\lambda)$")
    axes[0].set_ylabel(r"$2n\lambda|\Psi|^2$")
    axes[0].set_ylim(-0.05, 1.15)
    axes[0].grid(alpha=0.25)

    q = np.linspace(-4 * np.pi, 4 * np.pi, 2401)
    momentum_density = np.sinc(q / np.pi) ** 2
    axes[1].plot(q, momentum_density)
    axes[1].axvline(-np.pi, color="gray", linestyle=":", linewidth=0.8)
    axes[1].axvline(np.pi, color="gray", linestyle=":", linewidth=0.8)
    axes[1].set_xlabel(r"$Q=(p-p_0)n\lambda/\hbar$")
    axes[1].set_ylabel(r"$\sin^2Q/Q^2$")
    axes[1].set_ylim(-0.05, 1.15)
    axes[1].grid(alpha=0.25)

    fig.tight_layout()
    plt.show()

位置分布の主ピークの両端は `x=\pm n\lambda` なので，

.. math::
    w_x=2n\lambda

となる。運動量分布の中心の両側にある最初のゼロ点は，

.. math::
    \frac{\left(p-p_0\right)n\lambda}{\hbar}
    =\pm\pi,
    \quad
    p=p_0\pm\frac{\pi\hbar}{n\lambda}

なので，

.. math::
    w_p=\frac{2\pi\hbar}{n\lambda}

である。 `n\to\infty` では `w_x\to\infty`， `w_p\to0` となる。 `w_x`， `w_p` を不確定さの粗い尺度として用いると，

.. math::
    \Delta x\,\Delta p
    \sim w_xw_p
    =\left(2n\lambda\right)
    \frac{2\pi\hbar}{n\lambda}
    =4\pi\hbar>\frac{\hbar}{2}

となり，Heisenberg 不確定性原理を満たす。

最後に，運動量の標準偏差を計算できない理由を調べる。大きな `|p|` に対して，

.. math::
    |\Phi(p,0)|^2=O\left(p^{-2}\right)

であり， `p^2|\Phi(p,0)|^2` は無限遠で減衰しない。したがって，

.. math::
    \braket{p^2}
    =\int_{-\infty}^{\infty}
    p^2|\Phi(p,0)|^2\,\dd p
    =\infty,
    \quad
    \sigma_p=\infty

となる。これは，位置空間波動関数を `x=\pm n\lambda` で不連続に切断したことが原因である。鋭い不連続点が任意に大きな波数成分を生み，運動量分布に長い裾を与えるため，有限の `w_p` は分布全体の標準偏差を表さない。
