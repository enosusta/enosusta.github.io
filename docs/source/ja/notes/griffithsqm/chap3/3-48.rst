Problem 3.48
==================

a.  まず，

    .. math::
        D(\hat{p})
        =\left\{
            f\mathrel{\big|}
            f,f'\in L^2(0,a),\quad f(0)=f(a)=0
        \right\}

    と置く。 `f\in D(\hat{p})` に対して部分積分すると，

    .. math::
        \begin{aligned}
            \braket{g|\hat{p}f}
            &=\int_0^a g(x)^*\left(-i\hbar f'(x)\right)\,\dd x
            \\
            &=-i\hbar\left[g^*f\right]_0^a
            +\int_0^a i\hbar g'(x)^*f(x)\,\dd x
            \\
            &=\int_0^a\left(-i\hbar g'(x)\right)^*
            f(x)\,\dd x
            \\
            &=\braket{\hat{p}^\dagger g|f}
        \end{aligned}

    となる。境界項は `f(0)=f(a)=0` だけで消えるため， `g(0)`， `g(a)` には条件を課す必要がない。したがって，随伴の作用は，

    .. math::
        \hat{p}^\dagger g=-i\hbar g'

    と元の演算子と同じであるが，その定義域は，

    .. math::
        D(\hat{p}^\dagger)
        =\left\{
            g\mathrel{\big|}g,g'\in L^2(0,a)
        \right\}

    となる。よって，共通の定義域上では作用が随伴と一致するためエルミートであるが，

    .. math::
        D(\hat{p})
        \subsetneq D(\hat{p}^\dagger)

    なので，自己随伴ではない。

b.  今度は，

    .. math::
        D_\lambda(\hat{p})
        =\left\{
            f\mathrel{\big|}
            f,f'\in L^2(0,a),\quad f(a)=\lambda f(0)
        \right\}

    とする。部分積分で現れる境界項は，

    .. math::
        \begin{aligned}
            -i\hbar\left[g^*f\right]_0^a
            &=-i\hbar\left[
                g^*(a)f(a)-g^*(0)f(0)
            \right]
            \\
            &=-i\hbar\left[
                \lambda g^*(a)-g^*(0)
            \right]f(0)
        \end{aligned}

    と置く。これがすべての `f\in D_\lambda(\hat{p})` に対してゼロとなる条件は，

    .. math::
        g^*(0)=\lambda g^*(a)
        \iff
        g(0)=\lambda^*g(a)

    である。 `\lambda\neq0` ならば，これは，

    .. math::
        g(a)=\frac{1}{\lambda^*}g(0)

    とも書ける。したがって，元の境界条件と随伴の境界条件が一致するための必要十分条件は，

    .. math::
        \lambda=\frac{1}{\lambda^*}
        \iff
        |\lambda|=1

    となる。

c.  半無限区間では無限遠の境界項が消えるため，境界形式は，

    .. math::
        -i\hbar\left[g^*f\right]_0^\infty
        =i\hbar g^*(0)f(0)

    だけである。これを同じ定義域に属するすべての `f,g` に対してゼロとするには， `f(0)=0` を課す必要がある。しかし，この定義域から定まる随伴には `g(0)` の制限がなく，両者の定義域は一致しない。
