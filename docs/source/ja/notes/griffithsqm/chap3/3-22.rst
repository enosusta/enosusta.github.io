Problem 3.22
==================

可観測量として `Q=x` を選ぶと，エネルギー・時間不確定性原理は，

.. math::
    \sigma_H\sigma_x
    \geq
    \frac{\hbar}{2}
    \left|\dv{\braket{x}}{t}\right|

となる。一方，:ref:`notes/griffithsqm/chap3/3-18:Problem 3.18` の \(c) より，

.. math::
    \dv{\braket{x}}{t}=\frac{\braket{p}}{m}

であるから，

.. math::
    \sigma_x\sigma_H
    \geq
    \frac{\hbar}{2m}|\braket{p}|

となる。
