Problem 3.30
==================

位置空間の波動関数を，

.. math::
    \Psi(x,t)=\braket{x|S(t)}

とする。エネルギー基底における成分は，

.. math::
    c_n(t)=\braket{n|S(t)}

である。この内積に位置基底による恒等演算子を挿入すると，

.. math::
    \begin{aligned}
        c_n(t)
        &=\left\langle
            n\middle|
            \left(
                \int_{-\infty}^{\infty}
                |x\rangle\langle x|\,\dd x
            \right)
            \middle|S(t)
        \right\rangle
        \\
        &=\int_{-\infty}^{\infty}
        \braket{n|x}\braket{x|S(t)}\,\dd x
    \end{aligned}

となる。位置表示における第 `n` エネルギー固有状態を，

.. math::
    \psi_n(x)=\braket{x|n}

と書くと，

.. math::
    \braket{n|x}=\braket{x|n}^*=\psi_n(x)^*

なので，

.. math::
    c_n(t)
    =\int_{-\infty}^{\infty}
    \psi_n(x)^*\Psi(x,t)\,\dd x

となる。
