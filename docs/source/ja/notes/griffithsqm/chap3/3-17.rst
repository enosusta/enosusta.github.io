Problem 3.17
==================

簡単のため，

.. math::
    x_0\coloneqq\braket{x},\quad
    p_0\coloneqq\braket{p}

と置く。式 (3.69) は，

.. math::
    \left(-i\hbar\dv{}{x}-p_0\right)\Psi
    =ia(x-x_0)\Psi

である。微分項を左辺に残して整理すると，

.. math::
    -i\hbar\dv{\Psi}{x}
    =\left[p_0+ia(x-x_0)\right]\Psi

となる。 `\Psi\neq0` の領域では，

.. math::
    \frac{1}{\Psi}\dv{\Psi}{x}
    =\frac{ip_0}{\hbar}-\frac{a}{\hbar}(x-x_0)

である。両辺を `x` について積分すると，

.. math::
    \ln\Psi
    =\frac{ip_0x}{\hbar}
    -\frac{a}{2\hbar}(x-x_0)^2+C

となるので，一般解は，

.. math::
    \Psi(x)
    =A
    \exp\left[-\frac{a}{2\hbar}(x-x_0)^2\right]
    \exp\left(\frac{ip_0x}{\hbar}\right)

である。全実線上で規格化可能となるためには `a>0` が必要である。このとき，

.. math::
    1
    =|A|^2\int_{-\infty}^{\infty}
    e^{-a(x-x_0)^2/\hbar}\,\dd x
    =|A|^2\sqrt{\frac{\pi\hbar}{a}}

より，全体位相を除いて，

.. math::
    |A|=\left(\frac{a}{\pi\hbar}\right)^{1/4}

となる。

確認として，この Gauss 波束では，

.. math::
    \sigma_x^2=\frac{\hbar}{2a}

である。また，もとの方程式より，

.. math::
    \left(\hat{p}-p_0\right)\Psi
    =ia(x-x_0)\Psi

なので，

.. math::
    \begin{aligned}
        \sigma_p^2
        &=\braket{
            \left(\hat{p}-p_0\right)\Psi
            |
            \left(\hat{p}-p_0\right)\Psi
        }
        \\
        &=a^2\sigma_x^2
        \\
        &=\frac{a\hbar}{2}
    \end{aligned}

となる。したがって， `\sigma_x\sigma_p=\hbar/2` となり，最小不確定波束であることも確認できる。
