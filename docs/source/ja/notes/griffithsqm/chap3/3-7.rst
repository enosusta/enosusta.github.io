Problem 3.7
==================

a.  仮定より，

    .. math::
        \hat{Q}f=qf,\quad
        \hat{Q}g=qg

    である。任意の複素数 `\alpha,\beta` に対し， `\hat{Q}` の線形性を用いると，

    .. math::
        \begin{aligned}
            \hat{Q}(\alpha f+\beta g)
            &=\alpha\hat{Q}f+\beta\hat{Q}g
            \\
            &=\alpha qf+\beta qg
            \\
            &=q(\alpha f+\beta g)
        \end{aligned}

    となる。したがって， `\alpha f+\beta g\neq0` である限り，この線形結合も固有値 `q` に属する固有関数である。線形結合が零関数となる場合だけは，零関数を固有関数と数えないという定義により除く。

b.  2回微分すると，

    .. math::
        \dv{^2}{x^2}e^x=e^x,\quad
        \dv{^2}{x^2}e^{-x}=e^{-x}

    となるので， `f=e^x` と `g=e^{-x}` はともに固有値 `1` に属する。\(a) より，その和と差から作られる，

    .. math::
        u(x)=\frac{f+g}{2}=\cosh x,\quad
        v(x)=\frac{f-g}{2}=\sinh x

    も固有値 `1` の固有関数である。 `u` は偶関数， `v` は奇関数なので，積 `u^*v=\cosh x\sinh x` は奇関数であり，

    .. math::
        \braket{u|v}
        =\int_{-1}^{1}\cosh x\sinh x\,\dd x
        =0

    となる。したがって，この2つの関数は区間 `(-1,1)` 上で直交している。

    規格化まで行うと，

    .. math::
        \begin{aligned}
            \int_{-1}^{1}\cosh^2x\,\dd x
            &=1+\frac{1}{2}\sinh2
            \\
            \int_{-1}^{1}\sinh^2x\,\dd x
            &=-1+\frac{1}{2}\sinh2
        \end{aligned}

    なので，正規直交固有関数として，

    .. math::
        u_1(x)=\frac{\cosh x}{\sqrt{1+\frac{1}{2}\sinh2}},
        \quad
        u_2(x)=\frac{\sinh x}{\sqrt{-1+\frac{1}{2}\sinh2}}

    を選ぶことができる。
