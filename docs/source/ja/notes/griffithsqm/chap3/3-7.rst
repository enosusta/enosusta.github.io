Problem 3.7
==================

a.  仮定より，

    .. math::
        \hat{Q}f=qf,\quad
        \hat{Q}g=qg

    である。任意の複素数 `\alpha,\beta` に対し，

    .. math::
        \begin{aligned}
            \hat{Q}(\alpha f+\beta g)
            &=\alpha\hat{Q}f+\beta\hat{Q}g
            \\
            &=\alpha qf+\beta qg
            \\
            &=q(\alpha f+\beta g)
        \end{aligned}

    となる。

b.  2回微分すると，

    .. math::
        \dv{^2}{x^2}e^x=e^x,\quad
        \dv{^2}{x^2}e^{-x}=e^{-x}

    となるので， `f=e^x` と `g=e^{-x}` はともに固有値 `1` に属する。\(a) より，

    .. math::
        u(x)=\frac{f+g}{2}=\cosh x,\quad
        v(x)=\frac{f-g}{2}=\sinh x

    も固有値 `1` の固有関数である。 `u` は偶関数， `v` は奇関数なので，積 `u^*v=\cosh x\sinh x` は奇関数であり，

    .. math::
        \braket{u|v}
        =\int_{-1}^{1}\cosh x\sinh x\,\dd x
        =0

    となる。したがって，この2つの関数は区間 `(-1,1)` 上で直交している。
