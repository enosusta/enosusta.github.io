Problem 1.9
==================

a.  規格化条件より，

    .. math::
        1 = A^2\int_{-\infty}^{\infty}e^{-2amx^2/\hbar}\,\dd x = A^2\sqrt{\frac{\pi\hbar}{2am}}

    となり， `A` は正なので，

    .. math::
        A = \left(\frac{2am}{\pi\hbar}\right)^{1/4}

    となる。

b.  波動関数を微分すると，

    .. math::
        \begin{aligned}
            \pdv{\Psi}{t} &= -ia\Psi
            \\
            \pdv{\Psi}{x} &= -\frac{2am}{\hbar}x\Psi
            \\
            \pdv{^2\Psi}{x^2} &= \left(-\frac{2am}{\hbar} + \frac{4a^2m^2}{\hbar^2}x^2\right)\Psi
        \end{aligned}

    となるので，時間に依存する Schrödinger 方程式の左辺は，

    .. math::
        i\hbar\pdv{\Psi}{t} = a\hbar\Psi

    となる。一方で運動エネルギー項は，

    .. math::
        -\frac{\hbar^2}{2m}\pdv{^2\Psi}{x^2} = (a\hbar - 2ma^2x^2)\Psi

    となる。したがって，ポテンシャルを調和振動子型

    .. math::
        V(x) = 2ma^2x^2

    にすれば `\Psi` は時間に依存する Schrödinger 方程式の解となる。

c.  確率密度 `|\Psi|^2 = A^2e^{-2amx^2/\hbar}` は `x` の偶関数なので，

    .. math::
        \braket{x} = 0

    となる。また，

    .. math::
        \begin{aligned}
            \braket{x^2} &= A^2\int_{-\infty}^{\infty}x^2e^{-2amx^2/\hbar}\,\dd x
            \\
            &= A^2\frac{\sqrt{\pi}}{2}\left(\frac{\hbar}{2am}\right)^{3/2} = \frac{\hbar}{4am}
        \end{aligned}

    となる。運動量については，

    .. math::
        \hat{p}\Psi = -i\hbar\pdv{\Psi}{x} = 2iamx\Psi

    となるので，

    .. math::
        \braket{p} = 0

    また，

    .. math::
        \hat{p}^2\Psi = -\hbar^2\pdv{^2\Psi}{x^2} = (2am\hbar - 4a^2m^2x^2)\Psi

    となるので，

    .. math::
        \begin{aligned}
            \braket{p^2} &= 2am\hbar - 4a^2m^2\braket{x^2}
            \\
            &= 2am\hbar - 4a^2m^2\frac{\hbar}{4am} = am\hbar
        \end{aligned}

    となる。

d.  \(c) より，それぞれの標準偏差は，

    .. math::
        \begin{aligned}
            \sigma_x &= \sqrt{\braket{x^2} - \braket{x}^2} = \sqrt{\frac{\hbar}{4am}} = \frac{1}{2}\sqrt{\frac{\hbar}{am}}
            \\
            \sigma_p &= \sqrt{\braket{p^2} - \braket{p}^2} = \sqrt{am\hbar}
        \end{aligned}

    となる。これらの積は，

    .. math::
        \sigma_x\sigma_p = \frac{\hbar}{2}

    であり，不確定性原理の下限にちょうど等しい。
