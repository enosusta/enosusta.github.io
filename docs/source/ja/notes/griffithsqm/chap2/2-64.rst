Problem 2.64
==================

a.  `f(x)` の微分は，

    .. math::
        \begin{aligned}
            f'(x) &= \sum_{n=1}^{\infty}n a_n x^{n-1}
            \\
            f''(x) &= \sum_{n=2}^{\infty}n(n-1) a_n x^{n-2}
        \end{aligned}

    となる。ここで `f''(x)` の添え字を2つ分ずらすと，

    .. math::
        f''(x) = \sum_{n=0}^{\infty}(n+2)(n+1)a_{n+2}x^n

    となる。また， `-x^2f''-2xf'` の `x^n` の係数は，

    .. math::
        -n(n-1)a_n -2na_n = -n(n+1)a_n

    となるので，各次数の係数を比較すると，

    .. math::
        (n+2)(n+1)a_{n+2} + [l(l+1)-n(n+1)]a_n = 0

    となる。これを `a_{n+2}` について解くと，

    .. math::
        a_{n+2} = \frac{(n-l)(n+l+1)}{(n+1)(n+2)}a_n \quad (n=0,1,2,\ldots)

    となる。

b.  `L=l(l+1)` と置き，`n\geq1` に対して `b_n=na_n` を導入すると，

    .. math::
        b_{n+2}=\left(1-\frac{L}{n(n+1)}\right)b_n

    となる。十分大きな添え字 `n_0` を選ぶと，

    .. math::
        b_{n_0+2k}=b_{n_0}
        \prod_{j=0}^{k-1}
        \left(1-\frac{L}{(n_0+2j)(n_0+2j+1)}\right)

    となる。積の `1` からのずれは `O(n^{-1})` なので，ある定数 `A\ne0` を用いて，

    .. math::
        b_n=A+O(n^{-1}),\quad
        a_n=\frac{A}{n}+O(n^{-2})

    と書ける。つまり，十分大きな `n` では係数の符号が揃い， `x=1` における和は調和級数と同様に発散する。

c.  `l=0` では，

    .. math::
        a_2 = \frac{(0-0)(0+1)}{(1)(2)}a_0 = 0

    となるので `f(x)=a_0` となる。 `l=1` では，

    .. math::
        a_3 = \frac{(1-1)(1+2)}{(2)(3)}a_1 = 0

    となるので `f(x)=a_1x` となる。 `l=2` では，

    .. math::
        \begin{aligned}
            a_2 &= \frac{(0-2)(0+3)}{(1)(2)}a_0 = -3a_0
            \\
            a_4 &= \frac{(2-2)(2+3)}{(3)(4)}a_2 = 0
        \end{aligned}

    となるので `f(x)=a_0(1-3x^2)` となる。 `l=3` では，

    .. math::
        \begin{aligned}
            a_3 &= \frac{(1-3)(1+4)}{(2)(3)}a_1 = -\frac{5}{3}a_1
            \\
            a_5 &= \frac{(3-3)(3+4)}{(4)(5)}a_3 = 0
        \end{aligned}

    となるので `f(x)=a_1(x-5x^3/3)` となる。以上より，

    .. math::
        \begin{aligned}
            P_0(x) &= a_0
            \\
            P_1(x) &= a_1x
            \\
            P_2(x) &= a_0(1-3x^2)
            \\
            P_3(x) &= a_1\left(x-\frac{5}{3}x^3\right)
        \end{aligned}

    となる。
