Problem 2.4
==================

第 `n` 定常状態の空間部分は，

.. math::
    \psi_n(x) = \sqrt{\frac{2}{a}}\sin\left(\frac{n\pi x}{a}\right)

であり，確率密度は `x=a/2` に関して対称なので，

.. math::
    \braket{x}  = \frac{a}{2}

となる。ここで， `\braket{x^2}` を計算するために，

.. math::
    b \coloneqq \frac{2n\pi}{a}

と置き，

.. math::
    \sin^2u = \frac{1-\cos(2u)}{2}

を用いると，

.. math::
    \begin{aligned}
        \braket{x^2} &= \frac{2}{a}\int_0^a x^2\sin^2\left(\frac{n\pi x}{a}\right)\,\dd x
        \\
        &= \frac{1}{a}\int_0^a x^2\,\dd x - \frac{1}{a}\int_0^a x^2\cos\left(bx\right)\,\dd x
    \end{aligned}

となる。ここで第二項の積分は

.. math::
    \int x^2\cos(bx)\,\dd x = \frac{x^2\sin(bx)}{b} + \frac{2x\cos(bx)}{b^2} - \frac{2\sin(bx)}{b^3} + C

となり， `ba=2m\pi` より `\sin(ba)=0` および `\cos(ba)=1` なので，

.. math::
    \braket{x^2} = a^2\left(\frac{1}{3} - \frac{1}{2n^2\pi^2}\right)

となる。

ここで， `\braket{p}` を計算するために，

.. math::
    \int_0^a \psi_n\psi'_n\,\dd x = \frac{1}{2}[\psi_n^2]_0^a = 0

となることを用いると，

.. math::
    \braket{p} = -i\hbar\int_0^a \psi_n\psi'_n\,\dd x = 0

となる。さらに，

.. math::
    -\hbar^2\psi_n'' = \left(\frac{n\pi}{a}\right)^2\psi_n

となるので，

.. math::
    \begin{aligned}
        \braket{p^2} &= \int_0^a \psi_n(-\hbar^2\psi_n'')\,\dd x
        \\
        &= \left(\frac{n\pi\hbar}{a}\right)^2\int_0^a \psi_n^2\,\dd x
        \\
        &= \left(\frac{n\pi\hbar}{a}\right)^2
    \end{aligned}

となる。したがって，

.. math::
    \begin{aligned}
        \sigma_x &= \sqrt{\braket{x^2}-\braket{x}^2} = a\sqrt{\frac{1}{12}-\frac{1}{2n^2\pi^2}}
        \\
        \sigma_p &= \sqrt{\braket{p^2}-\braket{p}^2} = \frac{n\pi\hbar}{a}
    \end{aligned}

となる。これらの積は，

.. math::
    \sigma_x\sigma_p = \hbar\sqrt{\frac{n^2\pi^2}{12}-\frac{1}{2}}

となる。ここで，

.. math::
    f(n) \coloneqq \frac{n^2\pi^2}{12}-\frac{1}{2}

は `f'(n)=n\pi^2/6 > 0` なので，不確定性の下限に最も近い状態は `n=1` のときであり，

.. math::
    \sigma_x\sigma_p = \frac{\hbar}{2}\sqrt{\frac{\pi^2-6}{3}} \approx 0.568\hbar > \frac{\hbar}{2}

となる。したがって，すべての定常状態は Heisenberg の不確定性原理を満たす。
