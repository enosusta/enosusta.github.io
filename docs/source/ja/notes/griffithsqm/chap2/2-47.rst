Problem 2.47
==================

a.  ポテンシャルは対称なので，基底状態 `\psi_1` は節を持たない偶関数，第一励起状態 `\psi_2` は原点に1つの節を持つ奇関数である。

    i.  `b=0` のとき，2つの井戸は繋がって幅 `2a` のひとつの井戸になるので， `\psi_1` は原点で最大となるような山を持ち， `\psi_2` は左右に符号の異なる2つの山を持つ。

    ii.  `b\approx a` のとき，中央に有限幅の障壁があるため，どちらの波動関数も左右の井戸内に2つの山を持つ。 `\psi_1` は左右に同符号の山を持ち， `\psi_2` は左右に符号の異なる山を持つ。

    iii.  `b\gg a` のとき，一方の井戸から他方の井戸から他方の井戸へのトンネル効果が非常に弱くなるので，それぞれの井戸の孤立した基底状態を `\phi_L,\phi_R` とすると，

        .. math::
            \psi_1 \approx \frac{\phi_L + \phi_R}{\sqrt{2}}, \quad
            \psi_2 \approx \frac{\phi_L - \phi_R}{\sqrt{2}}

        となる。

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt
        from scipy.linalg import eigh_tridiagonal

        a = 1.0
        V_0 = 20.0
        dx = 0.01

        def double_well_potential(x, b):
            tolerance = dx / 4.0
            in_left_well = (
                -b / 2.0 - a - tolerance <= x
            ) & (x <= -b / 2.0 + tolerance)
            in_right_well = (
                b / 2.0 - tolerance <= x
            ) & (x <= b / 2.0 + a + tolerance)
            return np.where(in_left_well | in_right_well, -V_0, 0.0)

        def two_lowest_states(b):
            domain_half_width = b / 2.0 + a + 2.5 * a
            number_of_points = round(2.0 * domain_half_width / dx) + 1
            x = np.linspace(
                -domain_half_width,
                domain_half_width,
                number_of_points,
            )
            actual_dx = x[1] - x[0]
            potential = double_well_potential(x, b)

            diagonal = 2.0 / actual_dx**2 + potential
            off_diagonal = -np.ones(len(x) - 1) / actual_dx**2
            _, states = eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, 1),
            )

            psi_1 = states[:, 0] + states[::-1, 0]
            psi_2 = states[:, 1] - states[::-1, 1]
            psi_1 /= np.sqrt(np.trapezoid(psi_1**2, x))
            psi_2 /= np.sqrt(np.trapezoid(psi_2**2, x))

            center = np.argmin(np.abs(x))
            right_well_center = np.argmin(np.abs(x - (b + a) / 2.0))
            if psi_1[center] < 0.0:
                psi_1 *= -1.0
            if psi_2[right_well_center] < 0.0:
                psi_2 *= -1.0

            return x, psi_1, psi_2

        cases = [
            (0.0, r"(i) $b=0$"),
            (a, r"(ii) $b=a$"),
            (4.0 * a, r"(iii) $b=4a\gg a$"),
        ]

        fig, axes = plt.subplots(
            1,
            3,
            figsize=(12, 4.0),
            sharey=True,
            constrained_layout=True,
        )

        for ax, (b, title) in zip(axes, cases):
            x, psi_1, psi_2 = two_lowest_states(b)

            ax.axvspan(-b / 2.0 - a, -b / 2.0, color="tab:gray", alpha=0.18)
            ax.axvspan(b / 2.0, b / 2.0 + a, color="tab:gray", alpha=0.18)
            ax.plot(x, psi_1, label=r"$\psi_1$")
            ax.plot(x, psi_2, linestyle="--", label=r"$\psi_2$")
            ax.axhline(0.0, color="black", linewidth=0.8)
            ax.axvline(0.0, color="tab:gray", linestyle=":", linewidth=0.8)
            ax.set_title(title)
            ax.set_xlabel(r"$x$")
            ax.set_xlim(x[0], x[-1])
            ax.grid(alpha=0.25)
            ax.legend()

        axes[0].set_ylabel(r"$\psi(x)$")
        plt.show()

b.  `b=0` では，基底状態は幅 `2a` 全体へ広がることができるため，運動エネルギーが小さくなる。間隔 `b` を広げると，基底状態の左右の山の重なりが小さくなり，運動エネルギーが増加する。そのため `E_1(b)` は増加する。一方で，奇関数の `\psi_2` は原点でゼロであるため，井戸を離すにつれて，原点付近で急激に符号を変える必要がなくなり，運動エネルギーが減少する。そのため `E_2(b)` は減少する。 `b\to\infty` では両方とも，ひとつの孤立した幅 `a` の井戸の基底状態のエネルギーに近づくので， `E_1(b)` と `E_2(b)` は同じ値に近づく。

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt
        from scipy.linalg import eigh_tridiagonal

        a = 1.0
        V_0 = 20.0
        dx = 0.01

        def double_well_potential(x, b):
            tolerance = dx / 4.0
            in_left_well = (
                -b / 2.0 - a - tolerance <= x
            ) & (x <= -b / 2.0 + tolerance)
            in_right_well = (
                b / 2.0 - tolerance <= x
            ) & (x <= b / 2.0 + a + tolerance)
            return np.where(in_left_well | in_right_well, -V_0, 0.0)

        def two_lowest_energies(b):
            domain_half_width = b / 2.0 + a + 2.5 * a
            number_of_points = round(2.0 * domain_half_width / dx) + 1
            x = np.linspace(
                -domain_half_width,
                domain_half_width,
                number_of_points,
            )
            actual_dx = x[1] - x[0]
            potential = double_well_potential(x, b)

            diagonal = 2.0 / actual_dx**2 + potential
            off_diagonal = -np.ones(len(x) - 1) / actual_dx**2
            return eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, 1),
                eigvals_only=True,
            )

        b_values = np.linspace(0.0, 5.0 * a, 101)
        energy_levels = np.array(
            [two_lowest_energies(b) for b in b_values]
        )

        plt.plot(b_values / a, energy_levels[:, 0], label=r"$E_1(b)$")
        plt.plot(b_values / a, energy_levels[:, 1], label=r"$E_2(b)$")
        plt.xlabel(r"$b/a$")
        plt.ylabel(r"$E\,/\,[\hbar^2/(2ma^2)]$")
        plt.xlim(b_values[0] / a, b_values[-1] / a)
        plt.grid(alpha=0.25)
        plt.legend()
        plt.show()

c.  電子が基底状態 `\psi_1` にあるとき，井戸の間隔が小さいほど `E_1` は小さいので，2つの井戸，すなわち2つの原子核を互いに引き寄せる傾向がある。
