2粒子系
==============

前章まで扱ってきた1粒子系の量子力学を2粒子系に拡張する。1個の粒子では `\Psi(\bm{r},t)` は空間座標 `\bm{r}` と時刻 `t` の関数である（ひとまずスピンは無視する）。2粒子系の状態は，粒子1の座標 `\bm{r}_1` と粒子2の座標 `\bm{r}_2` および時刻の関数

.. math::
    \Psi(\bm{r}_1,\bm{r}_2,t)

である。その時間発展は時間に依存する Schrödinger 方程式

.. math::
    i\hbar\pdv{\Psi}{t} = \hat{H}\Psi

によって決まる。ここで `\hat{H}` は系全体のハミルトニアン

.. math::
    \hat{H} = -\frac{\hbar^2}{2m_1}\nabla_1^2 - \frac{\hbar^2}{2m_2}\nabla_2^2 + V(\bm{r}_1,\bm{r}_2)

である。 `\nabla` の添え字は粒子1あるいは粒子2の座標についての微分を表す。確率解釈は明らかな方法で継承される：

.. math::
    |\Psi(\bm{r}_1,\bm{r}_2,t)|^2\,\dd^3 r_1\dd^3 r_2

は，粒子1を体積 `\dd^3 r_1` 内に，かつ粒子2を体積 `\dd^3 r_2` 内に見出す確率である。また `\Psi` は

.. math::
    \int |\Psi(\bm{r}_1,\bm{r}_2,t)|^2\,\dd^3 r_1\dd^3 r_2 = 1
    
のように規格化されていなければならない。時間に依存しないポテンシャルについては，変数分離解

.. math::
    \Psi(\bm{r}_1,\bm{r}_2,t) = \psi(\bm{r}_1,\bm{r}_2)e^{-iEt/\hbar}

によって全ての解を得ることができる。ここで `\psi` は時間に依存しない Schrödinger 方程式

.. math::
    -\frac{\hbar^2}{2m_1}\nabla_1^2\psi - \frac{\hbar^2}{2m_2}\nabla_2^2\psi + V\psi = E\psi

の解であり， `E` は系の全エネルギーである。一般にこれを解くのは難しいが次の2つの特別な場合には1粒子の問題に帰着する：

1.  相互作用しない粒子の場合：この場合，全ポテンシャルエネルギーは

    .. math::
        V(\bm{r}_1,\bm{r}_2) = V_1(\bm{r}_1) + V_2(\bm{r}_2)

    となり，時間に依存しない Schrödinger 方程式は変数分離解

    .. math::
        \psi(\bm{r}_1,\bm{r}_2) = \psi_a(\bm{r}_1)\psi_b(\bm{r}_2)

    によって解くことができる。実際にこれを代入し `\psi(\bm{r}_1,\bm{r}_2)` で割り，整理すると， `\psi_a(\bm{r}_1)` と `\psi_b(\bm{r}_2)` はそれぞれ1粒子の時間に依存しない Schrödinger 方程式

    .. math::
        \begin{aligned}
            -\frac{\hbar^2}{2m_1}\nabla_1^2\psi_a(\bm{r}_1) + V_1\psi_a(\bm{r}_1) &= E_a\psi_a(\bm{r}_1)
            \\
            -\frac{\hbar^2}{2m_2}\nabla_2^2\psi_b(\bm{r}_2) + V_2\psi_b(\bm{r}_2) &= E_b\psi_b(\bm{r}_2)
        \end{aligned}

    を満たし， `E=E_a + E_b` となる。この場合，2粒子波動関数は1粒子波動関数の単純な積

    .. math::
        \begin{aligned}
            \Psi(\bm{r}_1,\bm{r}_2,t) &= \psi_a(\bm{r}_1)\psi_b(\bm{r}_2)e^{-i(E_a+E_b)t/\hbar}
            \\
            &= (\psi_a(\bm{r}_1)e^{-iE_at/\hbar})(\psi_b(\bm{r}_2)e^{-iE_bt/\hbar})
            \\
            &= \Psi_a(\bm{r}_1,t)\Psi_b(\bm{r}_2,t)
        \end{aligned}

    であり，粒子1は状態 `\Psi_a` にあり，粒子2は状態 `\Psi_b` にあると言うことに意味がある。しかし，このような解の任意の線形結合も時間に依存する Schrödinger 方程式の解である。例えば，

    .. math::
        \Psi(\bm{r}_1,\bm{r}_2,t) = \frac{3}{5}\Psi_a(\bm{r}_1,t)\Psi_b(\bm{r}_2,t) + \frac{4}{5}\Psi_c(\bm{r}_1,t)\Psi_d(\bm{r}_2,t)

    この場合，粒子1の状態は粒子2の状態に依存し，逆もまた然りである。粒子1のエネルギーを測定すると， `E_a` を確率 `9/25` で得るが，そのとき粒子2のエネルギーは確実に `E_b` と決まる。このような2つの粒子は **エンタングルしている** という。つまり，エンタングル状態とは，1粒子状態の積として書けない状態である。

2.  中心力ポテンシャルの場合：この場合，全ポテンシャルエネルギーは

    .. math::
        V(\bm{r}_1,\bm{r}_2) = V(|\bm{r}_1-\bm{r}_2|)

    となる。陽子の運動を考慮すれば，水素原子がこの例である。この場合，古典力学の場合をまったく同様に，2体問題は等価な1体問題に帰着する。

しかし，一般には2粒子系の解析は複雑になる。例えばヘリウム原子中の2つの電子を考えると，各々が原子核（電荷 `2e` ）から Coulomb 引力を受けると同時に，互いに Coulomb 斥力で反発する：

.. math::
    V(\bm{r}_1,\bm{r}_2) = \frac{1}{4\pi\epsilon_0}\left(-\frac{2e^2}{|\bm{r}_1|} - \frac{2e^2}{|\bm{r}_2|} + \frac{e^2}{|\bm{r}_1-\bm{r}_2|}\right)

ボソンとフェルミオン
--------------------------

さて，相互作用しない2つの粒子があり，粒子1は状態 `\psi_a(\bm{r})` に，粒子2は状態 `\psi_b(\bm{r})` にあるとする。この場合， `\psi(\bm{r}_1,\bm{r}_2)` は積

.. math::
    \psi(\bm{r}_1,\bm{r}_2) = \psi_a(\bm{r}_1)\psi_b(\bm{r}_2)

である。しかし，これは粒子が区別できることを仮定している。もしそうでなければ，粒子1が状態 `\psi_a` にあり，粒子2が状態 `\psi_b` にあるという主張に意味がない。量子力学は原理的に識別不可能な粒子の存在を記述できる。つまり，どちらの粒子がどちらの状態にあるかについて何も決めない波動関数を構成すればよい。これには2つの方法がある：

.. math::
    \psi_{\pm}(\bm{r}_1,\bm{r}_2) = A[\psi_a(\bm{r}_1)\psi_b(\bm{r}_2) \pm \psi_b(\bm{r}_1)\psi_a(\bm{r}_2)]

理論はこの2種類の同種粒子を許す。正符号の粒子を **ボソン** と呼び，負符号の粒子を **フェルミオン** と呼ぶ。ボソン状態は位置の交換に対して対称であり，フェルミオン状態は反対称である。実は，

.. math::
    \begin{aligned}
        &\text{all particles with integer spin are bosons}
        \\
        &\text{all particles with half-integer spin are fermions}
    \end{aligned}

であることが知られている。このスピン統計定理は相対論的量子力学では証明できるが，非相対論的量子力学では，いまのところ単に公理として採用する。

特に，2つのフェルミオンは同じ状態を占めることができない。なぜなら，もし `\psi_a=\psi_b` ならば，

.. math::
    \psi_{-}(\bm{r}_1,\bm{r}_2) = A[\psi_a(\bm{r}_1)\psi_a(\bm{r}_2) - \psi_a(\bm{r}_1)\psi_a(\bm{r}_2)] = 0

となるからである。これが **Pauli の排他原理** である。ここまでの話はスピンを無視していることに注意する。後でスピン変数を導入しより一般的に議論する。

交換力
----------------

同種粒子という概念が実際にどのような影響を及ぼすか理解するために，2粒子間の距離の2乗の期待値

.. math::
    \braket{(x_1-x_2)^2} = \braket{x_1^2} + \braket{x_2^2} - 2\braket{x_1x_2}

を計算する。簡単のため，1次元系を考え，一方の粒子が状態 `\psi_a(x)` にあり，他方の粒子が状態 `\psi_b(x)` にあって，これら2つの状態は直交規格化されているとする。もし2粒子が区別可能で，粒子1が状態 `\psi_a` にあるなら，合成波動関数は

.. math::
    \psi(x_1,x_2) = \psi_a(x_1)\psi_b(x_2)

である。ボソンなら

.. math::
    \psi_{+}(x_1,x_2) = \frac{1}{\sqrt{2}}[\psi_a(x_1)\psi_b(x_2) + \psi_b(x_1)\psi_a(x_2)]

フェルミオンなら

.. math::
    \psi_{-}(x_1,x_2) = \frac{1}{\sqrt{2}}[\psi_a(x_1)\psi_b(x_2) - \psi_b(x_1)\psi_a(x_2)]

である。

1.  区別可能な場合：

    .. math::
        \begin{aligned}
            \braket{x_1^2} &= \int x_1^2|\psi_a(x_1)|^2\,\dd x_1\int|\psi_b(x_2)|^2\,\dd x_2 = \braket{x^2}_a
            \\
            \braket{x_2^2} &= \int|\psi_a(x_1)|^2\,\dd x_1\int x_2^2|\psi_b(x_2)|^2\,\dd x_2 = \braket{x^2}_b
            \\
            \braket{x_1x_2} &= \int x_1|\psi_a(x_1)|^2\,\dd x_1\int x_2|\psi_b(x_2)|^2\,\dd x_2 = \braket{x}_a\braket{x}_b
        \end{aligned}

    となるので，

    .. math::
        \braket{(x_1-x_2)^2} = \braket{x^2}_a + \braket{x^2}_b - 2\braket{x}_a\braket{x}_b

2.  区別不可能な場合：

    .. math::
        \begin{aligned}
            \braket{x_1^2} &= \frac{1}{2}\Bigg[ \int x_1^2|\psi_a(x_1)|^2\,\dd x_1\int |\psi_b(x_2)|^2\,\dd x_2
            \\
            &\quad +\int x_1^2|\psi_b(x_1)|^2\,\dd x_1\int |\psi_a(x_2)|^2\,\dd x_2
            \\
            &\quad \pm\int x_1^2\psi_a(x_1)^*\psi_b(x_1)\,\dd x_1\int \psi_b(x_2)^*\psi_a(x_2)\,\dd x_2
            \\
            &\quad \pm\int x_1^2\psi_b(x_1)^*\psi_a(x_1)\,\dd x_1\int\psi_a(x_2)^*\psi_b(x_2)\,\dd x_2 \Bigg]
            \\
            &= \frac{1}{2}[\braket{x^2}_a + \braket{x^2}_b \pm0\pm0] = \frac{1}{2}[\braket{x^2}_a + \braket{x^2}_b]
            \\
            \braket{x_2^2} &= \frac{1}{2}[\braket{x^2}_a + \braket{x^2}_b]
        \end{aligned}

    となる。区別できないので `\braket{x_2^2} = \braket{x_1^2}` である。また，

    .. math::
        \begin{aligned}
            \braket{x_1x_2} &= \frac{1}{2}\Bigg[ \int x_1|\psi_a(x_1)|^2\,\dd x_1\int x_2|\psi_b(x_2)|^2\,\dd x_2
            \\
            &\quad +\int x_1|\psi_b(x_1)|^2\,\dd x_1\int x_2|\psi_a(x_2)|^2\,\dd x_2
            \\
            &\quad \pm\int x_1\psi_a(x_1)^*\psi_b(x_1)\,\dd x_1\int x_2\psi_b(x_2)^*\psi_a(x_2)\,\dd x_2
            \\
            &\quad \pm\int x_1\psi_b(x_1)^*\psi_a(x_1)\,\dd x_1\int x_2\psi_a(x_2)^*\psi_b(x_2)\,\dd x_2 \Bigg]
            \\
            &= \frac{1}{2}[\braket{x}_a\braket{x}_b + \braket{x}_b\braket{x}_a \pm\braket{x}_{ab}\braket{x}_{ba} \pm\braket{x}_{ba}\braket{x}_{ab}\Bigg]
            \\
            &= \braket{x}_a\braket{x}_b \pm |\braket{x}_{ab}|^2
        \end{aligned}

    ここで

    .. math::
        \braket{x}_{ab} \coloneqq \int x\psi_a(x)^*\psi_b(x)\,\dd x

    である。したがって，

    .. math::
        \braket{(x_1-x_2)^2}_\pm = \braket{x^2}_a + \braket{x^2}_b - 2\braket{x}_a\braket{x}_b \mp 2|\braket{x}_{ab}|^2

2つの結果を比較すると違いは最後の項にある：

.. math::
    \braket{(\Delta x)^2}_\pm = \braket{(\Delta x)^2}_\text{d} \mp 2|\braket{x}_{ab}|^2

つまり，区別可能な場合と比べて，ボソンはいくらか互いに近づき，フェルミオンはいくらか互いに遠ざかる傾向がある。この傾向は交換力と呼ばれるが，実際には力ではない。2つの波動関数が実際に重なり合わない限り `\braket{x}_{ab} = 0` である。したがって，2つの粒子が互いに遠く離れている場合には，計算上は同種粒子を区別可能な粒子とみなしてよい [#]_ 。この現象は古典的対応物をもたない純粋な量子力学的な現象である。

完全な2粒子状態
----------------------

ここで，これまで無視してきたスピンを導入する。例えば電子の完全な状態は，その位置波動関数だけではなく，スピンの向きを記述するスピン波動関数も含む [#]_ ：

.. math::
    \psi(\bm{r})\chi

2粒子状態は

.. math::
    \psi(\bm{r}_1,\bm{r}_2)\chi(1,2)

である。粒子の交換に関して反対称でなければならないのは，空間部分だけではなく全体である：

.. math::
    \psi(\bm{r}_1,\bm{r}_2)\chi(1,2) = -\psi(\bm{r}_2,\bm{r}_1)\chi(2,1)

ここで前章の合成スピン状態の議論を振り返ると，一重項の場合はスピン状態は反対称であり，対称な空間波動関数と組み合わせなければならない。三重項の場合はスピン状態は対称であり，反対称な空間波動関数と組み合わせなければならない。したがって，Pauli の排他原理は，2つの電子のスピンが一重項状態にある限り，同じ位置状態にあることが許される。

一般化された対称化原理
------------------------------

これまで粒子は相互作用せず，スピンと位置は相互作用せず，ポテンシャルは時間に依存しないと仮定してきた。しかしボソンとフェルミオンに対する基本的な対称化・反対称化の要請ははるかに一般的な形で述べることができる。

2つの粒子を交換する交換演算子 `\hat{P}` を定義する：

.. math::
    \hat{P}\ket{1,2} = \ket{2,1}

明らかに `\hat{P}^2 = 1` であり，したがって `\hat{P}` の固有値は `\pm 1` である。さて，2粒子が同一ならハミルトニアンはそれらを同じように扱わなければならない。すなわち `m_1=m_2` かつ `V(\bm{r}_1,\bm{r}_2,t) = V(\bm{r}_2,\bm{r}_1,t)` である。したがって，ハミルトニアンは交換演算子と可換である：

.. math::
    [\hat{P}, \hat{H}] = 0

したがって，

.. math::
    \dv{\braket{\hat{P}}}{t} = 0

となる。つまり系が `\hat{P}` の固有状態から出発すれば，その後も `\hat{P}` の固有値は変化しない。特に対称化公理は，同種粒子に対して

.. math::
    \ket{1,2} = \pm\ket{2,1}

を満たすことを要請する [#]_ 。 `n` 種の同種粒子があるなら，状態は任意の2粒子の交換に対して対称あるいは反対称でなければならない：

.. math::
    \boxed{\ket{1,2,\ldots,i,\ldots,j,\ldots,n} = \pm\ket{1,2,\ldots,j,\ldots,i,\ldots,n}}

これが一般的な主張であり，波動関数に対する主張はこの特別な場合である。

.. [#] 実際，化学者が研究を進められるのはこのためである。原理的には，宇宙のすべての電子が波動関数の反対称化を通じて他のすべての電子と関係づいており，これが計算に影響するならば，それらすべてを扱わずに，どのひとつについても扱えないだろう。

.. [#] スピンと位置の間に相互作用がなければ，状態がスピン座標と空間座標について分離可能だと仮定してよい。これはスピン上向きを得る確率が粒子の位置に依存しない，というだけのことである。

.. [#] 対称化の要請は `\hat{P}` と `\hat{H}` が交換することから導かれるわけではない。ハミルトニアンが対称であっても，状態が（反）対称である必要の無い区別可能な場合が存在する。これは対称化の要請より弱い主張である。
