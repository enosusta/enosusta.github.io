原子
===========

原子番号 `Z` の中性原子は，電荷 `Ze` を持つ重い原子核と，その周囲にある `Z` 個の電子（質量 `m` ，電荷 `-e` ）から成る。この系のハミルトニアンは [#]_ ，

.. math::
    \hat{H} = \sum_{j=1}^{Z}\left[-\frac{\hbar^2}{2m}\nabla_j^2 - \left(\frac{1}{4\pi\epsilon_0}\right)\frac{Ze^2}{r_j}\right] + \frac{1}{2}\left(\frac{1}{4\pi\epsilon_0}\right)\sum_{j\neq k}^{Z}\frac{e^2}{|\bm{r}_j-\bm{r}_k|}

第一項の括弧内は，原子核の電場中にある第 `j` 電子の運動エネルギーとポテンシャルエネルギーを表す。第二項の和は，電子間の相互作用に伴うポテンシャルエネルギーである。前に付く係数 `1/2` は和が各対を二重に数えることを補正する。問題は時間に依存しない Schrödinger 方程式

.. math::
    \hat{H}\psi = E\psi

を

.. math::
    \psi(\bm{r}_1,\bm{r}_2,\ldots,\bm{r}_Z)

について解くことである。

しかし，残念ながら，これは最も単純な水素原子の場合（ `Z=1` ）を除けば厳密には解けない（少なくともこれまで解かれていない）。実際には，巧妙な近似に頼らなければならない。ここでは電子間の相互作用を完全に無視して得られる解の定性的な特徴だけを述べる。

ヘリウム
-------------

水素原子の次に単純な原子はヘリウム（ `Z=2` ）である。ハミルトニアン

.. math::
    \hat{H} = \left[-\frac{\hbar^2}{2m}\nabla_1^2 - \frac{1}{4\pi\epsilon_0}\frac{2e^2}{r_1}\right] + \left[-\frac{\hbar^2}{2m}\nabla_2^2 - \frac{1}{4\pi\epsilon_0}\frac{2e^2}{r_2}\right] + \left(\frac{1}{4\pi\epsilon_0}\right)\frac{e^2}{|\bm{r}_1-\bm{r}_2|}

は電子1と電子2にひとつずつ対応する2つのハミルトニアンと，2電子間の相互作用を記述する項から成る。最後の項を無視すれば，時間に依存しない Schrödinger 方程式は分離し，解は水素原子の波動関数の積として書ける：

.. math::
    \psi(\bm{r}_1,\bm{r}_2) = \psi_{nlm}(\bm{r}_1)\psi_{n'l'm'}(\bm{r}_2)

ただし Bohr 半径は半分に，Bohr エネルギーは4倍になる。全エネルギーは

.. math::
    E = 4(E_n + E_{n'}),\quad E_n = -13.6/n^2\,\mathrm{eV}

となる。特に基底状態は

.. math::
    \psi_0(\bm{r}_1,\bm{r}_2) = \psi_{100}(\bm{r}_1)\psi_{100}(\bm{r}_2) = \frac{8}{\pi a^3}e^{-2(r_1+r_2)/a}

であり，そのエネルギーは

.. math::
    E_0 = 8(-13.6\,\mathrm{eV}) = -109\,\mathrm{eV}

となる。 `\psi_0` は対称関数なので，スピン状態は反対称でなければならない。したがって，ヘリウムの基底状態は，スピンが「反対向きに整列」した一重項状態であるはずである。ヘリウムの実際の基底状態は確かに一重項状態であるが，実験的に決定されたエネルギーは `-78.975\,\mathrm{eV}` であり，あまり一致していない。無視した電子間の相互作用は全エネルギーを `-109\,\mathrm{eV}` から `-79\,\mathrm{ev}` まで押し上げるらしい。

ヘリウムの励起状態は，一方の電子が水素型の基底状態にあり，他方が基底状態にあるものからなる：

.. math::
    \psi_{nlm}\psi_{100}

実は，両方の電子を励起状態へ置こうとすると，一方はただちに基底状態へ落ち，他方を連続状態（ `E>0` ）へたたき出すのに十分なエネルギーを放出する。その結果，ヘリウムイオン（ `\mathrm{He}^+` ）と自由電子が残る。通常の方法で対称な組み合わせと反対称な組み合わせの両方を構成できる。前者は反対称なスピン配置（一重項）と組になり，パラヘリウムと呼ばれる。後者は対称なスピン配置（三重項）と組になり，オルトヘリウムと呼ばれる。基底状態はパラヘリウムである。対称な空間状態は電子同士をより近づける傾向があるので，パラヘリウムでは相互作用エネルギーがより高くなると予想され，実際にそうなる。

周期表
----------------

より重い原子の基底状態の電子配置も，ほぼ同じ方法で構成することができる。電子間の相互作用を完全に無視すれば，個々の電子は，電荷 `Ze` の原子核による Coulomb ポテンシャル中の1粒子水素型状態 `(n,l,m)` を占める。この状態を **軌道** と呼ぶ。電子がボソンなら，すべてが基底状態 `(1,0,0)` へ落ち込んでしまうが，電子はフェルミオンなので，任意のひとつの軌道を占められるのは2つだけ（正確には一重項状態）である。与えられた `n` に対して同じエネルギー `E_n` を持つ水素型波動関数は `n^2` 個ある。したがって， `n=1` の殻には2電子の余地があり， `n=2` の殻には8電子， `n=3` の殻には `18` 電子が入り，一般に第 `n` 殻には `2n^2` 個の電子を収容できる。定性的には，周期表の横の行は各殻を満たすことに対応する。しかし実際は電子間の相互作用があるため，横の行の数は狂う。

ヘリウムでは `n=1` 殻が満たされるので，次の原子リチウム（ `Z=3` ）は1電子を `n=2` 殻へ入れなければならない。ところで， `n=2` では `l=0` または `l=1` が可能である。3つ目の電子はどちらを選ぶだろうか。電子間の相互作用がなければ，両者のエネルギーは同じである。しかし，電子間の相互作用の効果は，次の理由から最小の `l` を有利にする。角運動量は電子を外側へ押し出す傾向があり，電子が外へ行くほど，内側の電子が原子核をいっそう効果的に遮蔽する。したがって，同じ殻の中では，エネルギーが最も低い状態は `l=0` であり， `l` が大きくなるにつれてエネルギーは増加する。よって，リチウムの3つ目の電子は軌道 `(2,0,0)` を占める。次の原子の新たな電子もこの状態に入る。しかしその次の原子の新たな電子は `l=1` も使わなければならない。

これを続けていくとネオン（ `Z=10` ）に達し，そこで `n=2` 殻が満たされる。次に周期表の次の行へ進み， `n=3` 殻を満たし始める。しかし，アルゴン（ `Z=18` ）の次には `n=3,l=2` の原子が10個来るはずであるが，遮蔽効果が極めて強いため次の殻と重なってしまい，カリウム（ `Z=19` ）とカルシウム（ `Z=20` ）の新たな電子は `n=3,l=2` より `n=4,l=0` を選ぶ。その後，取り残されていた `n=3,l=2` を再び拾い上げ， `n=4,l=1` へ進む。詳細はここでは述べないが，このように周期表が構成されている。

.. [#] ここでは原子核は静止しているものと仮定している。換算質量を用いて原子核の運動を考慮する方法が使えるのは2体問題だけである。幸いなことに，原子核は電子よりはるかに重いため，水素の場合でさえ補正は極めて小さい。電子スピンに伴う磁気的な相互作用や相対論的な補正，原子核の有限な大きさに由来する興味深い効果もあるが，いずれも微小な補正である。
