固体
===========

固体状態は，各原子の最外殻にある，ゆるく束縛された価電子のうちいくつかが離脱して物質全体を動き回り，もはや特定の「親」原子核の Coulomb 場だけでなく，結晶格子全体のポテンシャルを受ける。ここでは極めて原始的な2つの模型を調べる。1つ目は Sommerfeld の自由電子気体で，閉じ込める境界以外のすべての力を無視し，動き回る電子を箱の中の自由粒子として扱う。2つ目は Bloch の理論で，規則正しく並んだ正電荷を持つ原子核による引力を表す周期ポテンシャルを導入する。これらの模型は固体物理学の第一歩にすぎないが，「固体性」を説明するうえで Pauli の排他原理の重要性を明らかにし，導体・半導体・絶縁体の性質について示唆に富む洞察を与える。

自由電子気体
----------------

物体が，辺の長さ `l_x,l_y,l_z` の直方体であり，内部の電子は壁を除いて全く力を受けないとする：

.. math::
    V(x,y,z) = \begin{cases}
        0 & (0<x<l_x, 0<y<l_y, 0<z<l_z)
        \\
        \infty & (\text{otherwise})
    \end{cases}

時間に依存しない Schrödinger 方程式

.. math::
    -\frac{\hbar^2}{2m}\nabla^2\psi = E\psi

は Descartes 座標で

.. math::
    \psi(x,y,z) = X(x)Y(y)Z(z)

と分離でき，それぞれ

.. math::
    -\frac{\hbar^2}{2m}\dv{^2X}{x^2} = E_x X,\quad
    -\frac{\hbar^2}{2m}\dv{^2Y}{y^2} = E_y Y,\quad
    -\frac{\hbar^2}{2m}\dv{^2Z}{z^2} = E_z Z

を満たし， `E=E_x+E_y+E_z` である。ここで，

.. math::
    k_x \coloneqq \frac{\sqrt{2mE_x}}{\hbar},\quad
    k_y \coloneqq \frac{\sqrt{2mE_y}}{\hbar},\quad
    k_z \coloneqq \frac{\sqrt{2mE_z}}{\hbar}

を置けば，一般解は，

.. math::
    \begin{aligned}
        X(x) &= A_x\sin(k_x x) + B_x\cos(k_x x)
        \\
        Y(y) &= A_y\sin(k_y y) + B_y\cos(k_y y)
        \\
        Z(z) &= A_z\sin(k_z z) + B_z\cos(k_z z)
    \end{aligned}

となる。境界条件 `X(0)=Y(0)=Z(0)=0` より `B_x=B_y=B_z=0` であり，さらに `X(l_x)=Y(l_y)=Z(l_z)=0` より

.. math::
    k_x l_x = n_x\pi,\quad
    k_y l_y = n_y\pi,\quad
    k_z l_z = n_z\pi

となる。ここで

.. math::
    n_x,n_y,n_z = 1,2,3,\dots

である。規格化された波動関数は

.. math::
    \psi_{n_x n_y n_z}(x,y,z) = \sqrt{\frac{8}{l_x l_y l_z}}\sin\left(\frac{n_x\pi}{l_x}x\right)\sin\left(\frac{n_y\pi}{l_y}y\right)\sin\left(\frac{n_z\pi}{l_z}z\right)

で，許されるエネルギーは

.. math::
    E_{n_x n_y n_z} = \frac{\hbar^2\pi^2}{2m}\left(\frac{n_x^2}{l_x^2} + \frac{n_y^2}{l_y^2} + \frac{n_z^2}{l_z^2}\right) = \frac{\hbar^2k^2}{2m}

である。ここで `k` は波数ベクトル `\bm{k} = (k_x,k_y,k_z)` の大きさである。

`\bm{k}` 空間を考え，

.. math::
    k_x = \frac{\pi}{l_x},\frac{2\pi}{l_x},\ldots, \quad
    k_y = \frac{\pi}{l_y},\frac{2\pi}{l_y},\ldots, \quad
    k_z = \frac{\pi}{l_z},\frac{2\pi}{l_z},\ldots

の位置に平面を書いたとする。各交点は，異なる定常状態を表す。この格子の各ブロック，したがって各状態は `\bm{k}` 空間で体積

.. math::
    \frac{\pi^3}{l_x l_y l_z} = \frac{\pi^3}{V}

を占める。ここで `V\coloneqq l_x l_y l_z` は物体そのものの体積である。

物体が `N` 個の原子を含み，各原子が `d` 個の自由電子を持つとする。実際の物体では `N` は Avogadro 数程度という莫大な数であるのに対し， `d` は通常数個といった小さな数である。電子がボソンなら，すべて基底状態 `\psi_{111}` へ落ち着くだろう [#]_ 。しかし実際には電子はフェルミオンなので，任意の状態を占められるのは2電子だけである。この電子は `\bm{k}` 空間内の球の `1/8` を満たすことになる [#]_ 。その半径 `k_F` は電子一対ごとに体積 `\pi^3/V` を占めるという事実から決まる：

.. math::
    \frac{1}{8}\left(\frac{4\pi k_F^3}{3}\right) = \frac{N d}{2}\left(\frac{\pi^3}{V}\right)

したがって，

.. math::
    k_F = (3\rho\pi^2)^{1/3},\quad \rho \coloneqq \frac{N d}{V}

となる。ここで  `\rho` は自由電子密度（単位体積あたりの自由電子数）である。

`\bm{k}` 空間において，占有状態と非占有状態を隔てる境界を **Fermi 面** と呼ぶ。対応するエネルギーを **Fermi エネルギー** `E_F` と呼び，自由電子気体では

.. math::
    E_F = \frac{\hbar^2}{2m}(3\rho\pi^2)^{2/3}

となる。自由電子気体の全エネルギーは次のように計算できる：厚さ `\dd k` の球殻が占める体積は

.. math::
    \frac{1}{8}(4\pi k^2)\,\dd k

なので，球殻の中にある電子状態の数は

.. math::
    \frac{2[(1/2)\pi k^2\,\dd k]}{\pi^3/V} = \frac{V}{\pi^2}k^2\,\dd k

となる。各状態はエネルギー `\hbar^2k^2/2m` を持つので，球殻の中の電子のエネルギーは

.. math::
    \dd E = \frac{\hbar^2k^2}{2m}\frac{V}{\pi^2}k^2\,\dd k

となる。したがって，満たされた全状態の全エネルギーは

.. math::
    E_\text{tot} = \frac{\hbar^2 V}{2\pi^2 m}\int_0^{k_F}k^4\,\dd k = \frac{\hbar^2 k_F^5 V}{10\pi^2 m} = \frac{\hbar^2(3\pi^2 Nd)^{5/3}}{10\pi^2 m}V^{-2/3}

となる。このエネルギーは通常の気体の内部熱エネルギー `U` とかなり似た役割を果たす。特にこれは壁に圧力を及ぼす。実際，箱が `\dd V` だけ膨張すると，全エネルギーは

.. math::
    \dd E_\text{tot} = -\frac{2}{3}\frac{\hbar^2(3\pi^2 Nd)^{5/3}}{10\pi^2 m}V^{-5/3}\,\dd V = -\frac{2}{3}E_{\text{tot}}\frac{\dd V}{V}

だけ減少し，これは量子圧力 `P` が外部になした仕事 `\dd W = P\,\dd V` として現れる。したがって，

.. math::
    P = \frac{2}{3}\frac{E_\text{tot}}{V} = \frac{2}{3}\frac{\hbar^2k_F^5}{10\pi^2 m} = \frac{(3\pi^2)^{2/3}\hbar^2}{5m}\rho^{5/3}

となる。これで，冷たい固体がなぜ単純に潰れないのかという問題に対する，解答が得られる。電子間の相互作用とも熱運動とも無関係で，純粋に量子力学的な安定化をもたらす内部圧力が存在するのである。それは究極的にはフェルミオンの波動関数に対する反対称化の要請に起因する。この圧力は縮退圧と呼ばれることもあるが，「排他圧」という名称の方が良いかもしれない。

バンド構造
-----------------

次に，規則正しく並んだ原子核が電子へ及ぼす力を取り入れて，自由電子模型を改良する。固体の定性的な振る舞いは，このポテンシャルが周期的であるという事実だけによって驚くほど左右される。可能な限り単純にするために，等間隔のデルタ関数の山からなる1次元の Dirac 櫛を考える [#]_ 。しかし，解析に入る前に周期ポテンシャルについての一般的な定理（証明は次章で述べる）を述べる。

周期ポテンシャルとは，ある一定の距離 `a` ごとに繰り返すポテンシャルである：

.. math::
    V(x+a) = V(x)

このとき以下の **Bloch の定理** が成り立つ：

.. important::
    周期ポテンシャルに対する時間に依存しない Schrödinger 方程式の解

    .. math::
        -\frac{\hbar^2}{2m}\dv{^2\psi}{x^2} + V(x)\psi = E\psi

    の解は，ある実数 `q` について

    .. math::
        \psi(x+a) = e^{iqa}\psi(x)

    という条件を満たすように選べる。

したがって `\psi(x)` そのものは周期的でないが， `|\psi(x)|^2` は周期的である：

.. math::
    |\psi(x+a)|^2 = |\psi(x)|^2

もちろん，実際の固体は無限に続くことはなく，端では `V(x)` の周期性が崩れて Bloch の定理を適用できなくなる。しかし，Avogadro 数程度の原子を含む巨視的な結晶では，端の効果が内部深くの電子の振る舞いに影響を及ぼすとは通常考えられない。そこで，Bloch の定理を使えるようにするために， `x` 軸を円上に丸めて，多数の周期 `N\approx 10^{23}` の後で末尾を先頭へつなぐ。つまり，形式的には境界条件

.. math::
    \psi(x+Na) = \psi(x)

を課す。そうすると Bloch の定理により，

.. math::
    e^{iNqa}\psi(x) = \psi(x)

となるので， `e^{iNqa} = 1` すなわち `Nqa = 2\pi n` であり，したがって，

.. math::
    q = \frac{2\pi n}{Na},\quad n=0,\pm 1,\pm 2,\dots

となる。Bloch の定理のご利益は，ひとつの単位胞の内部で時間に依存しない Schrödinger 方程式を解けばよいという点にある。

さて本題に戻って，ポテンシャルが Dirac 櫛である場合を考える：

.. math::
    V(x) = \alpha\sum_{j=0}^{N-1}\delta(x-ja)

単位胞 `0 < x < a` の領域ではポテンシャルはゼロなので，

.. math::
    -\frac{\hbar^2}{2m}\dv{^2\psi}{x^2} = E\psi

すなわち

.. math::
    \dv{^2\psi}{x^2} = -k^2\psi,\quad k\coloneqq \frac{\sqrt{2mE}}{\hbar}

一般解は

.. math::
    \psi(x) = A\sin(kx) + B\cos(kx)\quad (0<x<a)

Bloch の定理より，原点のすぐ左にある単位胞内の波動関数は

.. math::
    \psi(x) = e^{-iqa}\{A\sin[k(x+a)] + B\cos[k(x+a)]\}\quad (-a<x<0)

`x=0` で `\psi` は連続でなければならないので，

.. math::
    B = e^{-iqa}[A\sin(ka) + B\cos(ka)]

すなわち，

.. math::
    A\sin(ka) = [e^{iqa}-\cos(ka)]B

一方で導関数はデルタ関数の係数 `\alpha` に比例する不連続性を持つので，

.. math::
    kA - e^{-iqa}k[A\cos(ka)-B\sin(ka)] = \frac{2m\alpha}{\hbar^2}B

となる。ここで `kB` を消去すると，

.. math::
    [e^{iqa}-\cos(ka)][1-e^{-iqa}\cos(ka)] + e^{-iqa}\sin^2(ka) = \frac{2m\alpha}{\hbar^2k}\sin(ka)

となる。これは

.. math::
    \cos(qa) = \cos(ka) + \frac{m\alpha}{\hbar^2k}\sin(ka)

となる。これが基本的な結果であり，他のすべてはここから従う。特に `k` の可能な値，したがって許されるエネルギーを決定する。記法を簡単にするために

.. math::
    z \coloneqq ka,\quad \beta \coloneqq \frac{m\alpha a}{\hbar^2}

と置くと，右辺は

.. math::
    f(z) \coloneqq \cos(z) + \beta\frac{\sin(z)}{z}

と書ける。定数 `\beta` はデルタ関数の大きさを表す無次元の量である。例えば `\beta=10` の場合の `f(z)` のグラフを書いてみると， `f(z)` が `(-1,+1)` の外へはみ出す領域があることが分かる。そのような領域では，もちろん `|\cos(qa)|` は `1` を超えられないので，境界条件は解けない。これらの `z` の隙間は禁制エネルギーを表し，許容エネルギーの **バンド** によって隔てられている。与えられたバンド内では，事実上どのエネルギーも許される。なぜなら `qa = 2\pi n/N` であり， `N` は莫大な数， `n` は任意の整数だからである。

ここまでは，ポテンシャル中に電子を1つだけ入れた。実際には `Nd` 個の電子がある。Pauli の排他原理より，1つの空間状態を占められるのは2電子だけなので， `d=1` なら第1バンドを半分まで満たし， `d=2` なら第1バンドを完全に満たし， `d=3` なら第2バンドを半分まで満たす，という具合になる。3次元でより現実的なポテンシャルを用いると，バンド構造をもっと複雑になりうる。しかし禁制ギャップによって隔てられた許容バンドの存在は変わらない [#]_ 。

さて，最上位のバンドが部分的にしか満たされていなければ，電子を次の許容準位へ励起するのに必要なエネルギーはごくわずかであり，そのような物質は **導体** （金属）となる。一方で，最上位バンドが完全に満たされていれば，電子は禁制領域を飛び越えなければならないので，励起には比較的大きなエネルギーが必要となる。そのような物質は通常 **絶縁体** である。ただし，ギャップがかなり狭く，温度が十分高ければ，ランダムな熱エネルギーによって電子が障壁を越え，物資は **半導体** になる [#]_ 。自由電子模型では，許容エネルギーのスペクトルに大きなギャップがないので，すべての固体が金属になるはずである。自然界の固体が示す広い範囲の電気伝導度を説明するには，バンド理論が必要不可欠である。

.. [#] 固体を基底状態から持ち上げるほどの，無視できない熱励起その後の攪乱はないもと仮定している。つまり「冷たい」固体を考えている。しかし実際の典型的な固体は室温をはるかに超えても依然として冷たいままである。

.. [#] `N` は極めて大きいので，格子の実際のギザギザした境界と，それを近似する滑らかな球面との違いを気にする必要はない。

.. [#] 原子核の引力を表すには，デルタ関数を下向きにするのが自然である。しかし，そうすると負エネルギー解も現れ，計算が煩雑になる。ここでは周期性の帰結を知りたいのでこの複雑さを避ける。

.. [#] 次元によらず，自由電子の数 `d` が奇数なら部分的に満たされたバンドが必ず存在し，金属的な振る舞いが予想される。 `d` が偶数なら，部分的に満たされたバンドが存在するかどうかは具体的なバンド構造に依存する。Mott 絶縁体と呼ばれる一部の物質波， `d` が奇数であるにもかかわらず非導体である。この場合，絶縁体的な振る舞いをもたらすのは電子間の相互作用である。

.. [#] 半導体のバンドギャップは典型的には `4\,\mathrm{eV}` 以下であり，室内での熱励起（ `k_\text{B}T \approx 0.025\,\mathrm{eV}` ）でも伝導性を生むほど小さい。半導体の伝導度はドーピングによって制御できる。すなわち， `d` がより大きい，またはより小さい原子を少量混ぜることで，次の高いバンドへ余分な電子が入るか，それまで満たされていたバンドに正孔が作られ，いずれの場合にも弱い電流が流れられるようになる。
