定常状態
==================

波動関数 `\Psi(\bm{x},t)` を得るには，与えられたポテンシャル `V(\bm{x})` に対して，Schrödinger 方程式

.. math::
    i\hbar\pdv{}{t}\Psi(\bm{x},t) = -\frac{\hbar^2}{2m}\nabla^2\Psi(\bm{x},t) + V(\bm{x})\Psi(\bm{x},t)

を解かなければならない。簡単のため，この章では1次元の場合を考え，3次元の場合は後で考えることにする。つまり，

.. math::
    i\hbar\pdv{}{t}\Psi(x,t) = -\frac{\hbar^2}{2m}\pdv{^2}{x^2}\Psi(x,t) + V(x)\Psi(x,t)

を解かなければならない。このような偏微分方程式は変数分離法，すなわち，

.. math::
    \Psi(x,t) = \psi(x)\varphi(t)

という形をした解を求めることで解くことができる。一見すると，これは非自明な制限であり，全ての解のうちごく限られたものしか得られないように思える。しかし，このような解をつなぎ合わせることで最も一般的な解を構成することができる。

このような解について，

.. math::
    \pdv{\Psi}{t} = \psi\dv{\varphi}{t},\quad \pdv{^2\Psi}{x^2} = \varphi\dv{^2\psi}{x^2}

となるから，Schrödinger 方程式は，

.. math::
    i\hbar\psi\dv{\varphi}{t} = -\frac{\hbar^2}{2m}\varphi\dv{^2\psi}{x^2} + V(x)\psi\varphi

となる。両辺を `\psi\varphi` で割れば，

.. math::
    i\hbar\frac{1}{\varphi}\dv{\varphi}{t} = -\frac{\hbar^2}{2m}\frac{1}{\psi}\dv{^2\psi}{x^2} + V

となる。左辺は `t` のみの関数であり，右辺は `x` のみの関数である。これが成立する唯一の方法は，両辺が定数であることである。そうでなければ， `t` を変換させることで右辺を動かさずに左辺を変化させることができるため，両辺は等しくならない。この定数を `E` と置くと，

.. math::
    \dv{\varphi}{t} = -\frac{iE}{\hbar}\varphi,\quad -\frac{\hbar^2}{2m}\dv{^2\psi}{x^2} + V\psi = E\psi

という連立常微分方程式に帰着する。最初の方程式は簡単に解けて，

.. math::
    \varphi(t) = e^{-iEt/\hbar}

となる。興味のある量は `\psi\varphi` であるから積分定数は `\psi` の方に押し付けても構わない。残った方程式は **時間に依存しない Schrödinger 方程式** と呼ばれ，元の Schrödinger 方程式は強調のために **時間に依存するSchrödinger 方程式** と呼ばれることがある。この章の残りの節では，さまざまなポテンシャル `V(x)` に対して時間に依存しない Schrödinger 方程式を解く。

その前に，分離された解が特別な理由を説明しよう。

1.  それらは **定常状態** である。つまり，波動関数そのもの

    .. math::
        \Psi(x,t) = \psi(x)e^{-iEt/\hbar}


    は時刻 `t` に依存するが，確率密度

    .. math::
        |\Psi(x,t)|^2 = \Psi^*\Psi = \psi^*e^{+iEt/\hbar}\psi e^{-iEt/\hbar} = |\psi|^2

    は時間依存性が相殺され時刻に依存しない。これはどのような力学変数の期待値を計算するときにも同様である：

    .. math::
        \braket{Q(x,t)} = \int\psi^*\left[Q\left(x,-i\hbar\pdv{}{x}\right)\right]\psi dx

    すべての期待値は時刻について一定である。したがって， `\Psi` の代わりに `\psi` を用いてもよい。特に `\braket{x}` は一定であり， `\braket{p}=0` である。定常状態ではなにも起こらない。

2.  それらは **全エネルギーが確定した状態** である。古典力学では，全エネルギーはハミルトニアン

    .. math::
        H = \frac{p^2}{2m} + V(x)

    である。運動量 `p` を演算子 `-i\hbar\pdv{}{x}` に置き換えると，ハミルトニアン演算子は，

    .. math::
        \hat{H} = -\frac{\hbar^2}{2m}\pdv{^2}{x^2} + V(x)

    となる。したがって，時間に依存しない Schrödinger 方程式は，

    .. math::
        \hat{H}\psi = E\psi
    
    と書け，全エネルギーの期待値は，

    .. math::
        \braket{H} = \int\psi^*\hat{H}\psi\,\dd x = E\int|\psi|^2\,\dd x = E\int|\Psi|^2\,\dd x = E
    
    となる。さらに，

    .. math::
        \braket{H^2} = \int\psi^*\hat{H}^2\psi\,\dd x = E^2\int|\psi|^2\,\dd x = E^2\int|\Psi|^2\,\dd x = E^2

    となるから，全エネルギーの分散は，

    .. math::
        \sigma_H^2 = \braket{H^2} - \braket{H}^2 = E^2 - E^2 = 0

    となる。したがって，全エネルギーを何度測定しても必ず同じ値 `E` が得られる。

3.  時間に依存する Schrödinger 方程式の **一般解はそれらの線形結合** である。これから見ていくように，時間に依存しない Schrödinger 方程式は，あるポテンシャル `V(x)` に対して，離散的なエネルギー `E_n` を持つ解 `\psi_n` を与える。時間に依存する Schrödinger 方程式には，解のどのような線形結合も，それ自身が解になるという性質がある。したがって，分離された解を見つけさえすれば，より一般的な

    .. math::
        \Psi(x,t) = \sum_{n=1}^{\infty} c_n\psi_n(x)e^{-iE_nt/\hbar}

    という形の解を構成することができる。実は時間に依存する Schrödinger 方程式のすべての解は，このような形で書くことができることが知られている。したがって我々は，与えられた問題の初期条件に適合するような適切な係数 `c_n` を見つけてくるだけで良い。つまり時間に依存しない Schrödinger 方程式を解けば，その系の波動関数が分かり，任意の力学変数の期待値を計算することができる。

これから我々が解くことになる問題は以下のステップに従って機械的に解くことができる：

1. ポテンシャル `V(x)` と初期条件 `\Psi(x,0)` が与えられる。
2. 時間に依存しない Schrödinger 方程式を解き，離散的なエネルギー `E_n` を持つ定常状態 `\psi_n` を求める。
3. 初期条件 `\Psi(x,0)=\sum_{n=1}^{\infty}c_n\psi_n(x)` を満たす係数 `c_n` を求める。
4. 一般解は `\Psi(x,t)=\sum_{n=1}^{\infty}c_n\psi_n(x)e^{-iE_nt/\hbar}` である。

分離された解 `\Psi_n(x,t)=\psi_n(x)e^{-iE_nt/\hbar}` は定常状態であるが，一般解はそうではない。異なる定常状態ではエネルギーが異なるため， `|\Psi|^2` を構成すると時間依存性は相殺されない。

最後に，係数 `c_n` の物理的な意味について述べておく。詳細な説明は後回しにするが， `|c_n|^2` はエネルギーを測定した時に値 `E_n` が得られる確率を表している。もちろん，これらの確率の和は `1` でなければならないから，

.. math::
    \sum_{n=1}^{\infty}|c_n|^2 = 1

である。そしてエネルギーの期待値は，

.. math::
    \braket{H} = \sum_{n=1}^{\infty}|c_n|^2E_n

と書ける。この結果が具体的にどのように使われるかはこれから見ることになる。定数 `c_n` は時間に依存しないので，特定のエネルギーが得られる確率も時間に依存せず，エネルギーの期待値も時間に依存しないことに注意する。これは量子力学におけるエネルギー保存則を表している。
