自由粒子
================

次に本来なら最も簡単なはずの

.. math::
    V(x) = 0

の自由粒子の場合を考える。しかし量子力学ではこの問題は驚くほど微妙である。

時間に依存しない Schrödinger 方程式は

.. math::
    -\frac{\hbar^2}{2m}\dv{^2\psi}{x^2} = E\psi

すなわち，

.. math::
    \dv{^2\psi}{x^2} = -k^2\psi,\quad k \coloneqq \frac{\sqrt{2mE}}{\hbar}

である。これは無限井戸型ポテンシャルの内側と同じだが，今回は一般解を

.. math::
    \psi(x) = Ae^{ikx} + Be^{-ikx}

と書くことにする。無限井戸型ポテンシャルの場合と違って， `k` の値を制限する境界条件はない。完全は波動関数は，

.. math::
    \Psi(x,t) = Ae^{ik(x-\frac{\hbar k}{2m}t)} + Be^{-ik(x+\frac{\hbar k}{2m}t)}

となる。

さて， `x` と `t` の任意の関数で，変数に `x\pm vt` という形で現れるものは，速さ `v` で `\mp x` 方向へ進む波を表す。波形上の全ての点が同じ速度で動くので，伝播しても形は変化しない。したがって， `\Psi(x,t)` の第一項は右へ進む波を，第二項は左へ進む波を表す。ここで，両者は `k` の前の符号だけが違うので，

.. math::
    \Psi_k(x,t) = Ae^{i(kx-\frac{\hbar k^2}{2m}t)}

と書き，左向きの波の場合も含めるために `k` が負の値も取るようにする：

.. math::
    k = \pm\frac{\sqrt{2mE}}{\hbar}

明らかに自由粒子の「定常状態」は伝播する波である。その波長は `\lambda=2\pi/|k|` であり，de Broglie の公式によれば，運動量

.. math::
    p = \hbar k

を持つ。この波の速さ（ `t` の係数を `x` で割ったもの）は

.. math::
    v_\text{quantum} = \frac{\hbar|k|}{2m} = \sqrt{\frac{E}{2m}}

である。一方で，自由粒子の古典的な速さは， `E=(1/2)mv^2` から

.. math::
    v_\text{classical} = \sqrt{\frac{2E}{m}} = 2v_\text{quantum}

となる。どうやら量子力学的な波動関数はそれが表すはずの粒子の半分の速さで進むようだ（このことについては後で説明を加える）。

より深刻な問題として，この波動関数は規格化できない：

.. math::
    \int_{-\infty}^{\infty}\Psi_k^*\Psi_k\,\dd x = |A|^2\int_{-\infty}^{\infty}\dd x = |A|^2(\infty)

したがって，自由粒子は定常状態には存在できない。つまり，確定したエネルギーをもつ自由粒子というものは存在しない。

しかし，時間に依存する Schrödinger 方程式の一般解は，依然として定常状態の線形結合である：

.. math::
    \Psi(x,t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\phi(k)e^{i(kx-\frac{\hbar k^2}{2m}t)}\,\dd k

ここで `k` は今回の場合，連続的なので離散的な和ではなく積分になる。また，因子 `1/\sqrt{2\pi}` は便宜上付けている。この波動関数は適切な係数 `\phi(k)` に対しては規格化することができる。しかし，ある範囲の `k` の値を含み，したがってある範囲のエネルギーを含む。このような状態を **波束** と呼ぶ。自由粒子に対して解は波束である。

残る問題は，初期条件

.. math::
    \Psi(x,0) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\phi(k)e^{ikx}\,\dd k

に一致するように `\phi(k)` を決定することである。その答えは Plancherel の定理によって与えられる：

.. math::
    f(x) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}F(k)e^{ikx}\,\dd k \iff F(k) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}f(x)e^{-ikx}\,\dd x

ここで `F(x)` は `f(x)` の **Fourier 変換** と呼ばれ， `f(x)` は `F(x)` の **逆 Fourier 変換** と呼ばれる [#]_ 。もちろん許される関数には制限があり積分が存在しなければならない [#]_ 。今の場合は， `\Psi(x,0)` が規格化されていれば積分が存在する。したがって，自由粒子について一般的な量子力学の問題を解くには，係数として

.. math::
    \phi(k) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\Psi(x,0)e^{-ikx}\,\dd x

を用いれば良い。

さて， `\Psi_k(x,t)` が表しているはずの粒子に対して「間違った」速さで進むという問題に戻る。これは `\Psi_k` が物理的でないと分かった時点で消滅している。しかし，粒子の速度に関する情報が波束にどのように含まれるかを考えることは興味深い。

波束は，振幅が `\phi` によって変調された正弦関数の重ね合わせであり，「包絡線」の内部に収められた「波紋」から成る。粒子の速度に対応するのは，個々の波紋の速さ（いわゆる位相速度）というよりは，包絡線の速さ（いわゆる群速度）である。群速度は一般に位相速度と一致するとは限らない。それでは，

.. math::
    \Psi(x,t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\phi(k)e^{i(kx-\omega t)}\,\dd k

という形をもつ波束の群速度はどうなるだろう。ここで `\omega` は `\omega=\hbar k^2/2m` のような分散関係に限らず，あらゆる種類の波束を考えることにする。

`\phi(k)` がある特定の値 `k_0` の周りに鋭いピークを持つと仮定する [#]_ 。被積分関数は `k_0` の近傍以外では無視できるので，関数 `\omega(k)` を `k_0` の周りで Taylor 展開し，一次の項だけ残しても良い：

.. math::
    \omega(k) \approx \omega(k_0) + \omega_0'(k-k_0)

ここで `\omega_0'` は `k_0` における `\omega` の `k` に関する導関数である。積分の中心を `k_0` に移すために，変数を `k` から `s\coloneqq k-k_0` へ変えると，

.. math::
    \begin{aligned}
        \Psi(x,t) &\approx \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\phi(k_0+s)e^{i[(k_0+s)x-(\omega(k_0)+\omega_0's)t]}\,\dd s
        \\
        &= \frac{1}{\sqrt{2\pi}}e^{i(k_0x-\omega_0t)}\int_{-\infty}^{\infty}\phi(k_0+s)e^{is(x-\omega_0't)}\,\dd s
    \end{aligned}

となる。前にくくりだされた因子は速さ `\omega_0/k_0` で進む波，すなわち「波紋」である。それは積分，すなわち「包絡線」によって変調される。積分は `x-\omega_0't` の関数なので，速さ `\omega_0'` で伝播する。したがって，位相速度は

.. math::
    v_\text{phase} = \left.\frac{\omega}{k}\right|_{k=k_0}

群速度は

.. math::
    v_\text{group} = \left.\frac{\dd\omega}{\dd k}\right|_{k=k_0}

となる。

自由粒子の場合， `\omega=\hbar k^2/2m` なので，位相速度は `\omega/k = \hbar k/2m` であり，群速度は `\dd\omega/\dd k=\hbar k/m` である。したがって，

.. math::
    v_\text{classical} = v_\text{group} = 2v_\text{phase}

となる。これで波束の群速度が古典的な粒子の速度と一致することが確認できた。

.. [#] Fourier 変換を係数 `1/\sqrt{2\pi}` なしで定義する人もいる。その場合，逆 Fourier 変換の係数は `1/(2\pi)` になり，2つの式の対称性が損なわれる。

.. [#] この積分が存在するための `f(x)` に対する必要十分条件は， `\int_{-\infty}^{\infty}|f(x)|^2\,\dd x` が有限であることである。

.. [#] `k` が広い分布を持つ場合は，波束は急速に形を変え，異なる成分が異なる速さで進むため，よく定まった速度を持つ「群」という概念が意味を失う。
