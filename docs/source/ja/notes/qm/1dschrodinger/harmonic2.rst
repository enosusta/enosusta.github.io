調和振動子型ポテンシャル：解析的方法
========================================

次のポテンシャルを考える：

.. math::
    V(x) = \frac{1}{2} m \omega^2 x^2

ここで， `m` と `\omega` はそれぞれ質量と角振動数である。これはほとんどどんなポテンシャルでも局所的な極小点の近くでは近似的に調和振動子型ポテンシャルが現れるので重要である。

時間に依存しない Schrödinger 方程式は，

.. math::
    -\frac{\hbar^2}{2m} \dv{^2\psi}{x^2} + \frac{1}{2} m \omega^2 x^2 \psi = E \psi

となる。この解法には異なる2つの方法がある。

1. 冪級数を用いた解析的な方法
2. 昇降演算子を用いた代数的な方法

方法 1 は多くの他のポテンシャルに対してできるが比較的複雑である。方法 2 は使用できる場合は限られるが比較的単純である。前節では方法 2 を用いて解いた。ここでは方法 1 を用いて解く。

まず無次元変数

.. math::
    \xi \coloneqq \sqrt{\frac{m\omega}{\hbar}} x

を導入する。そうすると方程式は，

.. math::
    :label: eq:1dschrodinger-harmonic1

    \dv{^2\psi}{\xi^2} = (\xi^2 - K) \psi,\quad K \coloneqq \frac{2E}{\hbar \omega}

となる。非常に大きな `\xi` に対して， `\xi^2 \gg K` なので，

.. math::
    \dv{^2\psi}{\xi^2} \approx \xi^2 \psi

となる。この近似的な方程式の解は，

.. math::
    \psi(\xi) \approx A e^{-\xi^2/2} + B e^{+\xi^2/2}

となる。しかし，第二項は `|x| \to \infty` で発散するので規格化できず，捨てなければならない。したがって，物理的に許される解は大きな `\xi` で

.. math::
    \psi(\xi) \to A e^{-\xi^2/2} \quad (|\xi| \to \infty)

という漸近形を持たなければならない。そこで，この因子をくくりだして，

.. math::
    \psi(\xi)  h(\xi)e^{-\xi^2/2}

と置く。そうすると一階微分は，

.. math::
    \dv{\psi}{\xi} = \left(\dv{h}{\xi}-\xi h\right)e^{-\xi^2/2}

となり，二回微分は，

.. math::
    \dv{^2\psi}{\xi^2} = \left[\dv{^2h}{\xi^2} -2\xi\dv{h}{\xi} + (\xi^2-1)h\right]e^{-\xi^2/2}

となる。したがって，時間に依存しない Schrödinger 方程式は，

.. math::
    :label: eq:1dschrodinger-harmonic2

    \dv{^2h}{\xi^2} - 2\xi \dv{h}{\xi} + (K-1) h = 0

となる。

次にこの方程式の解を `\xi` の冪級数として探す [#]_ ：

.. math::
    h(\xi) = a_0 + a_1\xi + a_2\xi^2 + \cdots = \sum_{j=0}^{\infty} a_j \xi^j

その一階微分は，

.. math::
    \dv{h}{\xi} = a_1 + 2a_2\xi + 3a_3\xi^3 + \cdots = \sum_{j=0}^{\infty}ja_j\xi^{j-1}

であり，二階微分は，

.. math::
    \dv{^2h}{\xi^2} = 2a_2 + 2\cdot 3a_3\xi + 3\cdot 4a_4\xi^2 + \cdots = \sum_{j=0}^{\infty}(j+1)(j+2)a_{j+2}\xi^j

となる。したがって，式 :eq:`eq:1dschrodinger-harmonic2` は，

.. math::
    \sum_{j=0}^{\infty}\left[(j+1)(j+2)a_{j+2}-2ja_j+(K-1)a_j\right]\xi^j = 0

となる。この冪級数がすべての `\xi` についてゼロであるためには，各項の係数がゼロでなければならないので，

.. math::
    a_{j+2} = \frac{2j+1-K}{(j+1)(j+2)} a_j

という漸化式が得られる。ここで， `a_0` が与えられれば全ての偶数係数が

.. math::
    a_2 = -\frac{1-K}{2}a_0,\quad a_4 = -\frac{5-K}{12}a_2 = \frac{(5-K)(1-K)}{24}a_0,\quad \cdots

のように決まり， `a_1` が与えられれば全ての奇数係数が

.. math::
    a_3 = -\frac{3-K}{6}a_1,\quad a_5 = -\frac{7-K}{20}a_3 = \frac{(7-K)(3-K)}{120}a_1,\quad \cdots

のように決まる。このようにして解は，

.. math::
    h(\xi) = h_\text{even}(\xi) + h_\text{odd}(\xi)

と書ける。ここで，

.. math::
    \begin{aligned}
        h_\text{even}(\xi) &= a_0 + a_2\xi^2 + a_4\xi^4 + \cdots
        \\
        h_\text{odd}(\xi) &= a_1\xi + a_3\xi^3 + a_5\xi^5 + \cdots
    \end{aligned}

である。

しかし問題がある。非常に大きな `j` に対して漸化式は近似的に

.. math::
    a_{j+2} \approx \frac{2}{j} a_j

となるため，係数は大きな `j` に対して

.. math::
    a_j \approx \frac{C}{(j/2)!}

となる。すなわち，解は大きな `\xi` に対して

.. math::
    h(\xi) \approx C\sum\frac{1}{(j/2)!}\xi^j \approx C\sum\frac{1}{j!}\xi^{2j} \approx C e^{\xi^2}

のように振る舞う。そうすると波動関数 `\psi=he^{-\xi^2/2}` は大きな `\xi` に対して `e^{+\xi^2/2}` のように振る舞い，まさに先ほど捨てた許されない漸近形になってしまう。

この問題を避けるには，級数が途中で打ち切られなければならない。すなわち，ある最高次 `j=n` が存在して `a_{n+2}=0` となり，以降の係数もすべてゼロにならなければならない。そのためには，偶数級数あるいは奇数級数の一方を打ち切り，他方をゼロにしなければならない。この打ち切りが起こる条件は

.. math::
    K = 2n+1,\quad n=0,1,2,\ldots

である。 `K` の定義 :eq:`eq:1dschrodinger-harmonic1` に立ち返れば，これはエネルギー固有値が

.. math::
    \boxed{E_n = \left(n+\frac{1}{2}\right)\hbar\omega,\quad n=0,1,2,\ldots}

であることを意味する。このような特別なエネルギーの値のときだけ波動関数は発散せず物理的に許される [#]_ 。

この許されたエネルギーに対して，漸化式は

.. math::
    a_{j+2} = -\frac{2(n-j)}{(j+1)(j+2)} a_j

となる。 基底状態 `n=0` なら `a_1=0` とし， `j=0` で `a_2=0` となるので，

.. math::
    h_0(\xi) = a_0,\quad \psi_0(\xi) = a_0 e^{-\xi^2/2}

第一励起状態 `n=1` なら `a_0=0` とし， `j=1` で `a_3=0` となるので，

.. math::
    h_1(\xi) = a_1\xi,\quad \psi_1(\xi) = a_1\xi e^{-\xi^2/2}

第二励起状態 `n=2` なら `a_1=0` とし， `j=0` で `a_2=-2a_0` ， `j=2` で `a_4=0` となるので，

.. math::
    h_2(\xi) = a_0(1-2\xi^2),\quad \psi_2(\xi) = a_0(1-2\xi^2)e^{-\xi^2/2}

となる。一般に `h_n(\xi)` は `\xi` の `n` 次多項式であり， `n` が偶数なら偶関数，奇数なら奇関数である。定数倍を除けば，これらの多項式は **Hermite 多項式** `H_n(\xi)` である。適切に規格化すれば，波動関数は

.. math::
    \boxed{\psi_n(\xi) = \left(\frac{m\omega}{\pi\hbar}\right)^{1/4} \frac{1}{\sqrt{2^n n!}} H_n(\xi) e^{-\xi^2/2}}

となる。

量子振動子は古典的な対応物とは振る舞いが著しく異なる。エネルギーが量子化されるだけではなく，その位置分布にも奇妙な特徴がある。たとえば，粒子を古典的に許された範囲の外側に見出す確率はゼロではない。また，すべての奇数番目の励起状態では，中心に粒子を見出す確率はゼロである。大きい `n` になって初めて古典的な振る舞いとの一意が見られるようになる。

.. [#] Taylor の定理によれば，十分性質の良い関数はどれも冪級数として表せるので，この方法によって一般性が失われることはない。

.. [#] これをコンピュータ上で計算し，許されるエネルギーを実験的に発見することもできる。発散の原因となる `e^{+\xi^2/2}` の「尾」が `x` 軸をまたぐとき，許された値をちょうど通り過ぎたことが分かる。この方法は射撃法（shooting method）と呼ばている。
