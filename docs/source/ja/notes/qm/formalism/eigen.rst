エルミート演算子の固有関数
================================

エルミート演算子の固有関数は2種類に分けられる：

1. スペクトルが離散的な場合：固有関数は Hilbert 空間に属する。
2. スペクトルが連続的な場合：固有関数は Hilbert 空間に属さない [#]_ 。

離散スペクトルだけをもつ演算子（例：調和振動子型ポテンシャルのハミルトニアン）もあれば，連続スペクトルだけをもつ演算子（例：自由粒子のハミルトニアン）もあり，両方をもつ演算子（例：有限井戸型ポテンシャルのハミルトニアン）もある。離散スペクトルを持つ場合は内積の存在が保証されるため扱いやすい。そこで，まず離散スペクトルの場合を扱い，次に連続スペクトルの場合を扱う。

離散スペクトル
-------------------

数学的にはエルミート演算子の規格化可能な固有関数には，2つの重要な性質がある：

.. important::
    固有値は実数である。

.. dropdown:: 証明

    次を仮定する：

    .. math::
        \hat{Q}f = qf

    さらに，

    .. math::
        \braket{f|\hat{Q}f} = \braket{\hat{Q}f|f}

    とする [#]_ 。このとき，

    .. math::
        q\braket{f|f} = q^*\braket{f|f}

    となる。 `\braket{f|f}` はゼロではありえないので（ `f=0` は固有関数ではないので） `q=q^*` となる。

.. important::
    異なる固有値に属する固有関数は直交する。

.. dropdown:: 証明

    次を仮定する：

    .. math::
        \hat{Q}f = qf, \quad \hat{Q}g = q'g

    さらに，

    .. math::
        \braket{f|\hat{Q}g} = \braket{\hat{Q}f|g}

    とする。このとき，

    .. math::
        q'\braket{f|g} = q^*\braket{f|g} = q\braket{f|g}

    となる。 `q\neq q'` のとき， `\braket{f|g}=0` となる。

残念ながら，上の定理は縮退した状態（ `q=q` ）については何も教えてくれない。しかし，2つ以上の固有関数が同じ固有値を共有するなら，それらの任意の線形結合も同じ固有値を持つ固有関数である。そこで Gram-Schmidt の直交化法を用いれば，各縮退部分空間の内部で直交するように固有関数を構成することができる。したがって，我々は常に固有関数は直交していると仮定してよい。

有限次元ベクトル空間では，エルミート演算子の固有関数についてさらに重要な性質がある。それは固有関数が Hilbert 空間を張る（任意のベクトルがそれらの線形結合として表せる）ということである。残念ながら，その証明は無限次元ベクトル空間へ一般化できない。しかしこの性質は量子力学の内部整合性に不可欠なので，これを公理（正確には，エルミート演算子に対する制限）として採用する [#]_ ：

.. important::
    可観測量の演算子の固有関数は完全である。

連続スペクトル
-------------------

エルミート演算子のスペクトルが連続的なら，固有関数は規格化できず，内積が存在しないかもしれないため，離散スペクトルの場合の結果が証明できない。それにもかかわらず，上で述べた3つの性質がある意味では成り立つ。

区間 `-\infty<x<\infty` 上の運動量演算子の固有関数と固有値について考える。 `f_p(x)` と固有関数， `p` を固有値とする：

.. math::
    -i\hbar\dv{}{x}f_p(x) = pf_p(x)

一般解は，

.. math::
    f_p(x) = Ae^{ipx/\hbar}

である。これはどのような `p` に対しても二乗可積分ではない。したがって，運動量演算子は Hilbert 空間内に固有関数を持たない。それでも，固有値を実数に制限すれば，ある種の代用的な「正規直交性」を得ることができる。

.. math::
    \begin{aligned}
        \int_{-\infty}^{\infty}f_{p'}^*(x)f_p(x)\,\dd x &= |A|^2\int_{-\infty}^{\infty}e^{i(p-p')x/\hbar}\,\dd x
        \\
        &= |A|^22\pi\hbar\delta(p-p')
    \end{aligned}

となるので， `A=1/\sqrt{2\pi\hbar}` と選べば，

.. math::
    f_p(x) = \frac{1}{\sqrt{2\pi\hbar}}e^{ipx/\hbar}

となり，

.. math::
    \braket{f_{p'}|f_p} = \delta(p-p')

となる。これは本来の正規直交性と似ている。添え字は連続変数となり，Kronecker のデルタは Dirac のデルタになったが，それ以外は同じである。そこで，この性質を Dirac 正規直交性と呼ぶことにする。

実固有値を持つ固有関数は完全であり，任意の関数 `f(x)` は

.. math::
    f(x) = \int_{-\infty}^{\infty}c(p)f_p(x)\,\dd p = \frac{1}{\sqrt{2\pi\hbar}}\int_{-\infty}^{\infty}c(p)e^{ipx/\hbar}\,\dd p

と書ける。係数 `c(p)` はいつものように Fourier の方法によって求められる：

.. math::
    \begin{aligned}
        \braket{f_p|f} &= \int_{-\infty}^{\infty}f_p^*(x)f(x)\,\dd x
        \\
        &= \frac{1}{\sqrt{2\pi\hbar}}\int_{-\infty}^{\infty}e^{-ipx/\hbar}f(x)\,\dd x = c(p)
    \end{aligned}

あるいは Planchel の定理から逆 Fourier 変換として得ることもできる。

運動量の固有関数の波長は，

.. math::
    \lambda = \frac{2\pi\hbar}{p} = \frac{h}{p}

である。これは説明を保留していた de Broglie の公式である。実際には確定した運動量をもつ粒子は存在しないので，もともと de Broglie が考えていたものよりは少し微妙である。この公式は正確には波束に対して適用されるべきである。

`\hat{p}` の固有関数は Hilbert 空間に属さないが，そのうち実数の固有値をもつものは，ある種の規格化条件を備えていて，非常に扱いやすい [#]_ 。幸いなことに我々が実際に必要とする性質はこれで十分である。

.. [#] ただしそれらの線形結合は規格化できる場合がある。

.. [#] ここで固有関数が Hilbert 空間に属することを仮定している。そうでなければ内積の存在が保証されない。

.. [#] いくつかの特別な場合では，完全性を証明できる。たとえば無限井戸型ポテンシャルの定常状態が完全であることは Dirichlet の定理によって保証される。

.. [#] 実数でない固有値を持つ場合，単に規格化できないだけでなく， `\pm\infty` で発散する。Dirac 規格化条件まで許した空間は rigged Hilbert 空間と呼ばれ，それ自身との有限な内積は持たないが，それ以外との内積は持つという性質を備えている。これは実数でない固有値をもつ `\hat{p}` の固有関数には当てはまらない。
