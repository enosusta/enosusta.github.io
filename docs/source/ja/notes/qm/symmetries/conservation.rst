保存則
============

古典力学では，保存則の意味は明快である。すなわち，ある量が，ある過程の前後で同じであるということである。しかし量子力学では，一般に過程の前後に系が確定した値を持つわけではない。そこで可観測量 `Q` が保存されるとは次の2つの可能性がある：

1. 期待値 `\braket{Q}` が時刻に依存しない。
2. 任意の特定の値が得られる確率が時間に依存しない。

これらの保存則は，それぞれどのような条件のもとで成り立つだろうか。

可観測量は時刻に陽には依存しない，すなわち

.. math::
    \pdv{Q}{t} = 0

とする。この場合，一般化された Ehrenfest の定理によれば， **演算子** `\hat{Q}` **がハミルトニアンと可換ならば** ， `Q` の期待値は時刻に依存しない。実は，このとき第2の保存則も成り立つ。これを証明しよう。

時刻 `t` における `Q` の測定で値 `q_n` が得られる確率は

.. math::
    P(q_n) = |\braket{f_n|\Psi(t)}|^2

であったことを思い出そう。ここで `\ket{f_n}` は対応する固有ベクトル，すなわち，

.. math::
    \hat{Q}\ket{f_n} = q_n\ket{f_n}

である [#]_ 。波動関数の時間発展は，

.. math::
    \ket{\Psi(t)} = \sum_m e^{-iE_mt/\hbar}c_m\ket{\psi_m}

である。ここで `\ket{\psi_m}` は `\hat{H}` の固有状態であり，したがって，

.. math::
    P(q_n) = \left|\sum_m e^{-iE_mt/\hbar}c_m\braket{f_n|\psi_m}\right|^2

となる。次が重要である： `\hat{Q}` と `\hat{H}` は可換なので両者の同時固有状態の完全系を見出すことができる。したがって，一般性を失うことなく

.. math::
    \ket{f_n} = \ket{\psi_n}

とできる。 `\ket{\psi_n}` の正規直交性より

.. math::
    P(q_n) = \left|\sum_m e^{-iE_mt/\hbar}c_m\braket{\psi_n|\psi_m}\right|^2 = |c_n|^2

となり，これは明らかに時刻に依存しない。

.. [#] `\hat{Q}` のスペクトルが縮退している場合，それらの状態について和を取る必要がある： `P(q_n) = \sum_{i} |\braket{f_{n}^{(i)}|\Psi(t)}|^2` 。 `i` について和をとることを除けば，証明は変わらない。
