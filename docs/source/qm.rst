量子力学
=================

講義ノート
-----------------

量子力学の基本原理は何か，どのように教えるべきか，あるいはそれが本当は何を意味するのかについて一般的な合意はないように思える。物理学者なら誰しもが量子力学を「使う」ことはできるが，その説明については多種多様である。Niel Bohrは「量子論に困惑しないなら，あなたはそれを本当に理解していない」と言い，Richard Feynmanは「量子力学を理解している者は誰もいない，と私は断言してよいと思う」と言った。

本講義の目的は，量子力学の「使い方」を学ぶことである。深い哲学的な議論については基本的な使い方について述べた後に取っておくことにする。私は，量子力学の「使い方」を習得する前に，量子力学の「意味」について議論すべきではないと思う。
