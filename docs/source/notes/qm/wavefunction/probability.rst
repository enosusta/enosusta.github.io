確率解釈
=================

波動関数と呼ばれる複素数値関数 `\Psi(\bm{x}, t)` とはいったい何であろう。その答えは Born の **確率解釈** によって与えられる：

.. math::
    \int_{\bm{a}}^{\bm{b}} |\Psi(\bm{x}, t)|^2\, \dd^3\bm{x} = \left\{
        \begin{aligned}
            &\text{probability of finding the particle}
            \\
            &\text{between } a \text{ and } b \text{ at time } t
        \end{aligned}
    \right\}

このような解釈は量子力学のある種のあいまいさを導入する。すなわち，このような粒子の状態を表す波動関数を知っていたとしても，その粒子の位置について定まった値を予言することはできない。このあいまいさは物理学者や哲学者の間で長い間議論されてきた。

もし粒子の位置を実際に測定して，それが位置 `\bm{x}_0` であったとすると，測定を行う直前まで，粒子はどこに存在したのだろう。この問いにはもっともらしい答えが少なくとも三つあった：

1. 粒子は測定を行うまで，位置 `\bm{x}_0` に存在していた。
2. 粒子は測定を行うまで，どこにも存在していなかった。
3. 分からない。

長い間，それぞれの立場には支持者がいたが，1964年に John Bell が，測定前に粒子が正確だが未知の位置に存在したかどうかによって観測可能な違いが生じることを示したことで，1 の答えは棄却された。この Bell の議論を取り上げるのは随分と後のことになってしまうが，とりあえず 3 を無視すれば，2 が妥当だということを認識しておけば十分である。不思議なことに特定の位置を作り出すのは「測定」であり，波動関数はその位置を制限する統計的な重みに過ぎない。

それでは，測定の直後に再び測定を行ったらどうなるだろう。もし同じ値が得られないのならば，最初に粒子がその位置に存在していたことを証明するのは難しいだろう。実際，測定の直後に再び測定を行った場合，必ず同じ値が得られる。この事実を 2 と整合させるためには，最初の測定によって波動関数が変化し，測定された点に局在化（ **collapse** ）すると考えるほかない。そして，Schrödinger 方程式に従って波動関数は広がっていく前に測定を行えば，同じ値が得られる。すなわち，物理的な過程には全く異なる二種類の時間発展の仕方が存在する：

1. 波動関数が Schrödinger 方程式に従って連続的に時間発展する場合
2. 波動関数が測定によって不連続に時間発展（collapse）する場合

最後に，Born の確率解釈を裏付ける有名な二重スリット実験について紹介しよう。波動現象の特徴的な性質は干渉である。波が二つのスリットを通過すると，遠方のスクリーン上には干渉縞が現れる。もし粒子が波のように振る舞うならば，たとえば電子ひとつを二つにスリットに向かって射出した場合，そのような干渉縞が現れるはずである。実験自体は非常にシンプルで，実際に私も学部の講義で実験する機会があった。

さて，電子ビームの強度を電子がひとつになるまで下げたとしよう。確率解釈によれば，各電子はスクリーン上にひとつの点を作る。しかしその点の正確な位置は予言することはできない。実際に，これを繰り返していくと，蓄積されていく点の分布は干渉縞を形成される（動画でその様子を見たい方には `One electron double slit experiment by Akira Tonomura <https://www.youtube.com/watch?v=jvO0P5-SMxk>`_ を勧める）。
