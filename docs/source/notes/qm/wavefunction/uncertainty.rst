不確定性原理
==================

一般に波動現象の特徴として，波の位置がソリトンのように正確であればあるほど，その波長は正確ではなくなり，逆に波長が正確であればあるほど，その位置は正確ではなくなる。これは量子力学的な波動関数にも当てはまる。特に波動関数 `\Psi(\bm{x},t)` の波長は de Broglie の公式

.. math::
    |\bm{p}| = \frac{h}{\lambda} = \frac{2\pi\hbar}{\lambda}

によって粒子の運動量と関係づけられることが知られている [#]_ 。したがって，粒子の位置が正確であればあるほど，その運動量は正確ではなくなり，逆に粒子の運動量が正確であればあるほど，その位置は正確ではなくなる。定量的には，

.. math::
    \sigma_{\bm{x}} \sigma_{\bm{p}} \ge \frac{\hbar}{2}

となる。ここで `\sigma_{\bm{x}}` は位置 `\bm{x}` の標準偏差， `\sigma_{\bm{p}}` は運動量 `\bm{p}` の標準偏差である。これが Heisenberg の有名な **不確定性原理** である [#]_ 。ここでいう不確定性とは，同じように準備された系について行う測定が，同じ値を与えることはほぼないということである。これらの系の波動関数を位置の測定値が互いに非常に近くなるように準備した場合，運動量の測定値は広く散らばることになる。
