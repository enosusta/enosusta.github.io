イントロダクション
======================

本章では，対称性とは何か，また量子力学で何かが保存されるとはどういう意味かを説明し，両者がどのように関係するかを示す。その過程で，量子系が持つ2つの関連した性質，すなわちエネルギー準位の縮退と，許される遷移と許されない遷移とを区別する選択則について調べる。

対称性とは，系を変化させない何らかの変換である。例えば，正方形は `90^\circ` 回転させれば元の向きに戻る。したがって正方形は離散的な回転対称性を持つ。円の場合はどの角度だけ回転させても変化しないので，連続的な回転対称性を持つ。

もし正方形が2次元無限井戸型ポテンシャルの境界を表しているとすると，ポテンシャルエネルギーは正方形と同じ離散的回転対称性を持ち，ハミルトニアンも不変である。量子力学において系が対称性を持つということは，このようなことである。すなわち，回転や並進など，ある変換によってハミルトニアンが変化しないということである。

この節では，並進，反転，回転に対応する量子力学的な演算子を導入する。これらの演算子は，任意の関数にどのように作用するかによって定義される。例えば，並進演算子は関数を距離 `a` だけずらすものとして定義される：

.. math::
    \hat{T}(a)\psi(x) = \psi'(x) = \psi(x-a)

この負符号に初めは戸惑うかもしれない。この式は， `x` における並進後の関数 `\psi` が `x-a` における並進前の関数 `\psi` に等しいということである。つまり関数そのものは `a` だけ右へずれている。

同様に関数を原点に関して反転させる演算子，すなわちパリティ演算子は

.. math::
    \hat{\Pi}\psi(x) = \psi'(x) = \psi(-x)

によって定義される。もちろん3次元では3つの座標すべての符号を反転させる [#]_ ：

.. math::
    \hat{\Pi}\psi(x,y,z) = \psi'(x,y,z) = \psi(-x,-y,-z)

最後に，関数を例えば `z` 軸まわりに角度 `\varphi` だけ回転させる演算子は極座標を用いて

.. math::
    \hat{R}_z(\varphi)\psi(r,\theta,\phi) = \psi'(r,\theta,\phi) = \psi(r,\theta,\phi-\varphi)

によって定義される。任意の軸のまわりの回転について後で説明する。

.. [#] 3次元のパリティ変換は，鏡映変換に続いて回転を行うことで実現できる。2次元ではパリティ変換は `180^\circ` 回転することと何ら変わりない。そこで，1次元と3次元における空間反転だけにパリティという語を用いることにする。
