並進演算子
==============

並進演算子 `\hat{T}(a)` は，それと密接に関係する運動量演算子を用いて表すことができる。そのために， `\psi(x-a)` を Taylor 級数で置き換える [#]_ ：

.. math::
    \begin{aligned}
        \hat{T}(a)\psi(x) = \psi(x-a) &= \sum_{n=0}^{\infty}\frac{1}{n!}(-a)^n\dv{^n}{x^n}\psi(x)
        \\
        &= \sum_{n=0}^{\infty}\frac{1}{n!}\left(-\frac{ia}{\hbar}\hat{p}\right)^n\psi(x)
    \end{aligned}

この式の右辺は指数関数なので，

.. math::
    \boxed{\hat{T}(a) = \exp\left[-\frac{ia}{\hbar}\hat{p}\right]}

となる。そこで運動量は並進の **生成子** であるという [#]_ 。ここで `\hat{T}(a)` はユニタリー演算子であることに注意する [#]_ ：

.. math::
    \hat{T}(a)^{-1} = \hat{T}(-a) = \hat{T}(a)^\dagger

最初の等号は物理的に明らかであり，2つ目の等号は指数関数の随伴を取れば従う。

ここまでは関数をどのように並進するかを示した。演算子を並進するとはどういうことかも考えることができる。変換後の演算子 `\hat{Q}'` は，並進前の状態 `\psi` において，並進後の状態 `\psi'` における演算子 `\hat{Q}` と同じ期待値を与える演算子として定義される：

.. math::
    \braket{\psi'|\hat{Q}|\psi'} = \braket{\psi|\hat{Q}'|\psi}

期待値に対する並進の効果を計算する方法は2通りある。実際に波動関数をある距離だけずらす場合（ **能動変換** という）と，波動関数をそのままにして，座標系の元を同じ距離だけ反対方向へずらす場合（ **受動変換** という）がある。演算子 `\hat{Q}'` は，このずらされた座標系における演算子である。

`\ket{\psi'}=\hat{T}\ket{\psi}` を用いると，

.. math::
    \braket{\psi|\hat{T}^\dagger\hat{Q}\hat{T}|\psi} = \braket{\psi|\hat{Q}'|\psi}

ここで演算子の随伴が `\hat{T}\ket{f}=\ket{\hat{T}f}` ならば，

.. math::
    \bra{\hat{T}f} = \bra{f}\hat{T}^\dagger

であるように定義される。これは任意の `\psi` について成り立たなければならないので，

.. math::
    \boxed{\hat{Q}' = \hat{T}^\dagger\hat{Q}\hat{T}'}

となる。例えば， `\hat{Q}=\hat{x}` の場合，テスト関数 `f(x)` を用いると，

.. math::
    \hat{x}'f(x) = \hat{T}^\dagger(a)\hat{x}\hat{T}(a)f(x)

であり， `\hat{T}(a)=\hat{T}(-a)` なので，

.. math::
    \hat{x}'f(x) = \hat{T}(-a)\hat{x}\hat{T}(a)f(x) = \hat{T}(-a)xf(x-a)

であり，

.. math::
    \hat{T}(-a)[xf(x-a)] = (x+a)f(x)

だから，

.. math::
    \hat{x}'f(x) = (x+a)f(x)

となる。したがって演算子を読み取れば，

.. math::
    \hat{x}' = \hat{x} + a

となる。同様に運動量演算子の場合は，

.. math::
    \hat{p}' = \hat{T}^\dagger\hat{p}\hat{T} = \hat{p}

となる。すなわち運動量演算子はこの変換に対して変化しない。位置演算子と運動量演算子が並進のもとでどのように振る舞うかが分かれば，任意の演算子の振る舞いが分かる：

.. math::
    \hat{Q}'(\hat{x},\hat{p}) = \hat{T}^\dagger\hat{Q}(\hat{x},\hat{p})\hat{T} = \hat{Q}(\hat{x}+a,\hat{p})

これで，前節で述べた対称性の概念を正確にする準備が整った。ハミルトニアンが変換によって変化しない時，系は並進不変である：

.. math::
    \hat{H}' = \hat{T}^\dagger\hat{H}\hat{T} = \hat{H}

\hat{T} はユニタリーなので両辺に `\hat{T}` を掛けると，

.. math::
    \hat{H}\hat{T} = \hat{T}\hat{H}

となる。したがって，ハミルトニアンが並進演算子と可換

.. math::
    \boxed{[\hat{H},\hat{T}] = 0}

ならば，系は並進対称性を持つ。例えば，1次元ポテンシャル中を運動する質量 `m` の粒子について，ハミルトニアンは，

.. math::
    \hat{H} = \frac{\hat{p}^2}{2m} + V(x)

である。変換後のハミルトニアンは，

.. math::
    \hat{H}' = \frac{\hat{p}^2}{2m} + V(x+a)

なので，並進対称性は

.. math::
    V(x+a) = V(x)

を意味する。さて，これが現れる物理的な状況には全く異なる2つの場合がある：

1. 一定のポテンシャルの場合：全ての `a` に対して `V(x+a)=V(x)` が成り立つ。このような系は連続的な並進対称性を持つという。
2. 周期的ポテンシャルの場合：離散的な `a` に対してのみ `V(x+a)=V(x)` が成り立つ。このような系は離散的な並進対称性を持つという。

この節の最後にこれら2つの対称性がある場合について得られる重要な結果をひとつずつ述べる。

離散的な並進対称性
--------------------------

離散的並進対称性を持つ系にとって，最も重要な帰結は Bloch の定理である。この定理は定常状態がとる形を決める。前にもこの定理を用いたが，ここで証明を与えよう。

2つの演算子は可換ならば，同時固有状態の完全系を持つ。したがって，ハミルトニアンが並進不変ならば，ハミルトニアンの固有状態 `\psi(x)` を同時に `\hat{T}` の固有状態として選べる：

.. math::
    \hat{H}\psi(x) = E\psi(x),\quad \hat{T}(a)\psi(x) = \lambda\psi(x)

ここで `\hat{T}` はユニタリーなので，その固有値の絶対値は `1` になる。したがって，ある実数 `\phi` に対して `\lambda = e^{i\phi}` と書ける。慣例的に `\phi=-qa` と書き， `\hbar q` を結晶運動量と呼ぶ。したがって，周期ポテンシャル中を運動する質量 `m` の粒子の定常状態は，

.. math::
    \psi(x-a) = e^{-iqa}\psi(x)

という性質を持つ。より良い書き方は，

.. math::
    \boxed{\psi(x) = e^{iqx}u(x)}

である。ここで `u(x)` は `x` の周期関数であり， `e^{iqx}` は波長 `2\pi/q` の平面波である。これが Bloch の定理であり，周期ポテンシャル中の粒子の定常状態は，周期関数と進行波との積であるということを述べている。これは周期的な変調を除けば，電子が完全結晶中を散乱されることなく進めることを意味する。これは固体中の電気伝導にとって重要な結果である。

連続的な並進対称性
--------------------------

系が連続的な並進対称性を持つ場合，無限小並進

.. math::
    \hat{T}(\delta) = e^{-i\delta\hat{p}/\hbar} \approx 1 - i\frac{\delta}{\hbar}\hat{p}

を考えると便利である。ここで `\delta` は無限小の長さである。ハミルトニアンはこの無限小並進演算子と可換なので，

.. math::
    [\hat{H},\hat{T}(\delta)] = \left[\hat{H},1-i\frac{\delta}{\hbar}\hat{p}\right] = 0 \implies [\hat{H},\hat{p}] = 0

となる。よって，ハミルトニアンが連続的な並進対称性を持つならば，運動量演算子と可換でなければならない。このとき一般化された Ehrenfest の定理より，

.. math::
    \dv{}{t}\braket{\hat{p}} = \frac{i}{\hbar}\braket{[\hat{H},\hat{p}]} = 0

となる。これは運動量保存則である。これは強力な定理，すなわち対称性は保存則を導くことの最初の例である [#]_ 。

.. [#] ここでは関数が Taylor 級数展開を持つと仮定しているが，最終結果はより一般に成り立つ。

.. [#] この用語は Lie 群の研究に由来する。並進群はその一例に過ぎない。

.. [#] ユニタリー演算子とは，その随伴が逆演算子でもある演算子である： `\hat{U}^\dagger=\hat{U}^{-1}` 。

.. [#] 離散的な並進対称性の場合，運動量は保存しないが，離散的な並進対称性と密接に関係する保存量，すなわち結晶運動量がある。
