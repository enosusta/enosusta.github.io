縮退
===========

対称性は，量子力学における縮退の大部分の源である [#]_ 。これまで見たように，対称性があるならば，ハミルトニアンと可換な演算子 `\hat{Q}` が存在する：

.. math::
    [\hat{H}, \hat{Q}] = 0

定常状態 `\ket{\psi_n}` があるならば

.. math::
    \ket{\psi'_n} = \hat{Q}\ket{\psi_n}

も同じエネルギーを持つ定常状態である：

.. math::
    \begin{aligned}
        \hat{H}\ket{\psi'_n} &= \hat{H}(\hat{Q}\ket{\psi_n}) = \hat{Q}\hat{H}\ket{\psi_n} = \hat{Q}E_n\ket{\psi_n}
        \\
        &= E_n(\hat{Q}\ket{\psi_n}) = E_n\ket{\psi'_n}
    \end{aligned}

例えば，球対称なハミルトニアンの固有状態があり，その状態をある軸のまわりに回転させるならば，同じエネルギーをもつ別の状態が得られなければならない。

対称性は常に縮退をもたらし，連続対称性は無限の縮退をもたらす，と思うかもしれない。しかし，そうではない。2つの状態 `\ket{\psi_n}` と `\ket{\psi'_n}` が同じであるかもしれないからである。例えば，1次元調和振動子ポテンシャルの場合を考えると，これはパリティと可換である。その定常状態はすべて偶関数か奇関数なので，その1つにパリティ演算子を作用させると，初めと同じ状態が戻ってくる（ `-1` は掛かるが物理的には同じ状態である）。したがって，この場合，反転対称性に伴う縮退はない。

実際，対称性演算子がひとつしかない場合（あるいは複数の対称性演算子があっても，それらが互いにすべて可換である場合），スペクトルに縮退は生じない。なぜなら， `\hat{Q}` と `\hat{H}` の同時固有状態 `\ket{\psi_n}` を見出すことができ，これらの状態は対称変換の下で自身へ変換されるからである：

.. math::
    \hat{Q}\ket{\psi_n} = q_n\ket{\psi_n}

しかし，ハミルトニアンと可換な2つの演算子 `\hat{Q}` と `\hat{\Lambda}` が互いに可換出ない場合は，エネルギースペクトルは縮退する。まず， `\hat{H}` と `\hat{Q}` の同時固有状態 `\ket{\psi}` を考え，それぞれの固有値を `E_n,q_m` とする。 `\hat{H}` と `\hat{\Lambda}` は可換なので，状態

.. math::
    \ket{g} = \hat{\Lambda}\ket{\psi}

も固有値 `E_n` を持つ `\hat{H}` の固有状態である。一方で `\hat{Q}` と `\hat{\Lambda}` は可換でないので，3つの演算子 `\hat{Q},\hat{\Lambda},\hat{H}` すべての同時固有状態からなる完全系は存在しない。したがって，ある `\ket{\psi}` について `\hat{\Lambda}\ket{\psi}` は `\ket{\psi}` と異ならなけらばならない。これは，エネルギー準位 `E_n` が少なくとも二重に縮退していることを意味する。つまり **互いに可換でない複数の対称性演算子が存在すれば，エネルギースペクトルの縮退が保証される** 。

これはまさに中心力ポテンシャルの場合に出会った状況である。このときハミルトニアンは `x,y,z` 軸のまわりの回転，あるいは同じことだが，生成子 `\hat{L}_x,\hat{L}_y,\hat{L}_z` と可換である。しかし，これらの回転は互いに可換ではない。したがって，中心力ポテンシャル中の粒子のスペクトルには縮退が生じる。特にハミルトニアンと可換だが，互いに可換でない `\hat{L}_+,\hat{L}_-` を使うと， `\ket{nlm}` と同じエネルギーの `m` だけが異なる状態が合計で `2l+1` 個得られる。もちろん，水素原子の電子状態の縮退度は `n^2` であり，これは `2l+1` よりも大きいから，明らかに回転不変性だけでは説明できない多くの縮退が存在する。この余分な縮退は， `1/r` 型ポテンシャルに特有の隠れた対称性に由来する。

.. [#] ある特定の縮退を生じさせる対称性を特定できないとき，それを偶発的な縮退と呼ぶ。そのような場合の大半では，縮退はまったくの偶然ではなく，より特定しにくい隠れた対称性に由来する。例えば水素原子にも隠れた対称性が存在する。
