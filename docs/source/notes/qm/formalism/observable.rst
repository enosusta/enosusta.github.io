可観測量
==================

可観測量 `Q(x,p)` の期待値は，内積を用いて，

.. math::
    \braket{Q} = \int \Psi^*\hat{Q}\Psi\,\dd x = \braket{\Psi|\hat{Q}\Psi}

と表すことができる [#]_ 。測定の結果は実数でなければならないので，期待値も実数でなければならない：

.. math::
    \braket{Q}^* = \braket{Q}

内積の複素共役は順序を逆転させるので，任意の波動関数 `\Psi` に対して，

.. math::
    \braket{\Psi|\hat{Q}\Psi}^* = \braket{\hat{Q}\Psi|\Psi}

となる。このような特別な性質を持つ演算子を **エルミート演算子** という [#]_ 。これは，実際には任意の `f,g` に対して

.. math::
    \braket{f|\hat{Q}g} = \braket{\hat{Q}f|g}

と書かれることもあるが，これらの定義は同値である。本質的には，エルミート演算子を内積の第一引数に作用させても，第二引数に作用させても結果は同じであるということである。したがって，量子力学では，

.. important::
    可観測量 `Q` はエルミート演算子 `\hat{Q}` によって表される。

たとえば，運動量演算子は，

.. math::
    \begin{aligned}
        \braket{f|\hat{p}g} &= \int_{-\infty}^{\infty} f^*(-i\hbar)\dv{g}{x}\,\dd x
        \\
        &= \left[-i\hbar f^*g\right]_{-\infty}^{\infty} + \int_{-\infty}^{\infty} \left(-i\hbar\dv{f}{x}\right)^* g\,\dd x = \braket{\hat{p}f|g}
    \end{aligned}

となるのでエルミートである。ここで `f,g` が二乗可積分ならば通常は `x\to\pm\infty` でゼロにならなければならないので境界項は消えている [#]_ 。

一般に，演算子 `\hat{Q}` のエルミート共役あるいは随伴とは，任意の `f,g` に対して

.. math::
    \braket{f|\hat{Q}g} = \braket{\hat{Q}^\dagger f|g}

を満たす演算子 `\hat{Q}^\dagger` のことをいう。エルミート演算子は，そのエルミート共役が自分自身に等しい演算子である： `\hat{Q}^\dagger = \hat{Q}` 。

さて，すべて同じ状態 `\Psi` にある系のアンサンブルに対して可観測量 `Q` を測定したとき，毎回異なる値が得られることが期待される。しかし，定常状態では常にハミルトニアンは同じ値を持つ。このような特別な状態では， `Q` の標準偏差はゼロである：

.. math::
    \begin{aligned}
        \sigma^2 &= \braket{(Q-\braket{Q})^2} = \braket{\Psi|(\hat{Q}-q)^2\Psi}
        \\
         &= \braket{(\hat{Q}-q)\Psi|(\hat{Q}-q)\Psi} = 0
    \end{aligned}

自身との内積がゼロになるベクトルはゼロしかないので，そのような特別な状態は

.. math::
    \hat{Q}\Psi = q\Psi

を満たす。これはちょうど演算子 `\hat{Q}` に対する固有値方程式であり， `\Psi` は `\hat{Q}` の固有関数であり， `q` は対応する固有値である。したがって，量子力学では，

.. important::
    `Q` の値が確定している状態は `\hat{Q}` の固有関数である。

ゼロは固有関数には含めない。そうしなければ，任意の線形演算子 `\hat{Q}` と任意の数 `q` に対して `\hat{Q}0 = q0 = 0` となるので，すべての数が固有値になってしまう。しかし，固有値がゼロであることには何の問題もない。

演算子のすべての固有値の集合をその **スペクトル** という。2つ以上の線形独立な固有関数が，同じ固有値を共有する場合，スペクトルは **縮退** しているという。

.. [#] ここで `\hat{Q}` は `Q(x,p)` において `p\to -i\hbar\dd/\dd x` と置き換えて構成される演算子である。これらの演算子は，任意の関数 `f,g` と任意の複素数 `a,b` に対して `\hat{Q}(af+bg) = a\hat{Q}f + b\hat{Q}g` という意味で線形である。これらは Hilbert 空間上の線形写像を構成する。しかし，Hilbert 空間内の関数を，その外へ写すことがときどきあり，その場合は演算子の定義域を制限しなければならないことがある。

.. [#] 有限次元ベクトル空間では，エルミート演算子はエルミート行列によって表される。エルミート行列は，その転置共役に等しい。

.. [#] しかし，二乗可積分であっても無限遠でゼロでないような関数も存在する。しかし，そのような関数は物理学には通常現れないので無視する。ただし，有限区間では境界項が消えるかは非自明な問題で慎重に検討しなければならない。
