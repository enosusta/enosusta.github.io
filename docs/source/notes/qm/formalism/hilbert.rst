Hilbert 空間
=====================

これまで見てきた具体的な量子系に共通する一般的な性質を念頭に置いて，理論をより一般的な形で記述することを考える。この章の目的は，個々の具体例で既に発見したことを首尾一貫した形で理解することである。

量子論は，波動関数と演算子という2つの構成物に基づいている。系の状態はその波動関数によって表され，可観測量は演算子によって表される。数学的には，波動関数は抽象的なベクトルであり，演算子はそれらに作用する線形写像である。したがって，量子力学の自然な言語は線形代数である。

量子力学が出会う「ベクトル」はその大部分が関数であり，無限次元空間に属する。それらに対しては行列記法は扱いにくく，有限次元の場合には行える操作が問題を起こすこともある。したがって，用語や記法の大部分は線形代数を学んだことのある人にとっては見慣れたものであるが，数学的には慎重に扱う必要がある。

位置 `x` のすべての関数の集合はベクトル空間を成すが，可能な物理的状態を表すには，波動関数 `\Psi` は規格化されていなければならない：

.. math::
    \int |\Psi|^2\,\dd x = 1

指定された区間上のすべての二乗可積分関数の集合

.. math::
    L^2(a,b) = \left\{f(x) \mid \int_a^b |f(x)|^2 \, dx < \infty \right\}

もベクトル空間を成す。さらに， `L^2(a,b)` 上に2つの関数 `f` と `g` の内積を

.. math::
    \braket{f|g} = \int_a^b f^*(x) g(x) \, dx

と定義する。 `f` と `g` がともに二乗可積分ならば，その内積は存在する [#]_ 。このような内積を備えた `L^2(a,b)` のような空間のことを **Hilbert 空間** という [#]_ 。したがって，量子力学では，

.. important::
    波動関数は Hilbert 空間に属する。

関数とそれ自身との内積が `1` であるとき，その関数は規格化されているという。また，2つの関数の内積がゼロであるとき，それらは直交しているという。さらに，関数の集合 `\{f_n\}` が規格化され互いに直交しているとき，その集合は正規直交しているという：

.. math::
    \braket{f_m|f_n} = \delta_{mn}

最後に，任意の関数を，ある関数の線形結合として表すことができるとき，その集合は完全であるという：

.. math::
    f(x) = \sum_{n=1}^{\infty}c_n f_n(x)

関数 `\{f_n(x)\}` が正規直交しているなら，その係数は Fourier の方法によって求められる：

.. math::
    c_n = \braket{f_n|f}

実際に，無限井戸型ポテンシャルの定常状態は区間 `(0,a)` 上の完全な正規直交集合をなし，調和振動子型ポテンシャルの定常状態は区間 `(-\infty,\infty)` 上の完全な正規直交集合をなしていた。

.. [#] これは積分に対する Schwarz の不等式から従う。

.. [#] 正確には，Hilbert 空間は完備な内積空間であり， `L^2(a,b)` は Hilbert 空間の一例にすぎない。ここで完備という用語は，Hilbert 空間内の関数の任意の Cauchy 列が，その空間内の関数に収束することを意味する。
