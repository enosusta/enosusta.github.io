Problem 2.8
==================

規格化条件より，

.. math::
    1 = |A|^2\int_0^{a/2}\dd x = |A|^2\frac{a}{2}

となるので，

.. math::
    A = \sqrt{\frac{2}{a}}

と選べる。 `E_1 = \pi^2\hbar^2/2ma^2` が得られる確率は，

.. math::
    \begin{aligned}
        c_1 &= \sqrt{\frac{2}{a}}\int_0^a\sin\left(\frac{\pi x}{a}\right)\Psi(x,0)\,\dd x
        \\
        &= \frac{2}{a}\int_0^{a/2}\sin\left(\frac{\pi x}{a}\right)\dd x
        \\
        &= \frac{2}{a}\left[-\frac{a}{\pi}\cos\left(\frac{\pi x}{a}\right)\right]_0^{a/2} = \frac{2}{\pi}
    \end{aligned}

より，

.. math::
    P(E_1) = |c_1|^2 = \frac{4}{\pi^2} \approx 0.405

となる。
