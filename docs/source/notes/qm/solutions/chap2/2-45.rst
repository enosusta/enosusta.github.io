Problem 2.45
==================

a.  各固有状態は

    .. math::
        -\frac{\hbar^2}{2m}\psi_j'' + V\psi_j = E_j\psi_j

    を満たすので，

    .. math::
        \psi_j'' = \frac{2m}{\hbar^2}(V-E_j)\psi_j

    と書ける。これを

    .. math::
        \begin{aligned}
            \dv{}{x}(\psi_m'\psi_n-\psi_m\psi_n') &= \psi_m''\psi_n + \psi_m'\psi_n' - \psi_m'\psi_n' - \psi_m\psi_n''
            \\
            &= \psi_m''\psi_n - \psi_m\psi_n''
        \end{aligned}

    に代入すると，

    .. math::
        \psi_m''\psi_n - \psi_m\psi_n'' &= \frac{2m}{\hbar^2}[(V-E_m)-(V-E_n)]\psi_m\psi_n
        \\
        &= \frac{2m}{\hbar^2}(E_n-E_m)\psi_m\psi_n

    となる。したがって，

    .. math::
        \dv{}{x}(\psi_m'\psi_n-\psi_m\psi_n') = \frac{2m}{\hbar^2}(E_n-E_m)\psi_m\psi_n

    となる。

b.  \(a) の結果を `x_1` から `x_2` まで積分すると，

    .. math::
        [\psi_m'\psi_n-\psi_m\psi_n']_{x_1}^{x_2} = \frac{2m}{\hbar^2}(E_n-E_m)\int_{x_1}^{x_2}\psi_m\psi_n\,\dd x

    ここで

    .. math::
        \psi_m(x_1) = \psi_m(x_2) = 0

    であるから，

    .. math::
        \psi_m'(x_2)\psi_n(x_2)-\psi_m'(x_1)\psi_n(x_1) = \frac{2m}{\hbar^2}(E_n-E_m)\int_{x_1}^{x_2}\psi_m\psi_n\,\dd x

    となる。

c.  `x_1,x_2` は隣り合う節なので，開区間 `(x_1,x_2)` では `\psi_m` の符号は変わらない。そこで，位相を選んで

    .. math::
        \psi_m(x) > 0 \quad (x_1<x<x_2)

    とできる。そうすると，

    .. math::
        \psi_m'(x_1) > 0, \quad \psi_m'(x_2) < 0

    となる。ここで `\psi_n` が `(x_1,x_2)` に節を持たないと仮定すると，

    .. math::
        \psi_n(x) > 0 \quad (x_1<x<x_2)

    とできる。このとき，

    .. math::
        \psi_n(x_1),\psi_n(x_2) \ge 0

    となり，

    .. math::
        \psi_m'(x_2)\psi_n(x_2)-\psi_m'(x_1)\psi_n(x_1) \le 0

    となるが，

    .. math::
        E_n-E_m > 0,\quad \psi_m(x)\psi_n(x) > 0 \quad (x_1<x<x_2)

    なので，

    .. math::
        \frac{2m}{\hbar^2}(E_n-E_m)\int_{x_1}^{x_2}\psi_m\psi_n\,\dd x > 0

    となり，矛盾する。したがって， `\psi_m` の隣り合う2つの節の間には `\psi_n` の節が少なくともひとつ存在する。
