Problem 2.1
==================

a.  分離された解を

    .. math::
        \Psi(x,t) = \psi(x)e^{-iEt/\hbar}

    とし，分離定数を `E=E_0+i\Gamma\,(E_0,\Gamma\in\R)` と置く。そうすると，

    .. math::
        \begin{aligned}
            e^{-iEt/\hbar} &= \exp\left[-\frac{i}{\hbar}(E_0+i\Gamma)t\right]
            \\
            &= e^{-iE_0t/\hbar}e^{\Gamma t/\hbar}
        \end{aligned}

    となる。したがって，

    .. math::
        |\Psi(x,t)|^2 = |\psi(x)|^2 e^{2\Gamma t/\hbar}

    となる。全確率は，

    .. math::
        \int_{-\infty}^{\infty}|\Psi(x,t)|^2\,\dd x = e^{2\Gamma t/\hbar}\int_{-\infty}^{\infty}|\psi(x)|^2\,\dd x

    となるので， `\psi(x)` が規格化されていても `\Gamma>0` ならば全確率は指数的に増大し， `\Gamma<0` ならば指数的に減少する。しかし全確率は任意の時刻で `1` でなければならないので，

    .. math::
        \Gamma = 0

    でなければならない。したがって，分離定数 `E` は実数でなければならない。

b.  `V(x)` を実数のポテンシャルとする。 \(a) より `E` は実数なので，時間に依存しない Schrödinger 方程式とその複素共役は，

    .. math::
        \begin{aligned}
            -\frac{\hbar^2}{2m}\psi'' + V\psi = E\psi
            \\
            -\frac{\hbar^2}{2m}(\psi^*)'' + V\psi^* = E\psi^*
        \end{aligned}

    となる。よって `\psi^*` も同じ固有値 `E` の解である。微分方程式は線形なので，2つの線形結合

    .. math::
        \begin{aligned}
            u(x) &\coloneqq \frac{\psi+\psi^*}{2} = \mathrm{Re}\,\psi
            \\
            v(x) &\coloneqq \frac{\psi-\psi^*}{2i} = \mathrm{Im}\,\psi
        \end{aligned}

    も同じ方程式を満たし，定義より `u,v` は実数である。したがって，各固有値の解は実数値関数の線形結合として表すことができる。

c.  `V(-x)=V(x)` とする。時間に依存しない Schrödinger 方程式で `x` を `-x` に置き換えると，

    .. math::
        -\frac{\hbar^2}{2m}\psi''(-x) + V(-x)\psi(-x) = E\psi(-x)
        
    となる。すなわち `\psi(-x)` も同じ固有値 `E` の解である。したがって，2つの線形結合

    .. math::
        \begin{aligned}
            \psi_+(x) &\coloneqq \frac{\psi(x)+\psi(-x)}{2}
            \\
            \psi_-(x) &\coloneqq \frac{\psi(x)-\psi(-x)}{2}
        \end{aligned}

    も同じ方程式を満たし， `\psi_+` は偶関数， `\psi_-` は奇関数である。したがって，各固有値の解は偶関数と奇関数の線形結合として表すことができる。
