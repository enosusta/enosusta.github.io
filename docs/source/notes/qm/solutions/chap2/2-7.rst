Problem 2.7
==================

a.  規格化条件より，

    .. math::
        \begin{aligned}
            1 &= |A|^2\left[\int_0^{a/2}x^2\,\dd x + \int_{a/2}^a(a-x)^2\,\dd x\right]
            \\
            &= |A|^2\left[\frac{a^3}{24} + \frac{a^3}{24}\right] = \frac{|A|^2a^3}{12}
        \end{aligned}

    となるので，

    .. math::
        A = \sqrt{\frac{12}{a^3}} = \frac{2\sqrt{3}}{a^{3/2}}

    と選べる。

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt

        a = 1.0
        A = 2.0 * np.sqrt(3.0) / a**1.5

        x = np.linspace(-0.1 * a, 1.1 * a, 1001)
        psi = np.piecewise(
            x,
            [
                (0.0 <= x) & (x <= a / 2.0),
                (a / 2.0 < x) & (x <= a),
            ],
            [
                lambda x: A * x,
                lambda x: A * (a - x),
                0.0,
            ],
        )

        plt.plot(x, psi)
        plt.xlabel(r"$x$")
        plt.ylabel(r"$\Psi(x,0)$")
        plt.xticks(
            [0.0, a / 2.0, a],
            [r"$0$", r"$a/2$", r"$a$"],
        )
        plt.yticks([0.0, A * a / 2.0], [r"$0$", r"$Aa/2$"])
        plt.grid(alpha=0.25)
        plt.show()

b.  `b\coloneqq n\pi/a` を置くと，式 (2.40) より，

    .. math::
        c_n = \sqrt{\frac{2}{a}}A\left[\int_0^{a/2}x\sin(bx)\,\dd x + \int_{a/2}^a(a-x)\sin(bx)\,\dd x\right]

    となる。ここで第二項の積分変数を `u=a-x` を変換すると，

    .. math::
        \sin[b(a-u)] = \sin(n\pi-bu) = (-1)^{n+1}\sin(bu)

    となるので，第一項とまとめることができて，

    .. math::
        c_n = \sqrt{\frac{2}{a}}A[1+(-1)^{n+1}]\int_0^{a/2}x\sin(bx)\,\dd x

    となる。ここで，

    .. math::
        \begin{aligned}
            \int_0^{a/2}x\sin(bx)\,\dd x &= \left[-\frac{x\cos(bx)}{b} + \frac{\sin(bx)}{b^2}\right]_0^{a/2}
            \\
            &= -\frac{a^2}{2n\pi}\cos\left(\frac{n\pi}{2}\right) + \frac{a^2}{n^2\pi^2}\sin\left(\frac{n\pi}{2}\right)
        \end{aligned}

    であり， `n` が偶数のとき `1+(-1)^{n+1}=0` なので， `c_n=0` となる。 `n` が奇数のときは `1+(-1)^{n+1}=2` であり， `\cos(n\pi/2)=0` なので，

    .. math::
        c_n = \begin{cases}
            \frac{4\sqrt{6}}{n^2\pi^2}\sin\left(\frac{n\pi}{2}\right) & (n:\text{odd})
            \\
            0 & (n:\text{even})
        \end{cases}

    となる。実際，

    .. math::
        \sum_n |c_n|^2 = \frac{96}{\pi^4}\sum_{n:\text{odd}}\frac{1}{n^4} = \frac{96}{\pi^4}\frac{\pi^4}{96} = 1

    となる。したがって，

    .. math::
        \Psi(x,t) = \sum_{n:\text{odd}}\frac{4\sqrt{6}}{n^2\pi^2}\sin\left(\frac{n\pi}{2}\right)\sqrt{\frac{2}{a}}\sin\left(\frac{n\pi x}{a}\right)e^{-i(n^2\pi^2\hbar/2ma^2)t}

    となる。

c.  `c_1=4\sqrt{6}/\pi^2` なので，

    .. math::
        P(E_1) = |c_1|^2 = \frac{96}{\pi^4} \approx 0.985

    となる。

d.  `|c_n|^2 = 96/(n^4\pi^4)` なので，

    .. math::
        \begin{aligned}
            \braket{H} &= \sum_{n:\text{odd}}|c_n|^2E_n
            \\
            &= \sum_{n:\text{odd}}\frac{96}{n^4\pi^4}\frac{n^2\pi^2\hbar^2}{2ma^2}
            \\
            &= \frac{48\hbar^2}{ma^2\pi^2}\sum_{n:\text{odd}}\frac{1}{n^2}
            \\
            &= \frac{48\hbar^2}{ma^2\pi^2}\frac{\pi^2}{8} = \frac{6\hbar^2}{ma^2}
        \end{aligned}

    となる。ここで `\sum_{n:\text{odd}}1/n^2=\pi^2/8` を用いた。
