Problem 2.21
==================

a.  規格化条件より，

    .. math::
        \begin{aligned}
            1 &= A^2\int_{-\infty}^{\infty}e^{-2ax^2}\,\dd x
            \\
            &= A^2\sqrt{\frac{\pi}{2a}}
        \end{aligned}

    となり， `A` は正なので，

    .. math::
        A = \left(\frac{2a}{\pi}\right)^{1/4}

    となる。

b.  Fourier 変換は，

    .. math::
        \phi(k) = \frac{A}{\sqrt{2\pi}}\int_{-\infty}^{\infty}e^{-ax^2-ikx}\,\dd x

    であり，指数部分を

    .. math::
        ax^2 + ikx = a\left(x+\frac{ik}{2a}\right)^2 + \frac{k^2}{4a}

    と平方完成すると，

    .. math::
        \begin{aligned}
            \phi(k) &= \frac{A}{\sqrt{2\pi}}e^{-k^2/4a}\int_{-\infty}^{\infty}\exp\left[-a\left(x+\frac{ik}{2a}\right)^2\right]\,\dd x
            \\
            &= \frac{A}{\sqrt{2\pi}}e^{-k^2/4a}\sqrt{\frac{\pi}{a}}
            \\
            &= \frac{A}{\sqrt{2a}}e^{-k^2/4a}
        \end{aligned}

    となる。したがって，

    .. math::
        \begin{aligned}
            \Psi(x,t) &= \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty}\phi(k)e^{i(kx-\hbar k^2t/2m)}\,\dd k
            \\
            &= \frac{A}{2\sqrt{\pi a}}\int_{-\infty}^{\infty}\exp\left[-\left(\frac{1}{4a}+\frac{i\hbar t}{2m}\right)k^2 + ikx\right]\,\dd k
        \end{aligned}

    となる。ここで，

    .. math::
        q \coloneqq \frac{1}{4a} + \frac{i\hbar t}{2m} = \frac{\gamma^2}{4a}

    と置くと， `\operatorname{Re}q>0` で，指数部分を

    .. math::
        -qk^2 + ikx = -q\left(k-\frac{ix}{2q}\right)^2 - \frac{x^2}{4q}

    と平方完成すると，

    .. math::
        \begin{aligned}
            \Psi(x,t) &= \frac{A}{2\sqrt{\pi a}}\int_{-\infty}^{\infty}e^{-qk^2 + ikx}\,\dd k
            \\
            &= \frac{A}{2\sqrt{\pi a}}\sqrt{\frac{\pi}{q}}\exp\left(-\frac{x^2}{4q}\right)
            \\
            &= \left(\frac{2a}{\pi}\right)^{1/4}\frac{1}{\gamma}\exp\left(-\frac{ax^2}{\gamma^2}\right)
        \end{aligned}

    となる。

c.  `\beta\coloneqq 2\hbar at/m` と置くと， `\gamma^2 = 1 + i\beta` より，

    .. math::
        |\gamma^2| = |\gamma|^2 = \sqrt{1+\beta^2}

    となる。また，

    .. math::
        \frac{1}{\gamma^2} = \frac{1-i\beta}{1+\beta^2},\quad \operatorname{Re}\left(\frac{1}{\gamma^2}\right) = \frac{1}{1+\beta^2}

    となるので，

    .. math::
        \begin{aligned}
            \left|\exp\left(-\frac{ax^2}{\gamma^2}\right)\right|^2 &= \exp\left[-ax^2\left(\frac{1}{\gamma^2}+\frac{1}{(\gamma^2)^*}\right)\right]
            \\
            &= \exp\left[-ax^2\frac{(\gamma^2)^*+\gamma^2}{|\gamma^2|^2}\right]
            \\
            &= \exp\left[-\frac{2ax^2}{1+\beta^2}\right]
        \end{aligned}

    となる。さらに， `|1/\gamma|^2 = 1/|\gamma|^2` より，

    .. math::
        \begin{aligned}
            |\Psi(x,t)|^2 &= \sqrt{\frac{2a}{\pi}}\frac{1}{\sqrt{1+\beta^2}}\exp\left[-\frac{2ax^2}{1+\beta^2}\right]
            \\
            &= \sqrt{\frac{2}{\pi}}we^{-2w^2x^2}
        \end{aligned}

    となる。したがって波束は時間とともに拡散する：

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt

        a = 1.0
        mass = 1.0
        hbar = 1.0
        t_large = 5.0

        def probability_density(x, t):
            beta = 2.0 * hbar * a * t / mass
            spreading = 1.0 + beta**2
            return (
                np.sqrt(2.0 * a / np.pi)
                / np.sqrt(spreading)
                * np.exp(-2.0 * a * x**2 / spreading)
            )

        beta_large = 2.0 * hbar * a * t_large / mass
        sigma_large = np.sqrt(1.0 + beta_large**2) / (2.0 * np.sqrt(a))
        x = np.linspace(-4.0 * sigma_large, 4.0 * sigma_large, 1001)

        plt.plot(x, probability_density(x, 0.0), label=r"$t=0$")
        plt.plot(
            x,
            probability_density(x, t_large),
            label=rf"$t={t_large:g}$",
        )
        plt.xlabel(r"$x$")
        plt.ylabel(r"$|\Psi(x,t)|^2$")
        plt.xlim(x[0], x[-1])
        plt.grid(alpha=0.25)
        plt.legend()
        plt.show()

d.  `|\Psi(x,t)|^2, |\phi(k)|^2` は偶関数なので，

    .. math::
        \braket{x} = \braket{k} = 0

    となる。また，

    .. math::
        \begin{aligned}
            \braket{x^2} &= \sqrt{\frac{2}{\pi}}w\int_{-\infty}^{\infty}x^2e^{-2w^2x^2}\,\dd x
            \\
            &= \sqrt{\frac{2}{\pi}}w\frac{\sqrt{\pi}}{2(2w^2)^{3/2}}
            \\
            &= \frac{1}{4w^2} = \frac{1+\beta^2}{4a}
            \\
            \braket{p^2} &= \hbar^2\int_{-\infty}^{\infty}k^2|\phi(k)|^2\,\dd k
            \\
            &= \frac{\hbar^2}{\sqrt{2\pi a}}\int_{-\infty}^{\infty}k^2e^{-k^2/2a}\,\dd k
            \\
            &= \frac{\hbar^2}{\sqrt{2\pi a}}\sqrt{2\pi}a^{3/2} = a\hbar^2
        \end{aligned}

    となる。したがって，

    .. math::
        \begin{aligned}
            \sigma_x &= \sqrt{\braket{x^2}-\braket{x}^2} = \frac{\sqrt{1+\beta^2}}{2\sqrt{a}}
            \\
            \sigma_p &= \sqrt{\braket{p^2}-\braket{p}^2} = \hbar\sqrt{a}
        \end{aligned}

    となる。

e.  \(d) の結果より，

    .. math::
        \begin{aligned}
            \sigma_x\sigma_p &= \frac{\sqrt{1+\beta^2}}{2\sqrt{a}}\hbar\sqrt{a}
            \\
            &= \frac{\hbar}{2}\sqrt{1+\left(\frac{2\hbar at}{m}\right)^2} \geq \frac{\hbar}{2}
        \end{aligned}

    となり，Heisenberg の不確定性原理を満たす。最小点は `t=0` であり，そのとき等号が成立する。
