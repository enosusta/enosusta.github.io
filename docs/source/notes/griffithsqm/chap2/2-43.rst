Problem 2.43
==================

ポテンシャルは偶関数なので，固有関数は偶関数か奇関数である。奇関数の場合， `0< x <a` において，

.. math::
    \psi(x) = C\sin(kx),\quad ka = j\pi \quad (j=1,2,\ldots)

であり，許されるエネルギーは，

.. math::
    E_j = \frac{j^2\pi^2\hbar^2}{2ma^2}

となる。 `x=0` における境界条件

.. math::
    \psi'(0^+) - \psi'(0^-) = \frac{2m\alpha}{\hbar^2}\psi(0)

については， `\psi(0)=0` であり， `\psi'(0^+) = \psi'(0^-)` であるので，自動的に満たされる。物理的にも，

.. math::
    \alpha\delta(x)\psi(x) = \alpha\delta(x)\psi(0) = 0

となるため，奇関数で表される状態はデルタ関数型ポテンシャルの影響を受けない。一方で，偶関数の場合，境界条件 `\psi(-a)=\psi(a)=0` を満たす波動関数は，

.. math::
    \psi(x) = \begin{cases}
        C\sin(k(a+x)) & (-a<x<0)
        \\
        C\sin(k(a-x)) & (0<x<a)
    \end{cases}

と書ける。まとめると，

.. math::
    \psi(x) = C\sin(k(a-|x|)) \quad (|x|<a)

と書ける。ここで，

.. math::
    \begin{aligned}
        \psi(0) &= C\sin(ka)
        \\
        \psi'(0^+) &= -Ck\cos(ka)
        \\
        \psi'(0^-) &= Ck\cos(ka)
    \end{aligned}

となるので， `x=0` における境界条件は，

.. math::
    -2Ck\cos(ka) = \frac{2m\alpha}{\hbar^2}C\sin(ka)

すなわち，

.. math::
    k\cot(ka) = -\frac{m\alpha}{\hbar^2}

となる。ここで，

.. math::
    z \coloneqq ka,\quad \lambda \coloneqq \frac{m\alpha a}{\hbar^2}

と置くと，境界条件と許されるエネルギーは，

.. math::
    z\cot(z) = -\lambda,\quad E = \frac{\hbar^2 z^2}{2ma^2}

となる。

.. plot::
    :include-source: true
    :context: reset

    import numpy as np
    import matplotlib.pyplot as plt

    lam = 1.0
    z_max = 3.0 * np.pi
    y_min = -8.0
    z = np.linspace(1.0e-3, z_max - 1.0e-3, 6000)

    left_hand_side = z / np.tan(z)
    right_hand_side = -lam * np.ones_like(z)

    left_hand_side[
        (left_hand_side > 0.0) | (left_hand_side < y_min)
    ] = np.nan

    plt.plot(z, left_hand_side, label=r"$z\cot z$")
    plt.plot(z, right_hand_side, label=r"$-\lambda$")
    plt.xlabel(r"$z$")
    plt.ylabel("Both sides of the boundary condition")
    plt.xticks(
        [0.0, np.pi / 2.0, np.pi, 3.0 * np.pi / 2.0,
         2.0 * np.pi, 5.0 * np.pi / 2.0, 3.0 * np.pi],
        [r"$0$", r"$\pi/2$", r"$\pi$", r"$3\pi/2$",
         r"$2\pi$", r"$5\pi/2$", r"$3\pi$"],
    )
    plt.xlim(0.0, z_max)
    plt.ylim(y_min, 0.0)
    plt.grid(alpha=0.25)
    plt.legend()
    plt.show()

したがって，デルタ関数型ポテンシャルは各偶関数状態の `z` ，つまりエネルギーを増やす。しかし，奇関数状態の `z` には到達しないため，エネルギー準位は依然として交互に現れる。 `\alpha\to 0` で `\lambda\to 0` となるので， `z\cot(z) = 0` となり，幅 `2a` の無限井戸型ポテンシャルの場合のエネルギー準位 `z \to (n+1/2)\pi\,(n=0,1,2,\ldots)` が得られる。一方で `\alpha\to\infty` では `\lambda \to \infty` となるので， `z\to (n+1)\pi` となり，奇関数のエネルギー準位に近づく。
