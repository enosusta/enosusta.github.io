Problem 2.41
==================

`x<0` では波動関数は，

.. math::
    \psi(x) = 0 \quad (x<0)

である。一方で `x>0` における時間に依存しない Schrödinger 方程式は通常の調和振動子型ポテンシャルの場合と同様に，

.. math::
    -\frac{\hbar^2}{2m}\psi''(x) + \frac{1}{2}m\omega^2 x^2\psi(x) = E\psi(x) \quad (x>0)

である。通常の調和振動子型ポテンシャルの解は，偶関数か奇関数であり，原点でゼロになるのは奇関数だけである。したがって半調和振動子型ポテンシャルの場合の許されるエネルギーは，

.. math::
    E_n = \left(2n + \frac{3}{2}\right)\quad (n=0,1,2,\ldots)

となる。
