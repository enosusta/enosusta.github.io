Problem 2.15
==================

漸化式を

.. math::
    a_j = -\frac{(j+1)(j+2)}{2(n-j)}a_{j+2}

と書き直す。 `n=5` では奇数次のみが現れ，最高次係数は慣例より `a_5=2^5=32` である。 `j=3,1` の場合は，

.. math::
    \begin{aligned}
        a_3 &= -\frac{(3+1)(3+2)}{2(5-3)}a_5 = -\frac{20}{4}\cdot 32=-160
        \\
        a_1 &= -\frac{(1+1)(1+2)}{2(5-1)}a_3 = -\frac{6}{8}\cdot(-160)=120
    \end{aligned}

となる。したがって，

.. math::
    H_5(\xi) = 32\xi^5 - 160\xi^3 + 120\xi

となる。

`n=6` では偶数次のみが現れ，最高次係数は慣例より `a_6=2^6=64` である。 `j=4,2,0` の場合は，

.. math::
    \begin{aligned}
        a_4 &= -\frac{(4+1)(4+2)}{2(6-4)}a_6 = -\frac{30}{4}\cdot 64=-480
        \\
        a_2 &= -\frac{(2+1)(2+2)}{2(6-2)}a_4 = -\frac{12}{8}\cdot(-480)=720
        \\
        a_0 &= -\frac{(0+1)(0+2)}{2(6-0)}a_2 = -\frac{2}{12}\cdot 720=-120
    \end{aligned}

となる。したがって，

.. math::
    H_6(\xi) = 64\xi^6 - 480\xi^4 + 720\xi^2 - 120

となる。
