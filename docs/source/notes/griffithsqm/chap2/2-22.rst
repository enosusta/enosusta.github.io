Problem 2.22
==================

a.  `\delta(x+2)` の台は `-2\in [-3,+1]` なので，

    .. math::
        \begin{aligned}
            \int_{-3}^{+1}(x^3-3x^2+2x-1)\delta(x+2)\,\dd x &= (-2)^3-3(-2)^2+2(-2)-1
            \\
            &= -8-12-4-1 = -25
        \end{aligned}

    となる。

b.  `\delta(x-\pi)` の台は `\pi\in [0,\infty)` なので，

    .. math::
        \begin{aligned}
            \int_{0}^{\infty}[\cos(3x)+2]\delta(x-\pi)\,\dd x &= \cos(3\pi)+2
            \\
            &= -1+2 = 1
        \end{aligned}

    となる。

c.  `\delta(x-2)` の台は `2\notin [-1,1]` なので，

    .. math::
        \int_{-1}^{+1}\exp(|x|+3)\delta(x-2)\,\dd x = 0

    となる。
