Problem 1.3
===================

a.  With the change of variables `u=\sqrt{\lambda}(x-a)`, the normalization condition becomes

    .. math::
        \begin{aligned}
            1 &= A\int_{-\infty}^{\infty} e^{-\lambda(x-a)^2}\,\dd x
            \\
            &= \frac{A}{\sqrt{\lambda}}\int_{-\infty}^{\infty} e^{-u^2}\,\dd u
            \\
            &= A\sqrt{\frac{\pi}{\lambda}}.
        \end{aligned}

    Thus, the normalization constant is

    .. math::
        A = \sqrt{\frac{\lambda}{\pi}}.

b.  Let `y=x-a`. Since `\rho` is an even function of `y`,

    .. math::
        \braket{x} = \braket{y+a} = \braket{y}+a = a.

    Similarly,

    .. math::
        \braket{x^2} = \braket{(y+a)^2} = \braket{y^2}+2a\braket{y}+a^2 = \braket{y^2}+a^2.

    Here,

    .. math::
        \begin{aligned}
            \braket{y^2} &= \sqrt{\frac{\lambda}{\pi}}\int_{-\infty}^{\infty} y^2 e^{-\lambda y^2}\,\dd y
            \\
            &= \sqrt{\frac{\lambda}{\pi}}\frac{\sqrt{\pi}}{2\lambda^{3/2}}
            \\
            &= \frac{1}{2\lambda},
        \end{aligned}

    and therefore

    .. math::
        \braket{x^2} = \frac{1}{2\lambda}+a^2.

    Hence, the standard deviation is

    .. math::
        \sigma = \sqrt{\braket{x^2}-\braket{x}^2} = \frac{1}{\sqrt{2\lambda}}.

c.
    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt

        x = np.linspace(-5, 5, 100)
        a = 1.0
        lambda_ = 1.0
        A = np.sqrt(lambda_/np.pi)
        rho = A * np.exp(-lambda_ * (x - a)**2)

        plt.plot(x, rho)
        plt.title(r'$\rho(x) = A e^{-\lambda (x-a)^2}$')
        plt.xlabel('x')
        plt.ylabel(r'$\rho(x)$')
        plt.grid()
        plt.show()
