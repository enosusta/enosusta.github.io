Problem 2.14
==================

The classically allowed region is

.. math::
    [-x_c,x_c],\quad x_c \coloneqq \sqrt{\frac{2E_0}{m\omega^2}} = \sqrt{\frac{\hbar}{m\omega}}.

Define

.. math::
    \xi \coloneqq \sqrt{\frac{m\omega}{\hbar}}x.

The probability of finding the particle outside the classically allowed region is

.. math::
    \begin{aligned}
        P_\text{out} &= \int_{-\infty}^{-x_c}|\psi_0|^2\,\dd x + \int_{x_c}^{\infty}|\psi_0|^2\,\dd x
        \\
        &= 2\int_{x_c}^{\infty}|\psi_0|^2\,\dd x
        \\
        &= \frac{2}{\sqrt{\pi}}\int_1^{\infty} e^{-\xi^2}\,\dd \xi
        \\
        &= 1 - \text{erf}(1).
    \end{aligned}

.. exec_code::

    import numpy as np
    from scipy.integrate import quad
    from scipy.special import erf

    def integrand(xi):
        return 2.0 / np.sqrt(np.pi) * np.exp(-xi**2)

    probability, estimated_error = quad(integrand, 1.0, np.inf)
    exact_value = 1.0 - erf(1.0)

    print(f"Numerical integral : {probability:.12f}")
    print(f"1 - erf(1)        : {exact_value:.12f}")
    print(f"Estimated error   : {estimated_error:.2e}")
