Problem 2.61
==================

a.  At an interior grid point inside the well, the time-independent Schrödinger equation is

    .. math::
        -\lambda\psi_{j-1} + 2\lambda\psi_j - \lambda\psi_{j+1} = E\psi_j

    For `N=1`, the only interior point is `j=1`. Defining `E_*\coloneqq\hbar^2/2ma^2`,

    .. math::
        \mathbf{H}_1 = \lambda(2) \implies \lambda = 4E_*

    For `N=2`,

    .. math::
        \mathbf{H}_2 = \lambda\begin{pmatrix}
            2 & -1
            \\
            -1 & 2
        \end{pmatrix} \implies \lambda = 9E_*

    For `N=3`,

    .. math::
        \mathbf{H}_3 = \lambda\begin{pmatrix}
            2 & -1 & 0
            \\
            -1 & 2 & -1
            \\
            0 & -1 & 2
        \end{pmatrix} \implies \lambda = 16E_*

    The first and last rows give

    .. math::
        \begin{aligned}
            2\lambda\psi_1 - \lambda\psi_2 &= E\psi_1
            \\
            -\lambda\psi_{N-1} + 2\lambda\psi_N &= E\psi_N
        \end{aligned}

    which is Equation (2.201) with `\psi_0=\psi_{N+1}=0` substituted.

b.  For `N=1`, clearly

    .. math::
        E = 2\lambda = 8E_*

    For `N=2`, the characteristic equation is

    .. math::
        \begin{vmatrix}
            2 - \mu & -1
            \\
            -1 & 2 - \mu
        \end{vmatrix} = (2 - \mu)^2 - 1 = 0

    so

    .. math::
        E = 9E_*,\quad 27E_*

    For `N=3`, the characteristic equation is

    .. math::
        \begin{vmatrix}
            2 - \mu & -1 & 0
            \\
            -1 & 2 - \mu & -1
            \\
            0 & -1 & 2 - \mu
        \end{vmatrix} = (2 - \mu)[(2 - \mu)^2 - 2] = 0

    so

    .. math::
        E = 16(2-\sqrt{2})E_*,\quad 32E_*,\quad 16(2+\sqrt{2})E_*

    From Equation (2.30), the exact result is

    .. math::
        E_n = \frac{n^2\pi^2\hbar^2}{2ma^2} = n^2\pi^2 E_*.

    .. exec_code::

        import numpy as np

        print("Energy unit: E_* = hbar^2/(2 m a^2)")
        print(f"{'N':>2} {'n':>2} {'E_numeric/E_*':>16} {'E_exact/E_*':>16} {'rel. error (%)':>16}")

        for N in (1, 2, 3):
            H = (N + 1)**2 * (
                2.0 * np.eye(N)
                - np.diag(np.ones(N - 1), k=1)
                - np.diag(np.ones(N - 1), k=-1)
            )
            eigenvalues = np.linalg.eigvalsh(H)
            n_values = np.arange(1, N + 1)
            exact_energies = (n_values * np.pi)**2
            relative_errors = 100.0 * (eigenvalues / exact_energies - 1.0)

            for n, numeric, exact, error in zip(
                n_values, eigenvalues, exact_energies, relative_errors,
            ):
                print(f"{N:2d} {n:2d} {numeric:16.8f} {exact:16.8f} {error:16.6f}")
            print()

        import numpy as np
        import matplotlib.pyplot as plt
        from scipy.linalg import eigh_tridiagonal

        def lowest_eigenvectors(N, number_of_states):
            scale = (N + 1)**2
            diagonal = 2.0 * scale * np.ones(N)
            off_diagonal = -scale * np.ones(N - 1)
            eigenvalues, eigenvectors = eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, number_of_states - 1),
            )

            x = np.linspace(0.0, 1.0, N + 2)
            states = []
            for index in range(number_of_states):
                vector = eigenvectors[:, index]
                if vector[0] < 0.0:
                    vector *= -1.0
                vector /= np.max(np.abs(vector))
                states.append(np.pad(vector, (1, 1)))
            return x, eigenvalues, states

        fig, axes = plt.subplots(
            1, 3, figsize=(12, 3.6), sharey=True,
            constrained_layout=True,
        )
        for ax, N in zip(axes, (1, 2, 3)):
            x, eigenvalues, states = lowest_eigenvectors(N, N)
            for n, (energy, vector) in enumerate(
                zip(eigenvalues, states), start=1,
            ):
                ax.plot(
                    x,
                    vector,
                    marker="o",
                    label=rf"$n={n},\ E/E_*={energy:.4f}$",
                )
            ax.axhline(0.0, color="black", linewidth=0.8)
            ax.set_title(rf"$N={N}$")
            ax.set_xlabel(r"$x/a$")
            ax.set_xlim(0.0, 1.0)
            ax.grid(alpha=0.25)
            ax.legend(fontsize="small")
        axes[0].set_ylabel("Eigenvector (normalized amplitude)")

        fig, axes = plt.subplots(
            1, 2, figsize=(10, 3.8), sharey=True,
            constrained_layout=True,
        )
        for ax, N in zip(axes, (10, 100)):
            x, eigenvalues, states = lowest_eigenvectors(N, 3)
            for n, (energy, vector) in enumerate(
                zip(eigenvalues, states), start=1,
            ):
                ax.plot(
                    x,
                    vector,
                    marker="o" if N == 10 else None,
                    markersize=3,
                    label=rf"$n={n},\ E/E_*={energy:.4f}$",
                )
            ax.axhline(0.0, color="black", linewidth=0.8)
            ax.set_title(rf"$N={N}$")
            ax.set_xlabel(r"$x/a$")
            ax.set_xlim(0.0, 1.0)
            ax.grid(alpha=0.25)
            ax.legend(fontsize="small")
        axes[0].set_ylabel("Eigenvector (normalized amplitude)")
        plt.show()
