Problem 2.64
==================

a.  The derivatives of `f(x)` are

    .. math::
        \begin{aligned}
            f'(x) &= \sum_{n=1}^{\infty}n a_n x^{n-1}
            \\
            f''(x) &= \sum_{n=2}^{\infty}n(n-1) a_n x^{n-2}
        \end{aligned}

    Shifting the index of `f''(x)` by two gives

    .. math::
        f''(x) = \sum_{n=0}^{\infty}(n+2)(n+1)a_{n+2}x^n

    The coefficient of `x^n` in `-x^2f''-2xf'` is

    .. math::
        -n(n-1)a_n -2na_n = -n(n+1)a_n

    Comparing coefficients at each order therefore gives

    .. math::
        (n+2)(n+1)a_{n+2} + [l(l+1)-n(n+1)]a_n = 0

    Solving for `a_{n+2}` gives

    .. math::
        a_{n+2} = \frac{(n-l)(n+l+1)}{(n+1)(n+2)}a_n \quad (n=0,1,2,\ldots).

b.  Set `L=l(l+1)` and introduce `b_n=na_n` for `n\geq1`. Then

    .. math::
        b_{n+2}=\left(1-\frac{L}{n(n+1)}\right)b_n

    Choosing a sufficiently large index `n_0`,

    .. math::
        b_{n_0+2k}=b_{n_0}
        \prod_{j=0}^{k-1}
        \left(1-\frac{L}{(n_0+2j)(n_0+2j+1)}\right)

    Since the deviation of the product from `1` is `O(n^{-1})`, for some constant `A\ne0` we can write

    .. math::
        b_n=A+O(n^{-1}),\quad
        a_n=\frac{A}{n}+O(n^{-2})

    Thus, for sufficiently large `n` the coefficients have the same sign, and the sum at `x=1` diverges like the harmonic series.

c.  For `l=0`,

    .. math::
        a_2 = \frac{(0-0)(0+1)}{(1)(2)}a_0 = 0

    so `f(x)=a_0`. For `l=1`,

    .. math::
        a_3 = \frac{(1-1)(1+2)}{(2)(3)}a_1 = 0

    so `f(x)=a_1x`. For `l=2`,

    .. math::
        \begin{aligned}
            a_2 &= \frac{(0-2)(0+3)}{(1)(2)}a_0 = -3a_0
            \\
            a_4 &= \frac{(2-2)(2+3)}{(3)(4)}a_2 = 0
        \end{aligned}

    so `f(x)=a_0(1-3x^2)`. For `l=3`,

    .. math::
        \begin{aligned}
            a_3 &= \frac{(1-3)(1+4)}{(2)(3)}a_1 = -\frac{5}{3}a_1
            \\
            a_5 &= \frac{(3-3)(3+4)}{(4)(5)}a_3 = 0
        \end{aligned}

    so `f(x)=a_1(x-5x^3/3)`. Therefore,

    .. math::
        \begin{aligned}
            P_0(x) &= a_0
            \\
            P_1(x) &= a_1x
            \\
            P_2(x) &= a_0(1-3x^2)
            \\
            P_3(x) &= a_1\left(x-\frac{5}{3}x^3\right).
        \end{aligned}
