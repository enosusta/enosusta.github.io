Problem 2.1
==================

a.  Let the separated solution be

    .. math::
        \Psi(x,t) = \psi(x)e^{-iEt/\hbar},

    and write the separation constant as `E=E_0+i\Gamma\,(E_0,\Gamma\in\R)`. Then

    .. math::
        \begin{aligned}
            e^{-iEt/\hbar} &= \exp\left[-\frac{i}{\hbar}(E_0+i\Gamma)t\right]
            \\
            &= e^{-iE_0t/\hbar}e^{\Gamma t/\hbar}.
        \end{aligned}

    Therefore,

    .. math::
        |\Psi(x,t)|^2 = |\psi(x)|^2 e^{2\Gamma t/\hbar}.

    The total probability is

    .. math::
        \int_{-\infty}^{\infty}|\Psi(x,t)|^2\,\dd x = e^{2\Gamma t/\hbar}\int_{-\infty}^{\infty}|\psi(x)|^2\,\dd x.

    Thus, even if `\psi(x)` is normalized, the total probability grows exponentially when `\Gamma>0` and decays exponentially when `\Gamma<0`. Since the total probability must equal `1` at all times, we must have

    .. math::
        \Gamma = 0.

    Hence, the separation constant `E` must be real.

b.  Let `V(x)` be a real potential. From (a), `E` is real, so the time-independent Schrödinger equation and its complex conjugate are

    .. math::
        \begin{aligned}
            -\frac{\hbar^2}{2m}\psi'' + V\psi &= E\psi
            \\
            -\frac{\hbar^2}{2m}(\psi^*)'' + V\psi^* &= E\psi^*.
        \end{aligned}

    Thus, `\psi^*` is also a solution with the same eigenvalue `E`. Since the differential equation is linear, the two linear combinations

    .. math::
        \begin{aligned}
            u(x) &\coloneqq \frac{\psi+\psi^*}{2} = \mathrm{Re}\,\psi
            \\
            v(x) &\coloneqq \frac{\psi-\psi^*}{2i} = \mathrm{Im}\,\psi
        \end{aligned}

    satisfy the same equation, and `u` and `v` are real by definition. Therefore, every solution for a given eigenvalue can be expressed as a linear combination of real-valued functions.

c.  Suppose `V(-x)=V(x)`. Replacing `x` by `-x` in the time-independent Schrödinger equation gives

    .. math::
        -\frac{\hbar^2}{2m}\psi''(-x) + V(-x)\psi(-x) = E\psi(-x).

    Thus, `\psi(-x)` is also a solution with the same eigenvalue `E`. Consequently, the two linear combinations

    .. math::
        \begin{aligned}
            \psi_+(x) &\coloneqq \frac{\psi(x)+\psi(-x)}{2}
            \\
            \psi_-(x) &\coloneqq \frac{\psi(x)-\psi(-x)}{2}
        \end{aligned}

    satisfy the same equation. Here `\psi_+` is even and `\psi_-` is odd. Therefore, every solution for a given eigenvalue can be expressed as a linear combination of an even function and an odd function.
