Problem 3.20
==================

The wave function in :ref:`notes/griffithsqm/chap2/2-5:Problem 2.5` is

.. math::
    \Psi(x,t)
    =\frac{1}{\sqrt{2}}
    \left[
        \psi_1(x)e^{-i\omega t}
        +\psi_2(x)e^{-i4\omega t}
    \right],
    \quad
    \omega=\frac{\pi^2\hbar}{2ma^2}.

Here,

.. math::
    \psi_n(x)
    =\sqrt{\frac{2}{a}}
    \sin\left(\frac{n\pi x}{a}\right),
    \quad
    E_n=n^2\hbar\omega.

The energies `E_1=\hbar\omega` and `E_2=4\hbar\omega` are each obtained with probability `1/2`, so

.. math::
    \begin{aligned}
        \braket{H}
        &=\frac{1}{2}(E_1+E_2)
        =\frac{5}{2}\hbar\omega
        \\
        \braket{H^2}
        &=\frac{1}{2}(E_1^2+E_2^2)
        =\frac{17}{2}(\hbar\omega)^2.
    \end{aligned}

Therefore,

.. math::
    \begin{aligned}
        \sigma_H^2
        &=\braket{H^2}-\braket{H}^2
        \\
        &=\left(\frac{17}{2}-\frac{25}{4}\right)
        (\hbar\omega)^2
        \\
        &=\frac{9}{4}(\hbar\omega)^2,
    \end{aligned}

and hence

.. math::
    \sigma_H=\frac{3}{2}\hbar\omega.

Next, we calculate the variance in position. From :ref:`notes/griffithsqm/chap2/2-5:Problem 2.5`,

.. math::
    \braket{x}
    =\frac{a}{2}
    -\frac{16a}{9\pi^2}\cos(3\omega t).

The diagonal matrix elements of `x^2` are

.. math::
    \braket{n|x^2|n}
    =a^2\left(
        \frac{1}{3}-\frac{1}{2n^2\pi^2}
    \right),

so

.. math::
    \braket{1|x^2|1}
    =a^2\left(
        \frac{1}{3}-\frac{1}{2\pi^2}
    \right),
    \quad
    \braket{2|x^2|2}
    =a^2\left(
        \frac{1}{3}-\frac{1}{8\pi^2}
    \right).

The off-diagonal element is

.. math::
    \begin{aligned}
        \braket{1|x^2|2}
        &=\frac{2}{a}\int_0^a x^2
        \sin\left(\frac{\pi x}{a}\right)
        \sin\left(\frac{2\pi x}{a}\right)\,\dd x
        \\
        &=\frac{1}{a}\int_0^a x^2
        \left[
            \cos\left(\frac{\pi x}{a}\right)
            -\cos\left(\frac{3\pi x}{a}\right)
        \right]\,\dd x.
    \end{aligned}

For a positive integer `r`,

.. math::
    \int_0^a x^2
    \cos\left(\frac{r\pi x}{a}\right)\,\dd x
    =\frac{2a^3(-1)^r}{r^2\pi^2},

and therefore

.. math::
    \braket{1|x^2|2}
    =-\frac{16a^2}{9\pi^2}.

Since the matrix element is real, `\braket{2|x^2|1}` has the same value, and

.. math::
    \begin{aligned}
        \braket{x^2}
        &=\frac{1}{2}\left(
            \braket{1|x^2|1}
            +\braket{2|x^2|2}
        \right)
        +\braket{1|x^2|2}\cos(3\omega t)
        \\
        &=a^2\left(
            \frac{1}{3}
            -\frac{5}{16\pi^2}
            -\frac{16}{9\pi^2}\cos(3\omega t)
        \right).
    \end{aligned}

Therefore,

.. math::
    \sigma_x^2
    =a^2\left[
        \frac{1}{12}
        -\frac{5}{16\pi^2}
        -\frac{256}{81\pi^4}\cos^2(3\omega t)
    \right],

and hence

.. math::
    \sigma_x
    =a\sqrt{
        \frac{1}{12}
        -\frac{5}{16\pi^2}
        -\frac{256}{81\pi^4}\cos^2(3\omega t)
    }.

Also, differentiating `\braket{x}` gives

.. math::
    \dv{\braket{x}}{t}
    =\frac{16a\omega}{3\pi^2}\sin(3\omega t).

Squaring both sides of the energy-time uncertainty principle and taking their difference gives

.. math::
    \sigma_H^2\sigma_x^2
    -\frac{\hbar^2}{4}
    \left(\dv{\braket{x}}{t}\right)^2
    =\hbar^2a^2\omega^2
    \left(
        \frac{3}{16}
        -\frac{45}{64\pi^2}
        -\frac{64}{9\pi^4}
    \right).

.. exec_code::

    import numpy as np

    coefficient = (
        3.0 / 16.0
        - 45.0 / (64.0 * np.pi**2)
        - 64.0 / (9.0 * np.pi**4)
    )

    print(f"Difference = {coefficient:.10f} hbar^2 a^2 omega^2")
