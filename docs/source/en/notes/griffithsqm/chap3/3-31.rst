Problem 3.31
==================

Define the inner product on the interval `[-1,1]` by

.. math::
    \braket{f|g}
    =\int_{-1}^{1}f(x)^*g(x)\,\dd x.

First, let `u_0(x)=1`. Then

.. math::
    \|u_0\|^2=\int_{-1}^{1}\dd x=2,

so the first normalized function is

.. math::
    e_0(x)=\frac{1}{\sqrt{2}}.

Next, the projection of `x` onto `e_0` vanishes because it is the integral of an odd function, and

.. math::
    u_1(x)=x,
    \quad
    \|u_1\|^2
    =\int_{-1}^{1}x^2\,\dd x
    =\frac{2}{3}.

Therefore,

.. math::
    e_1(x)=\sqrt{\frac{3}{2}}\,x.

For `x^2`,

.. math::
    \braket{e_0|x^2}
    =\frac{1}{\sqrt{2}}
    \int_{-1}^{1}x^2\,\dd x
    =\frac{\sqrt{2}}{3},
    \quad
    \braket{e_1|x^2}=0,

so the orthogonalized function is

.. math::
    u_2(x)
    =x^2-\braket{e_0|x^2}e_0(x)
    =x^2-\frac{1}{3}.

Its norm is

.. math::
    \begin{aligned}
        \|u_2\|^2
        &=\int_{-1}^{1}
        \left(x^2-\frac{1}{3}\right)^2\,\dd x
        \\
        &=\frac{2}{5}-\frac{4}{9}+\frac{2}{9}
        =\frac{8}{45},
    \end{aligned}

and hence

.. math::
    e_2(x)
    =\sqrt{\frac{45}{8}}
    \left(x^2-\frac{1}{3}\right)
    =\sqrt{\frac{5}{8}}\left(3x^2-1\right).

Finally, `x^3` is orthogonal to the even functions `e_0` and `e_2`, while

.. math::
    \braket{e_1|x^3}
    =\sqrt{\frac{3}{2}}
    \int_{-1}^{1}x^4\,\dd x
    =\frac{2}{5}\sqrt{\frac{3}{2}}.

Therefore,

.. math::
    u_3(x)
    =x^3-\braket{e_1|x^3}e_1(x)
    =x^3-\frac{3}{5}x.

Furthermore,

.. math::
    \begin{aligned}
        \|u_3\|^2
        &=\int_{-1}^{1}
        \left(x^3-\frac{3}{5}x\right)^2\,\dd x
        \\
        &=\frac{2}{7}-\frac{12}{25}+\frac{6}{25}
        =\frac{8}{175},
    \end{aligned}

so

.. math::
    e_3(x)
    =\sqrt{\frac{175}{8}}
    \left(x^3-\frac{3}{5}x\right)
    =\sqrt{\frac{7}{8}}\left(5x^3-3x\right).

Collecting these results, the orthonormal set is

.. math::
    e_0=\frac{1}{\sqrt{2}},
    \quad
    e_1=\sqrt{\frac{3}{2}}\,x,
    \quad
    e_2=\sqrt{\frac{5}{8}}\left(3x^2-1\right),
    \quad
    e_3=\sqrt{\frac{7}{8}}\left(5x^3-3x\right).
