Problem 4.15
==================

a.  The ground-state wave function is

    .. math::
        \psi_{100}(r,\theta,\phi)
        =\frac{1}{\sqrt{\pi a^3}}e^{-r/a}.

    Therefore, for any nonnegative integer `q`,

    .. math::
        \begin{aligned}
            \braket{r^q}
            &=\int r^q|\psi_{100}|^2\,\dd^3\bm{r}
            \\
            &=\frac{4}{a^3}
            \int_0^\infty r^{q+2}e^{-2r/a}\,\dd r.
        \end{aligned}

    Using `\int_0^\infty r^ne^{-\alpha r}\,\dd r=n!/\alpha^{n+1}` gives

    .. math::
        \braket{r}
        =\frac{4}{a^3}\frac{3!}{(2/a)^4}
        =\frac{3a}{2}

    and

    .. math::
        \braket{r^2}
        =\frac{4}{a^3}\frac{4!}{(2/a)^5}
        =3a^2.

b.  The ground state is spherically symmetric about the origin, so the integrand for `\braket{x}` is odd in `x`, and hence

    .. math::
        \braket{x}=0.

    Also,

    .. math::
        \braket{x^2}
        =\braket{y^2}
        =\braket{z^2}.

    Since `r^2=x^2+y^2+z^2`, it follows that

    .. math::
        \braket{x^2}
        =\frac{1}{3}\braket{r^2}
        =a^2.

c.  In the state `n=2`, `l=1`, and `m=1`,

    .. math::
        R_{21}(r)
        =
        \frac{1}{2\sqrt{6}a^{3/2}}
        \left(\frac{r}{a}\right)e^{-r/(2a)},
        \quad
        |Y_1^1|^2=\frac{3}{8\pi}\sin^2\theta.

    First, the radial part is

    .. math::
        \begin{aligned}
            \braket{r^2}_{21}
            &=\int_0^\infty r^4|R_{21}(r)|^2\,\dd r
            \\
            &=\frac{1}{24a^5}
            \int_0^\infty r^6e^{-r/a}\,\dd r
            \\
            &=30a^2.
        \end{aligned}

    On the other hand, since `x^2/r^2=\sin^2\theta\cos^2\phi`, the angular part is

    .. math::
        \begin{aligned}
            &\int_0^{2\pi}\int_0^\pi
            \frac{x^2}{r^2}|Y_1^1|^2
            \sin\theta\,\dd\theta\,\dd\phi
            \\
            &\quad=
            \frac{3}{8\pi}
            \int_0^{2\pi}\cos^2\phi\,\dd\phi
            \int_0^\pi\sin^5\theta\,\dd\theta
            \\
            &\quad=
            \frac{3}{8\pi}\cdot\pi\cdot\frac{16}{15}
            =\frac{2}{5}.
        \end{aligned}

    Therefore,

    .. math::
        \braket{x^2}_{211}
        =30a^2\cdot\frac{2}{5}
        =12a^2.
