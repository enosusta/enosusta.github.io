Problem 4.54
==================

a.  The probability density of the ground state is

    .. math::
        |\psi_{100}|^2
        =
        \frac{1}{\pi a^3}e^{-2r/a}.

    Therefore, the probability of finding the electron inside a nucleus of radius `b` is

    .. math::
        P
        =
        \frac{4}{a^3}
        \int_0^b r^2e^{-2r/a}\,\dd r.

    Setting `x=2r/a` and `\epsilon=2b/a` gives

    .. math::
        \begin{aligned}
            P
            &=
            \frac{1}{2}
            \int_0^\epsilon x^2e^{-x}\,\dd x
            \\
            &=
            1-e^{-\epsilon}
            \left(
            1+\epsilon+\frac{\epsilon^2}{2}
            \right).
        \end{aligned}

b.  Expanding `e^{-x}` and integrating gives

    .. math::
        P
        =
        \frac{\epsilon^3}{6}
        -\frac{\epsilon^4}{8}
        +\frac{\epsilon^5}{20}
        +O\left(\epsilon^6\right).

    Since `\epsilon=2b/a`, to lowest order,

    .. math::
        P
        \approx
        \frac{1}{6}
        \left(\frac{2b}{a}\right)^3
        =
        \frac{4}{3}
        \left(\frac{b}{a}\right)^3.

c.  If the wave function is treated as constant inside the nucleus,

    .. math::
        P
        \approx
        \frac{4}{3}\pi b^3|\psi_{100}(0)|^2
        =
        \frac{4}{3}\pi b^3
        \frac{1}{\pi a^3}
        =
        \frac{4}{3}
        \left(\frac{b}{a}\right)^3,

    in agreement with the lowest-order result in part (b).

d.  Using the given values, the numerical calculation is as follows.

    .. exec_code::

        b = 1.0e-15
        a = 0.5e-10
        probability = (4.0 / 3.0) * (b / a)**3

        print(f"P = {probability:.3e}")

    Therefore,

    .. math::
        P\approx1.07\times10^{-14}.
