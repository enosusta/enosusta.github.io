Problem 4.71
==================

a.  The wave functions constructed from the spherical harmonics with `n=2` and `l=1` are

    .. math::
        \begin{aligned}
            \psi_{210}
            &=
            \frac{1}{\sqrt{32\pi a^3}}
            \frac{r}{a}e^{-r/(2a)}\cos\theta,
            \\
            \psi_{211}
            &=
            -\frac{1}{\sqrt{64\pi a^3}}
            \frac{r}{a}e^{-r/(2a)}
            \sin\theta e^{i\phi},
            \\
            \psi_{21(-1)}
            &=
            \frac{1}{\sqrt{64\pi a^3}}
            \frac{r}{a}e^{-r/(2a)}
            \sin\theta e^{-i\phi}.
        \end{aligned}

    Using `x=r\sin\theta\cos\phi`, `y=r\sin\theta\sin\phi`, and `z=r\cos\theta` gives

    .. math::
        \begin{aligned}
            \psi_{2p_x}
            &=
            \frac{1}{\sqrt{2}}
            \left(\psi_{21(-1)}-\psi_{211}\right),
            \\
            \psi_{2p_y}
            &=
            \frac{i}{\sqrt{2}}
            \left(\psi_{21(-1)}+\psi_{211}\right),
            \\
            \psi_{2p_z}
            &=\psi_{210}.
        \end{aligned}

    Thus, all three Cartesian orbitals belong to the subspace with `n=2` and `l=1`.

b.  Denote the common radial factor by `F(r)`, so that `\psi_{2p_x}=xF(r)`. Applying `L_x=-i\hbar\left(y\partial_z-z\partial_y\right)` gives

    .. math::
        \begin{aligned}
            L_x\left[xF(r)\right]
            &=
            -i\hbar x
            \left[
            y\frac{z}{r}\dv{F}{r}
            -z\frac{y}{r}\dv{F}{r}
            \right]
            \\
            &=0.
        \end{aligned}

    Cyclically permuting the coordinates similarly gives

    .. math::
        L_x\psi_{2p_x}=0,
        \quad
        L_y\psi_{2p_y}=0,
        \quad
        L_z\psi_{2p_z}=0.

    Therefore, each orbital is an eigenstate of the corresponding angular-momentum component, with eigenvalue 0 in every case.

c.  The positive and negative isosurfaces of the wave functions are shown in red and blue, respectively. Length is measured in units of `a`, and the overall normalization constant is omitted when plotting `\psi_{2p_i}\propto x_i e^{-r/(2a)}`.

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt
        from scipy.special import lambertw

        theta = np.linspace(0.0, np.pi, 121)
        phi = np.linspace(0.0, 2.0 * np.pi, 241)
        theta, phi = np.meshgrid(theta, phi)

        directions = [
            np.sin(theta) * np.cos(phi),
            np.sin(theta) * np.sin(phi),
            np.cos(theta),
        ]
        unit_x, unit_y, unit_z = directions
        level = 0.12
        threshold = np.e * level / 2.0

        fig = plt.figure(figsize=(11, 3.8))
        labels = [r"$2p_x$", r"$2p_y$", r"$2p_z$"]

        for index, (component, label) in enumerate(
            zip(directions, labels), start=1,
        ):
            ax = fig.add_subplot(1, 3, index, projection="3d")
            absolute_component = np.abs(component)
            valid = absolute_component >= threshold

            argument = np.full_like(component, np.nan)
            argument[valid] = (
                -level / (2.0 * absolute_component[valid])
            )

            for branch in (0, -1):
                radius = np.full_like(component, np.nan)
                radius[valid] = (
                    -2.0 * lambertw(
                        argument[valid], branch,
                    ).real
                )

                for sign, color in (
                    (1.0, "tab:red"),
                    (-1.0, "tab:blue"),
                ):
                    signed_radius = np.where(
                        valid & (np.sign(component) == sign),
                        radius,
                        np.nan,
                    )
                    ax.plot_surface(
                        signed_radius * unit_x,
                        signed_radius * unit_y,
                        signed_radius * unit_z,
                        color=color,
                        alpha=0.72,
                        linewidth=0.0,
                        antialiased=True,
                    )

            ax.set_title(label)
            ax.set_xlabel(r"$x/a$")
            ax.set_ylabel(r"$y/a$")
            ax.set_zlabel(r"$z/a$")
            ax.set_xlim(-7.0, 7.0)
            ax.set_ylim(-7.0, 7.0)
            ax.set_zlim(-7.0, 7.0)
            ax.set_box_aspect((1.0, 1.0, 1.0))
            ax.view_init(elev=22.0, azim=35.0)

        fig.tight_layout()
        plt.show()
