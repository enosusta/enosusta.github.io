Problem 4.68
==================

a.  Let the grid spacing be `\Delta r=b/(N+1)` and the interior grid points be `r_j=j\Delta r`. The energy scale used in the finite-difference method is

    .. math::
        \lambda
        \coloneqq
        \frac{\hbar^2}{2m_e\left(\Delta r\right)^2}.

    Dividing the effective potential by this scale gives

    .. math::
        \begin{aligned}
            v_j
            &=
            \frac{1}{\lambda}
            \left[
            -\frac{e^2}{4\pi\epsilon_0r_j}
            +\frac{\hbar^2l\left(l+1\right)}{2m_er_j^2}
            \right]
            \\
            &=
            -\frac{2\Delta r}{aj}
            +\frac{l\left(l+1\right)}{j^2}
            \\
            &=
            -\frac{2\beta}{j}
            +\frac{l\left(l+1\right)}{j^2},
            \quad
            \beta\coloneqq\frac{b}{\left(N+1\right)a}.
        \end{aligned}

    Here we used `a=4\pi\epsilon_0\hbar^2/(m_ee^2)`. Thus, the dimensionless Hamiltonian `\bm{H}/\lambda` is a tridiagonal matrix whose diagonal entries are `2+v_j` and whose adjacent off-diagonal entries are `-1`.

b.  Set `\beta=1/50` and `N=1000`, and calculate the three lowest eigenvalues of the tridiagonal matrix. Since `\lambda=|E_1|/\beta^2` for `|E_1|=\hbar^2/(2m_ea^2)`, a numerical eigenvalue `\varepsilon` can be converted according to `E/|E_1|=\varepsilon/\beta^2`.

    .. exec_code::

        import numpy as np
        from scipy.linalg import eigh_tridiagonal

        N = 1000
        beta = 1.0 / 50.0
        j = np.arange(1, N + 1, dtype=float)
        off_diagonal = -np.ones(N - 1)

        print(
            f"{'l':>2} {'state':>5} {'E/|E_1|':>12} "
            f"{'free H E/|E_1|':>20}"
        )
        for l in range(3):
            diagonal = (
                2.0 - 2.0 * beta / j
                + l * (l + 1.0) / j**2
            )
            energies = eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, 2),
                eigvals_only=True,
            ) / beta**2

            for index, energy in enumerate(energies):
                n = l + index + 1
                exact = -1.0 / n**2
                print(
                    f"{l:2d} {index + 1:5d} {energy:12.8f} "
                    f"{exact:20.8f}"
                )

    The two lowest states for `l=0` and the lowest state for `l=1` agree well with the free-hydrogen values. The more extended, highly excited states are more strongly affected by confinement due to the wall at `b/a=(N+1)\beta=20.02`.

    The corresponding normalized eigenfunctions `u(r)` are plotted below. For clarity, each curve is scaled so that its maximum absolute value is 1.

    .. plot::
        :include-source: true
        :context: reset

        import numpy as np
        import matplotlib.pyplot as plt
        from scipy.linalg import eigh_tridiagonal

        N = 1000
        beta = 1.0 / 50.0
        j = np.arange(1, N + 1, dtype=float)
        off_diagonal = -np.ones(N - 1)
        radius = np.arange(N + 2) * beta

        fig, axes = plt.subplots(
            1, 3, figsize=(12, 3.8), sharex=True,
            constrained_layout=True,
        )

        for l, ax in enumerate(axes):
            diagonal = (
                2.0 - 2.0 * beta / j
                + l * (l + 1.0) / j**2
            )
            values, vectors = eigh_tridiagonal(
                diagonal,
                off_diagonal,
                select="i",
                select_range=(0, 2),
            )
            energies = values / beta**2

            for index in range(3):
                vector = vectors[:, index]
                if vector[np.argmax(np.abs(vector))] < 0.0:
                    vector *= -1.0
                vector /= np.max(np.abs(vector))
                vector = np.pad(vector, (1, 1))
                ax.plot(
                    radius,
                    vector,
                    label=rf"$E/|E_1|={energies[index]:.4f}$",
                )

            ax.axhline(0.0, color="black", linewidth=0.7)
            ax.set_title(rf"$l={l}$")
            ax.set_xlabel(r"$r/a$")
            ax.set_xlim(0.0, radius[-1])
            ax.grid(alpha=0.25)
            ax.legend(fontsize="small")

        axes[0].set_ylabel(r"$u(r)$ (scaled)")
        plt.show()
